# 待开发需求：一票多件仅一件回款即可触发整单返款归集

## 1. 需求概要

- 目的：在`回款返款`模式下，一张业务订单包含多个尾程包裹时，不再等待全部包裹录入实收回款；任一包裹已有有效实收回款，即可按业务订单归集返款。
- 适用范围：COD 业务订单、`回款返款`模式、一票多件场景。
- 核心结果：首个符合条件的包裹只负责触发整单归集；订单级`应付返款（即代收货款）`、订单级机算`代收货款手续费`和包裹级导入手续费按各自挂靠层级归集。

## 2. 修改前后口径

| 业务位置 | 修改前 | 修改后 |
| :--- | :--- | :--- |
| 归集对象 | 返款归集主要按正常签收 COD 包裹组织，未明确一票多件的整单触发方式。 | 返款账单按 COD 业务订单归集订单级金额，尾程包裹提供签收和实收回款事实。 |
| 回款触发条件 | `回款返款`要求包裹满足已回款条件，未明确是否必须等待同单全部包裹回款。 | 同一业务订单任一尾程包裹已录入非空且非零的有效`实收回款`，整张业务订单即满足已回款归集条件。 |
| 金额归属 | 订单侧金额与包裹侧金额的形成方式和挂靠边界不够明确。 | `应付返款`和OIS机算的`代收货款手续费`挂靠业务订单；导入的`实收回款`和包裹级导入手续费挂靠尾程包裹。 |
| 重复归集 | 未明确其他包裹后续回款时是否会重复计入订单金额。 | 系统按业务订单去重；后续包裹回款只更新对应包裹事实，不重复计入订单级金额。 |

## 3. 业务规则

1. OIS机算形成的`应付返款`和订单级机算`代收货款手续费`直接挂靠业务订单；BMS只读取结果，不负责计算这两个原始金额。
2. 订单费用报表导入的`实回货款`直接挂靠尾程包裹，并作为该包裹的`实收回款`事实。
3. `回款返款`模式下，任一尾程包裹已录入非空且非零的有效`实收回款`，即可触发所属业务订单进入返款账单归集范围；不要求其他包裹同时回款。
4. 首个满足条件的包裹只产生一次触发结果。系统必须以业务订单为去重单位，将该订单的`应付返款`计入返款账单一次。
5. 订单级机算`代收货款手续费`命中客户级返款配置中的直接扣减规则后，按业务订单计入一次；包裹级导入手续费按其导入值单独归集。两者同时存在时，不做额外冲突判断。
6. 同一订单的其他包裹后续录入或更新`实收回款`时，只新增或更新该包裹的回款事实，不得再次归集该订单的`应付返款`或`代收货款手续费`。
7. 包裹级`实收回款`不得复制到同一订单的其他包裹，也不得自动拆分为订单下各包裹的回款金额；各包裹的回款状态仍按自身实收回款独立判定。
8. 订单级机算手续费与包裹级导入手续费同时存在时，不做额外冲突判断；两者因挂靠对象层级不同，按各自挂靠层级同时归集。
9. 异常签收包裹不形成自身有效回款事实，不得单独触发所属业务订单归集。
10. `签收返款`仍按既有正常签收条件触发，不要求先录入实收回款；本需求不改变其先返后回顺序。

## 4. 数据来源、归集与场景结果

| 数据 | 形成方式 | 挂靠对象 | 本需求中的用途 |
| :--- | :--- | :--- | :--- |
| `应付返款` | OIS机算 | 业务订单 | 被包裹回款事实触发后，按订单计入返款账单一次。 |
| `代收货款手续费` | OIS按包裹计算后汇总 | 业务订单 | 命中直接扣减配置后，按订单级机算结果归集一次。 |
| `实收回款` | 订单费用报表导入 | 尾程包裹 | 判断`回款返款`模式下业务订单是否具备归集条件，并保留包裹回款事实。 |
| 包裹级导入手续费 | 订单费用报表导入 | 尾程包裹 | 按包裹级导入结果归集；与订单级机算手续费同时存在时，不做额外冲突判断。 |


| 场景 | 处理结果 |
| :--- | :--- |
| 同一订单没有包裹录入有效实收回款 | `回款返款`模式下，不因本需求进入返款账单。 |
| 同一订单首个包裹录入有效实收回款 | 触发整张业务订单归集；订单级应付返款和符合配置的订单级机算手续费各归集一次。 |
| 同一订单其他包裹后续录入实收回款 | 更新对应包裹回款事实，不重复归集订单级金额。 |
| 同一订单同时存在订单级机算手续费和包裹级导入手续费 | 不做额外冲突判断；订单级机算手续费与包裹级导入手续费按各自挂靠层级同时归集。 |
| 返款模式为`签收返款` | 继续按正常签收条件归集，不套用“任一包裹实收回款触发”规则。 |

## 5. 生效与存量处理

1. 本规则用于功能上线后新发起的返款账单生成，以及按既有机制允许重新生成的未发出`待审核`账单。
2. 已生成账单不得因包裹后续回款或本规则上线而静默增加订单金额。
3. 未向客户发出的`待审核`账单需要采用本规则时，按账单生成机制重新处理。
4. 已向客户发出、待结清或已结清的账单不得自动作废、替换或回写；差异继续通过重算、调账、冲正或后续账单承接处理。
