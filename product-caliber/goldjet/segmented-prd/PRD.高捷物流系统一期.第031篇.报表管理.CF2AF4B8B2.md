## 1. 报表管理


**业务入口：** 报表管理页面。

**概念模型：** [数据字典 · 派生读模型与业务指标](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-domain-read-models)

### 1.1 报表范围、菜单与角色

报表按经营运营、财务与账龄、业绩利润和对账单模板分组。可独立复用的读模型、指标含义和单位见[数据字典 · 派生读模型与业务指标](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-domain-read-models)；各报表的取值、计算、筛选、字段组合和模板口径在对应场景中定义。

<a id="doc-CF2AF4B8B2-section-2627f0f4404b"></a>
#### 1.1.1 报表范围

报表管理汇总仓储、陆运、空运、电商和财务结算数据，提供经营监控、账龄分析、业绩利润分析与对账单输出。

#### 1.2.53 报表字段

**航晟陆运月报字段及场景约束：**

| 序号 | 字段 | 样式 |
| --- | --- | --- |
| 1 | 月份 | `<统计月份>` |
| 2 | 调度订单数 | `<调度订单数>` |
| 3 | 完成运输订单数 | `<完成运输订单数>` |
| 4 | 完成中转订单数 | `<完成中转订单数>` |
| 5 | 完成总订单数 | `<完成总订单数>` |
| 6 | 总应收 | `<总应收金额>` |
| 7 | 总应付 | `<总应付金额>` |
| 8 | 预计盈利 | `<预计盈利金额>` |

取值、计算、筛选与统计口径见[报表业务规则](PRD.高捷物流系统一期.第031篇.报表管理.CF2AF4B8B2.md#doc-CF2AF4B8B2-section-ad3ca407cbf9)。

各指标按下表所列来源、计算、筛选和统计口径取值。

| 序号 | 字段 | 取值来源 | 备注 |
| --- | --- | --- | --- |
| 1 | 月份 | 月份数依次倒序展示，从系统中第一笔订单的月份开始 |  |
| 2 | 调度订单数 | 该月总已完成的调度订单数（只要订单提交过调度就算） |  |
| 3 | 完成运输订单数 | 该月已完成的运输订单总数，运输订单状态=已完成，变更时间为该月 |  |
| 4 | 完成中转订单数 | 该月已完成中转订单总数，中转订单状态=已完成，变更时间为该月 |  |
| 5 | 完成总订单数 | 完成总订单数=完成运输订单数+完成中转订单数 |  |
| 6 | 总应收 | 该月已完成的所有订单的订单应收金额累计（取业务主管审批通过后的数据即可） |  |
| 7 | 总应付 | 该月已完成的所有订单的订单应付金额累计（取业务主管审批通过后的数据即可） |  |
| 8 | 预计盈利 | 预计盈利=总应收-总应付 |  |
