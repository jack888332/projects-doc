## 2. 集货、备货与附件申报

<a id="doc-034DD8F0D3-section-04cd41b57559"></a>

### 2.1 创建BC/CC进口集货出库需求单

**创建BC/CC进口集货出库需求单的业务约束**

- **适用范围**：根据仓库的出库清单，生成平台订单并选择需要的服务。

- **参与方**：客服

- **操作资格**：仓库已经生成出库清单

- **形成结果**：1、关务可以接单，并进行订单申报

- **处理行为**：1、仓库收到客户下发的订单，生成出库清单。<br>2、客服收到出库清单通知，把相同的出库清单的客户订单生成平台订单。<br>3、下发国内关务服务，关务接单<br>4、关务进行订单申报

- **例外处理**：1-1仓库缺货，无法下发，入库上架后再下发。

- **关联业务**：总运单录入、平台订单录入、客户门户订单管理

<a id="doc-034DD8F0D3-section-1cce8a4bd472"></a>

### 2.2 附件申报

**附件申报的业务约束**

- **适用范围**：CC进口需要对交易相关的附件进行申报

- **参与方**：关务

- **操作资格**：1、客服已经录入提单信息<br>2、系统可以根据订单和订购人信息自动生成相关附件

- **形成结果**：生成的附件正确并可以下载

- **处理行为**：客服已经录入提单信息，并通知接单的关务。<br>关务下载需要的资料，包括身份认证、小票、面单、身份证、发票、委托书，线下递交到海关。<br>对附件进行线上申报。<br>下线递交的附件和线上申报的附件相符，海关入库成功。

- **例外处理**：2-1导入数据模板有误，需要重新导入。<br>2-2导入数据重复或不完整，校验商品ID失败，如果没有备案，导入失败，下载导入失败的数据重新加工后再导入。<br>3-1、客服拒接，客户重新编辑后提交。

- **关联业务**：附件自动生成功能、附件申报

## 3. BC 进口订单与申报

<a id="doc-034DD8F0D3-section-d9d8f0cdec5c"></a>

### 3.1 客户订单管理

客户订单管理模块，用于承接电商平台的订单，客服可以查看不同电商平台的订单，以及订单的状态，可以对仓库出库的订单生成出库的平台订单。关务可以对订单进行申报，异常处理。

<a id="doc-034DD8F0D3-section-e8220b6f2021"></a>

### 3.2 BC进口订单

系统通过对接电商平台，把客户的电商平台订单信息同步到BC进口订单模块，客服可以查看各电商平台的订单的出库情况，把订单提交BC进口出库的平台订单。关务可以对订单的附件下载，对订单进行申报。

BC进口订单列表（未发货）

重置：清空所有查询条件。

提单录入：勾选一个客户订单，点击按钮，判断订单是否已经绑定干线，已经绑定干线提示“没有可操作的订单！”，还没有录入提单，查询订单所属出库订单号，跳转到新建提单（总运单）页面，把相同出库单号的订单一起绑定提单（总运单），同时把干线服务单对应的字段信息带到总运单，总运单—总运单号、启用港—港口代码、预计出港日期—预计离港时间、品名—中文品名、件数—托数/箱数、体积—体积、重量—提单总毛重。

录入提货后，系统自动把已经录入提单的BC客户订单进行订单申报和运单申报。

**待确认边界（CUSTOMS-B026）**：BC 转 CC 与 CC 转 BC 的清单资格、原出库订单状态及备案替换表述并不对称，且反向转换结果含 CC 转 BC 与作废/报废混写；最终状态及已下发仓库处理待确认。 下文涉及该边界的来源约束仅保留待确认，不视为已确定的执行规则。

转为CC订单：点击按钮，做以下校验——

1、校验清单状态是否为“海关退单”，如果不是，提示“没有可转换的订单！”，如果是，进行第二步校验；

2、把订单全部商品通过备案的商品ID查找对应的商品编号。如果全部或部分没有查出，弹窗提示“{商品名称}没有备案，请把商品进行CC和BC备案后再转换！”如果全部查出，弹出确认弹窗，确认后把订单从原来的总运单和出库平台订单解绑，并把订单转移到CC进口订单未发货列表，转换情况为“作废”，库存不动。

3、BC转CC订单后需要根据对应的行邮税号重新计算预估税金。

4、转换后的订单商品，对应的CC备案信息也要代替原来的BC备货信息。客服可以在CC订单-未发货列表重新生成出库平台订单。

从总运单解绑：点击按钮，校验订单状态是否为“待报关”，如果已经开始报关，提示“没有可解绑的订单！”，如果有，弹出确认弹窗，确认后把订单从原来的总运单和出库平台订单解绑，并把订单转移到BC进口订单未发货列表。客服可以重新生成出库平台订单。

### 7.2 BC进口关务

BC进口关务服务单是BC进口业务的国内清关服务单列表，客服生成平台订单后下发进口关务服务单。关务员可以在本页面看到自己已经接单和待接单的服务单，关务接单后只该服务单只显示在该关务的页面。

服务单列表显示服务单各状态的统计数据，包括“总计数量”、“待服务”、“进行中”、“已完成”、“已终止”、“已取消”。点击统计数量模块，可以把对应状态的服务单筛选显示出来。关务可以在服务单列表进行批量接单，查看服务单详情。当发生需要终止服务的情况，可以对服务单进行终止服务操作，被终止的服务单限制对应的订单继续进行报关操作。

查询：在填写查询条件后，点击查询按钮，列表展示符合该条件的数据。若未填写查询条件，点击查询按钮，列表数据无变化。

重置：清空所有查询条件。

收起：点击收起按钮，查询栏收起。（查询栏默认是展开状态）

自定义列表：点击自定义列表，展示自定义列表弹窗，可自定义字段显示或隐藏，以及字段排序。

查看：可查看该服务单的详情，点击查看按钮，跳转至服务单详情页。

终止服务：选择服务单后，点击按钮，判断选择的服务单是否进行中的状态，如果没有，提示“没有可终止的服务单”。如果有进行中的订单，弹出确认弹窗，确认后服务单状态为已终止。

流转：默认关闭，选择服务单后打开按钮。点击按钮，判断选择的服务单是否进行中的状态，如果没有，提示“没有可流转的服务单”。如果有进行中的订单，弹出流转弹窗。选择所有报关员可接单，本部门的其他报关员可以接单。指定人接单，选择一个本部门的报关员。点击确认后，订单改为待接单，并从本列表移出，订单显示在允许接单的报关员的服务单列表。

接单：默认关闭，选择服务单后打开按钮。点击后接单完成。

收起：点击收起按钮，查询栏收起。（查询栏默认是展开状态）

完成服务：选择列表一个订单，点击按钮，判断服务单是否“进行中”状态，如果不是，提示“没有可操作的订单！”，如果有，弹出确认弹窗，确认后服务单状态为“已完成”，完成的服务单不能在详情页补充信息。

终止服务：选择列表一个订单，点击按钮，判断服务单是否在“进行中”状态，同时判断上游取消服务为“是”，如果没有，toast“没有可终止的订单！”，如果有，弹窗确认弹窗，确认后服务单状态改为“已终止”。
