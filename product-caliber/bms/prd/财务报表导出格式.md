# 财务报表导出格式

以下格式基于 `aidocs/product-caliber/bms/prototype/财务给出报表` 目录内的样本文件整理，原则是：

1. 保留能影响金额、归属、追溯的字段。
2. 删除大面积空白的非费项冗余列，比如 `备用1/2/3`、单独的占位 `1`、纯分隔空列、图片占位列。
3. 明细列尽量统一命名，常见别名合并展示。
4. 账单头部信息、明细区、汇总区分开，便于导出后直接核对。

## 三、统一删除规则

<table>
  <thead>
    <tr>
      <th>删除对象</th>
      <th>处理结果</th>
      <th>原因</th>
    </tr>
  </thead>
  <tbody>
    <tr><td>`备用1 / 备用2 / 备用3`</td><td>删除</td><td>大面积空白，占位意义大于业务意义</td></tr>
    <tr><td>单独的 `1`、`2` 之类占位列</td><td>删除</td><td>通常只是排版残留</td></tr>
    <tr><td>纯空分隔列</td><td>删除</td><td>影响可读性，没有业务含义</td></tr>
    <tr><td>图片占位 / `DISPIMG` 区域</td><td>删除</td><td>导出文件只保留可计算字段</td></tr>
    <tr><td>金额、重量、地址、追溯字段</td><td>保留</td><td>这些字段决定账单完整性</td></tr>
  </tbody>
</table>

- `明细`
- `汇总`
