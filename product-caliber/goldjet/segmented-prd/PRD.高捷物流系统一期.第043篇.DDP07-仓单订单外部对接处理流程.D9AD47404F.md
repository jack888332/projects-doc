### 1.1 航晟物流：仓单订单外部对接处理的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | \| (入仓重量-报关重量)/报关重量\|<3%？ | 仓库系统 | 判断入仓实际重量与报关重量之差是否小于3%，如小于，则自动发送预配舱单信息。And 其他操作条件（密度要求）。 | 2 | 是 |
| 2 | 接收预配舱单 | 海关系统 | 接收并处理预配舱单信息。 | 4 |  |
| 3 | 手动确认重量信息，手动触发预配舱单 | 仓库系统 | 如重量误差大于3%（还有其他条件），则由空运/航晟物流-客户部进行人工确认重量，确认后由业务系统发送预配舱单。 | 4 |  |
| 4 | 接收预配舱单反馈信息 | 仓库系统 | 接收预配舱单的反馈结果信息。 | 5 |  |
| 5 | 线下申请报关 | 海关系统 | 线下操作，申请报关。 | 6 |  |
| 6 | 抓取报关状态：审结 | 海关系统 | 报关后，系统自动抓取海关的反馈状态结果。 | 7 |  |
| 7 | 自动出仓 | 仓库系统 | 当海关反馈状态为“放行”时，则仓库系统对该订单进行自动发送出仓单给WMS。 | 8 |  |
| 8 | 接收出仓单 | WMS | WMS接收出仓单，处理出仓。 | 9 |  |
| 9 | 反馈出仓信息 | WMS | WMS反馈出仓结果信息。 | 10 |  |
| 10 | 中转派车 | 仓库系统 | 对出仓货物进行中转派车（参考《中转仓用车流程》）。 | 11 |  |
| 11 | 手动/自动发送入区登记 | 仓库系统 | 手动或自动发送入区登记。 | 12 |  |
| 12 | 接收入区登记 | 货站 | 接收并处理入区登记信息。 | 13 |  |
| 13 | 反馈入区登记回执信息 | 货站 | 反馈入区登记回执信息。 | 14 |  |
| 14 | 接收入区登记回执信息 | 仓库系统 | 接收入区登记的回执信息。 |  |  |
