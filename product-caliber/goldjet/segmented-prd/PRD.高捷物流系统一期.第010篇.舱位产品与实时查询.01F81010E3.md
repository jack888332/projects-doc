#### 1.2.3 专用名词解释

| 专用名词 | 名词解释 |
| --- | --- |
| 合同板 | 航线部从不同航司购买的固定舱位。有效期限为一年。 |
| 临时板 | 航司基于市场的淡季和旺季，给予高捷有效期限为几天或几周的临时舱位。 |
| 板型 | 板的类型。不同航司的不同板型可呈纳不同体积的货物 |
| 基准载重 | 航司在跟高捷签订合同板的时候，会规定某一种板型的基准载重为XX千克。如果月结的时候，板容纳的货物重量没超过规定的基准载重时，高捷要付给航司惩罚金。 |
| 舱位总体积 | 以航班号+出港日期为维度，当前高捷可以使用的舱位总体积 |
| 已订舱位体积 | 基于已经绑定提单号的主订单，计算以航班号+出港日期的维度上已经被客户订舱的体积。 |
| 剩余舱位体积 | 舱位总体积-已订舱位体积。以航班号+出港日期为维度，当前业务可以销售的舱位。 |
