## 1. 数据字典边界与实体关系

本篇采用业务概念与逻辑实体视角，定义跨场景稳定的实体、属性、关系、值对象、受控术语、枚举和外部字段映射。查询栏、列表栏、新增、编辑、查看、审批等页面区域的字段组合，以及必填、默认、可编辑、只读、禁用、显隐、联动、分页和查询交互，由对应业务篇在实际场景中定义。

字段的“业务取值与格式”只保留产品可理解、可核对的值域、字符范围、日期格式、数值精度和单位，不规定数据库列类型、存储方案、前端组件或其他实现类型。场景规则可引用本篇实体定义；本篇不依赖某个页面区域才能成立。

同名属性只有在业务对象、含义和稳定约束相同时才共用定义；名称相同但对象或口径不同的属性分别定义。属性清单列出对象包含的数据；有明确取值、格式、来源或关联规则的属性在表格中单独说明。

同一字段在不同场景中的长度、格式或口径不一致时，本篇不推定统一约束；各场景按对应业务篇执行，冲突项保留待业务确认。

### 4.18 综合报价与计费值对象

| 实体或概念 | 稳定业务含义 | 关系或区别 |
| --- | --- | --- |
| 综合报价 | 财务组织及结算部门针对某业务类型、客户或供应商维护的服务计价约定 | 包含服务报价分组、一个或多个服务商品报价明细及有效期间；不与空运供应商运价、运输报价、仓库报价自动视为同一实体 |
| 外部客户报价、外部供应商报价 | 分别约定向外部客户收取费用、向外部供应商支付费用 | 引用对应合作方档案；合作方建档及财务审核前提由报价业务定义 |
| 内部客户报价 | 对集团内部财务组织及部门的应收约定 | 报价对方是内部组织与部门，不以外部客户名称代替其身份 |
| 服务报价分组 | 同一服务下按仓库、口岸、线路、地域或运输方式等条件组织的商品明细集合 | 不等同于服务商品类目 |
| 服务商品报价明细 | 报价内某个服务商品的计费模式与匹配条件组合 | 同商品可按区间或首加续分为多行，各行可具有独立的币种、含税方式、税率及有效日期 |
| 单价、区间单价、首加续 | 综合报价的三类计价模式 | 首加续的计量对象不限于重量，也可为主分单或报关票数；不把本模式与某一重量公式绑定 |
| 最低消费 | 报价约定的费用下限 | 比较对象及执行顺序属于计费规则，不由本概念推定 |
| 计费事件 | 某费用计算约定的业务触发事件 | 关联具体服务、费用及业务对象；不同费用的事件分别定义 |
| 内部应收转应付 | 本部门应收与内部对方部门应付之间的关联 | 不代表外部付款；生成及确认条件见报价配置 |
| 报价审批状态 | 报价的审核处理阶段，取值为待提交、待审核、审批成功、审批失败 | 与启用状态分别记录；内部报价的混合状态称谓尚待统一 |
| 报价启用状态 | 报价的使用状态，取值为未启用、已启用、已禁用 | 不以审批成功单独代替当前启用状态；迁移及重启边界由报价业务定义 |
| 成本项目映射 | 服务商品与财务成本项目、成本代码的对应关系 | 用于费用财务归类及金蝶交接；服务商品与成本项目不是同一标识 |
| 仓储免租天数 | 仓储报价中约定的免租期间长度 | 关联仓储报价及适用对象；计日、起算、批次及优先级规则由仓储计费正文定义 |
| 计费重量、计费件数 | 费用引用的业务对象重量或数量 | 总单、分单、包裹和SKU商品层级分别保留，不合并为可以互换的通用数量 |

报价形成、审批与启停见[报价生命周期](../PRD.高捷物流系统.第5册.财务管理/PRD.高捷物流系统.第044篇.综合报价与计费.6272B8B3EA.md#doc-6272B8B3EA-quote-lifecycle)，分组及明细约束见[报价配置](../PRD.高捷物流系统.第5册.财务管理/PRD.高捷物流系统.第044篇.综合报价与计费.6272B8B3EA.md#doc-6272B8B3EA-quote-configuration)，计费模式、逐费用算法和触发事件统一由[综合报价与计费](../PRD.高捷物流系统.第5册.财务管理/PRD.高捷物流系统.第044篇.综合报价与计费.6272B8B3EA.md#doc-6272B8B3EA-pricing-methods)定义。服务商品、合作方和成本项目复用本篇既有实体；柜型规格、托盘规格、车辆类型及车型作为报价匹配使用的受控基础资料，不另建报价专用主数据身份。

## 7. 关务概念与单据关系


<a id="doc-7A3D9E1F50-customs-terms"></a>
### 7.1 关务术语与申报模式

| 术语 | 业务含义 | 适用边界 |
| --- | --- | --- |
| 普货进出口 | 一般货物进出口并向海关申报的业务 | 与BC、CC、BBC业务类型区分 |
| 查验 | 海关对进出口实货进行核查，以核对申报与实际货物及归类、价格、原产地等信息 | 查验任务、查验结果与报关单是关联对象，不是同一记录 |
| 落装 | 已申报且已发运抵报告的海运出口拼箱货物，未由原运输工具装载出运 | 与重新订舱或一般未放行情况分开 |
| 改配 | 集装箱货物未按原计划配载后重新安排订舱的业务 | 具体原因及操作条件见普货关务场景，不以“改配”直接推定海关处理结果 |
| 删单退场 | 原计划出口不能继续，货物在站场且未进入监管仓库的删单退回业务 | 与已进入监管仓库的删单退仓区分 |
| 删单退仓 | 原计划出口不能继续，货物已在监管仓库内的删单退回业务 | “退仓”不等同于所有消费者退货 |
| 转关 | 货物在不同海关监管办理地点之间转移并衔接申报的业务 | 出口转关的参与方、申请与口岸顺序见相应主流程，不由该术语推导执行顺序 |
| 概要申报 | 两步申报中先提供概要项目的申报 | 与完整申报分别记录；补充时限及准入条件见普货关务 |
| 完整申报 | 两步申报中补充其余项目并办理税款等手续的申报 | 不是概要申报回执的另一个名称 |
| 一次录入 | 两步申报时一次完整录入报关单105项数据的方式 | 不代表省略两步申报，也不据项数补造尚未定义的字段 |
| 整合申报 | 将报关、报检项目整合于一张报关单录入的方式 | 与两步申报、一次录入分别表达其所属维度 |
| 大包号 | 大箱号、总包号的同义名，标识小包裹统一发往货站的批次 | 与小包裹号、总运单号区分；用于BC出口分组及申报关联 |

“代理报关、单证报关”的材料分工维度与[受控业务术语](#doc-7A3D9E1F50-domain-values)按出口资格、抬头划分的维度未统一：在[普货关务作业](../PRD.高捷物流系统.第2册.订单管理/PRD.高捷物流系统.第027篇.普货关务作业.367A5605ED.md#doc-367A5605ED-scope)中，代理报关指客户提供装箱单、关务制作报关单及发票合同；单证报关指客户提供装箱单、发票、合同及报关单草单。二者与既有术语的映射待确认，不互相覆盖。

### 7.2 保税监管业务模式

| 模式或区域 | 稳定含义 |
| --- | --- |
| BBC | 商品从境外进入保税仓，在保税监管下存储并按实际进出区业务办理申报 |
| 一线、二线、区内 | 一线为境外与监管区域的国境边界；二线为监管区域与境内其他区域的边界；区内为该监管区域内部 |
| 一线进境 | 商品从境外进入保税监管区域 |
| 包裹出区 | 商品以包裹形式从保税区进入境内消费者履约环节 |
| 区间调拨 | 商品在不同保税区之间调拨 |
| 区内调拨 | 商品在同一保税区内流转 |
| 简单加工 | 商品在保税仓内简单组合等加工后申报的业务，如销售组套 |
| 保税展示 | 商品离开保税区用于展示，并在展示后返区的业务 |
| 物料进区 | 库内作业包材或其他必需物料进入保税仓的业务 |
| 废料出区 | 商品产生的废料运出保税仓的业务 |

各模式的单证组合、核放、实物库存与账册库存变动见[BBC进口关务](../PRD.高捷物流系统.第2册.订单管理/PRD.高捷物流系统.第030篇.BBC进口关务.2CA9B1E5A1.md#doc-2CA9B1E5A1-scope)。退运、客退、消退的关系采用[逆向单据定义](#doc-7A3D9E1F50-reverse-order-concepts)。

### 7.3 关务实体与状态维度

| 实体或属性 | 业务含义 | 稳定关系或区别 |
| --- | --- | --- |
| 关务服务单 | 订单关务需求的受理、办理和反馈对象 | 关联上游订单、分单、服务项、办理人及业务类型；服务状态不同于单证申报状态 |
| 报关单 | 进出口货物向海关申报的单证 | 关联服务单、收发货人、运输与商品信息；平台编号与海关编号分别保留 |
| 备案清单 | 保税业务中按适用模式形成的备案单证 | 与报关单、核注清单分开，不根据列表合并展示将它们视为同一单证 |
| 海关账册 | 保税监管商品及其账册库存的归属对象 | 通过账册编号关联商品料号和核注清单；不同账册不能只按商品条码合并余额 |
| 核注清单 | 与海关账册关联、记载核注商品及数量的单证 | 一张核注清单属于一个账册，商品通过对应账册料号关联 |
| 核放单 | 记录货物进出监管区域核放业务的单证 | 按核放类型、绑定类型关联核注清单、业务申报表、进出库单或其他适用单证；不替代所绑定单证 |
| 业务申报表 | 按保税业务模式申报业务事项的单证 | 与核放单、核注清单及进出库单按场景关联，不把名称中的“申报”解释为报关单 |
| 进出库单 | 保税进出库货物及其对应作业的单证 | 与WMS作业单、核放单保持关联，各自编号和结果分别记录 |
| 平台单据状态 | 单据在平台中的创建、发送等处理结果 | 不等同于海关审核状态；改单产生的新旧单据关联由业务场景定义 |
| 海关审核状态 | 海关对对应申报单据返回的审核结果 | 订单、运单、清单以及其他申报单据分别记录，不以一张单据结果覆盖另一张 |
| 卡口状态 | 货物在监管卡口的验放或通行结果 | 与平台状态、海关审核状态并列，不把审核通过等同于已过卡 |
| WMS库存 | 仓储系统记录的实物及作业库存 | 与海关账册库存分别核对，不因申报成功直接认定实物已经出入库 |
| 海关账册库存 | 以账册及商品料号等监管维度记录的数量 | 与仓内实物库存不是同一余额；扣减、恢复、异步差异处理见关务及仓储正文 |

## 8. 仓库模型与库存实体


<a id="doc-7A3D9E1F50-warehouse-service-concepts"></a>
### 8.1 仓储模式、单号与批次

| 实体或概念 | 业务含义 | 稳定关系或区别 |
| --- | --- | --- |
| 集货 | 货物集中接收后整批出库申报的业务模式，不按备货模式理货上架 | 仍可形成集货理货与交接记录，不能把“不理货上架”解释为不清点货物 |
| 备货 | 商品先进入仓库、理货上架，再按后续订单出库的业务模式 | 进口场景涉及海外仓，BBC场景涉及保税仓，具体仓型不由“备货”一词决定 |
| 备货入库、备货出库、集货入库、集货出库 | 仓储服务的四类作业方向与模式组合 | 模式对应的单据、状态及执行方式见[仓储服务模式](../PRD.高捷物流系统.第3册.仓储管理/PRD.高捷物流系统.第034篇.仓库-仓库订单管理.A77FC65070.md#doc-A77FC65070-warehouse-service-modes) |
| 本库入库单号、本库出库单号 | 当前仓库入出库业务记录的标识 | 与上游服务单号、预报单号、客户订单号分别保留，不作为这些标识的同义字段 |
| 揽收、收货交接 | 仓库与司机之间的实物交接 | 收货交接单可关联多个到货批次 |
| 到货批次 | 一次实际到仓批量的记录 | 与收货交接单、商品到货信息关联，不直接等同于理货批次 |
| 理货报告、理货批次、商品理货明细 | 分别记录清点结果报告、一次理货处理批次和逐商品数量等结果 | 备货理货批次与报告的一对一或一对多关系尚未统一，不预设数量关系 |
| 商品批次明细 | 按商品编号与批号区分的库存或入库商品行 | 不以商品ID覆盖批次差异；上架结果还按条码、生产日期、失效日期及批次对应 |
| 上架 | 将已确认的商品实物入库并放至货架的仓储作业 | 形成上架数量及批次结果，不把理货确认本身视为上架完成 |
| 托盘与暂存区 | 托盘承载包裹或委托明细，暂存区记录托盘的暂存位置 | 托盘实体采用[托盘](#doc-7A3D9E1F50-ground-warehouse-entity-pallet)；同托盘可含多服务单明细，单服务单可分托；暂存区不替代物理仓 |
| 下发 | 向仓库传递可执行订单或发货指令的业务动作 | 自动、手动、现货、预售及补货触发规则由订单和仓储场景定义，不合并为一条普适自动规则 |

<a id="doc-7A3D9E1F50-four-level-warehouse"></a>
### 8.2 四层仓与库存视角

| 实体或属性 | 稳定含义 | 关系或标识 |
| --- | --- | --- |
| 物理仓 | 实际仓储空间或WMS库区的业务模型 | 编码为`WLC+5位流水`；可关联多个逻辑仓 |
| 逻辑仓 | 业务单据发生库存异动的仓库模型 | 编码为`LJC+5位流水`；每个逻辑仓只关联一个物理仓 |
| 共享仓 | 对逻辑仓库存进行共享映射的库存视图 | 不额外增加实物库存；与渠道仓可多对多关联 |
| 渠道仓 | 向渠道提供供货库存的库存视图 | 平台店铺与渠道仓一对一关联；共享仓、渠道仓及分配策略编码前缀待统一 |
| 实际库存 | 当前仓储账中已形成的商品库存 | 区分仓、货主、商品及批次等适用维度 |
| 锁定库存 | 因订单或其他业务而被占用的数量 | 不同于已经实物出库的数量 |
| 在途库存 | 已形成入出库安排但尚未完成相应实物交接的数量视角 | 入途与出途的触发、结转和公式见库存业务正文 |
| 可用库存 | 按业务规则可供后续订单使用的数量 | 不直接等于实际库存，不在字典重复计算公式 |
| 不良品库存 | 以质量属性区分的库存数量 | 与可正常供货库存分别记录 |
| 可分配可用库存、可分配不良品库存 | 可以进入共享、渠道等分配关系的对应质量库存 | 分配不创造额外实物；数量校验、转移和恢复规则见库存业务正文 |
| 库存分配策略 | 逻辑、共享、渠道库存之间的分配依据 | 策略与被分配仓、商品及数量关联；不以渠道展示数量替代物理仓余额 |

四层仓配置、计算公式和库存异动由[仓库模型与库存管理](../PRD.高捷物流系统.第3册.仓储管理/PRD.高捷物流系统.第035篇.仓库模型与库存管理.B73CA2EE76.md#doc-B73CA2EE76-warehouse-model)统一定义。

### 13.11 客户数据交接的对象身份

| 对象或标识 | 稳定含义 | 关系边界 |
| --- | --- | --- |
| 字节物流订单号、小包 | 客户小包的识别号及其清关、履约资料 | 与高捷出口订单号、面单号分别保存；同一SKU可有多条商品行，不以SKU相同合并 |
| 大包号、配载预报 | 客户大包标识及所含小包、重量、尺寸和揽收信息 | 对象组成由预报提供；小包与大包、大包与主提单跨运输段的唯一归属尚需确认 |
| 主提单、分提单与配载关系 | 运输集合标识及其与大包的关联 | 主提单配载回传承载完整大包集合，分提单可关联大包；不把一次回传理解为新增大包的增量清单 |
| 揽收状态、操作发送状态、绑定状态 | 分别表示实物揽收结果、资料发送结果、订单关联结果 | 三个维度独立；发送成功不表示揽收正常，绑定失败也不等同于解绑成功 |
| 客户节点事件 | 指定大包、小包或提单在实际发生时刻的履约事实 | 对象维度、事件时间及客户节点代码分别保留；实际发生时间不是接口调用时间 |
| 接口结果码、请求定位号 | 分别表达合作方处理结果及该请求的查询标识 | 错误文案不替代结果码；请求定位号不作为业务订单或申报单号 |
| 平台商品ID、中台商品ID、OUTERID | 客户平台商品、内部商品与客户订单交接字段的标识 | BBC与BC的OUTERID来源不同，通过平台商品对照关联，不默认为同一编码 |
| 跨系统订单接管关系 | 原OMS订单与接管系统对应业务对象的关系 | 标识用于区分实际处理归属；历史切换日期不构成永久订单属性或统一迁移条件 |

各接口的完整字段、单位、格式、签名约定、代码值和回传结果由[客户接口与数据交接](../PRD.高捷物流系统.第2册.订单管理/PRD.高捷物流系统.第032篇.客户接口与数据交接.58EB46CA94.md#doc-58EB46CA94-scope)维护。字节、拼多多与LemonBox的接口不是同一契约；不按相同字段名称或接口序号混用。
