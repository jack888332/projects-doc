### 1.1 结算业务范围、角色与流程

<a id="doc-C548DF1D48-section-75defc8db964"></a>
#### 1.1.1 产品整体描述

此文档主要描述结算中心的应用层财务结算的操作页面和字段展示。

财务作为业务中台之一，其在高捷的业务域包括：订单成本、结算对账、收付款申请、销项票管理、收付款核销。

财务结算模块内容为业务部门和财务部门共同使用。有：订单成本维护、调整单维护、结算成本审批、结算费用查询；应付对账单维护、应付对账单审批、应收对账单维护、应收对账单审批、对账单查询；付款申请维护、付款申请审批、收款申请维护、收款申请审批、收付款申请查询；销项发票申请、手工发票补录、开票申请查询；付款核销、付款核销打回、收款核销、收款核销打回、收付款核销查询。

<a id="doc-C548DF1D48-section-507c65157b68"></a>
#### 1.2.7 付款申请审批

（1）付款申请审批界面

付款申请列表原型界面，点击“审批”按钮，跳转“付款申请审批”页面。只有“已提交”状态的付款申请才具备审批按钮。

（2）按钮说明

- 返回：取消审批，返回“付款申请列表”界面。

- 审批通过：该付款申请的审批通过，返回“付款申请列表”界面。如果是业务员审批通过的，该付款申请批次号的状态变为“业务审批通过”；如果是财务人员审批通过的，该付款申请批次号的状态变为“财务审批通过”。

- 审批拒绝：该付款申请的审批拒绝，返回“付款申请列表”界面。如果是业务员审批拒绝的，该付款申请批次号的状态变为“业务审批拒绝”；如果是财务人员审批拒绝的，该付款申请批次号的状态变为“财务审批拒绝”。

#### 1.2.29 收款申请新增原型

（1）收款新增界面

（2）按钮说明

- 保存：保存该收款申请，弹出“保存确认”弹框。

保存校验：

①明细信息的“结算单位”、“币种”是否相同，不同则无法保存成功；

②校验必填字段是否填写，若未填写，点击保存时无法保存；

③需校验本次申请金额(原币)≤可申请金额；

③若总金额原币＞0，则本次申请金额原币＞0。

- 保存并提交：保存并提交该收款申请，弹出“提交确认”弹框。

保存并提交校验：需要进行保存校验。

- 返回：取消该收款申请，返回“待收款申请列表”界面。

- 附件上传：可上传附件，图片、文档、PDF，限制大小为20M。

- (收款账户信息)保存：保存维护的收款账号信息。

#### 1.2.32 业务规则说明

| 场景名称 | 收款申请管理-收款申请新增 |
| --- | --- |
| 范围/概述 | 勾选对应客户的结算明细数据，填写备注、选择收款账户，上传附件，完成收款申请新增 |
| 主要参与者 | 财务会计 |
| 前置条件 | 进入收款申请管理-> 收款申请列表，进入“待申请列表”页面；<br>选择结算数据，点击“创建”进入此页面 |
| 业务结果 | 页面操作功能可正常使用，输入符合格式和规则校验，可成功提交或提示输入错误。<br>保存后的数据在收款申请列表界面能够查看到，可进行查看、提交、删除操作；<br>保存并提交后的数据，在收款申请列表界面能够查看到，可进行查看、审批操作。 |
| 主业务流程 | 勾选“勾选界面明细”数据，进入收款申请新增页面，分别输入：备注、收款账号、本次申请金额(原币)。<br>1. 备注：<br>- 非必填；<br>- 文本格式，手工录入备注；<br>- 未保存前，可修改备注。<br>1. 附件上传<br>- 非必填；<br>- 超链接，手工上传附件（图片、文档、PDF，限制大小为20M）；<br>- 未保存前，可删除重新上传附件。<br>1. 收款账号：<br>- 非必填；<br>- 字符格式，LOV选择，LOV展示3列（收款账号、收款银行、收款账户名称）；<br>- 未保存前，可修改银行，可选择空值。<br>1. 本次申请金额(原币)：<br>- 必填；<br>- 数字格式，默认等于“可申请金额(原币)”；<br>- 未保存前，可修改本次申请金额(原币)。<br>每页显示50行明细数据，支持翻页查看明细数据。<br>点击“保存”进行提交保存，弹出保存确认弹框。<br>- 确认：一闪而过的提示语“保存成功”，跳转到“待收款申请列表”界面，该收款申请状态变为“新建”。<br>- 无法提交：若必填项未输入，则该输入项红色highlight提醒，保存按钮置灰不可点击。若本次申请金额(原币)>可申请金额(原币)，也无法保存成功。<br>- 取消保存，调整至“收款申请新增”界面，再次编辑收款申请。<br>点击“保存并提交”进行提交保存，弹出提交确认弹框。<br>- 确认：一闪而过的提示语“提交成功”，跳转到“待收款申请列表”界面，该收款申请状态变为“已提交”。<br>- 无法提交：若必填项未输入，则该输入项红色highlight提醒，保存按钮置灰不可点击。若本次申请金额(原币)>可申请金额(原币)，也无法保存成功。<br>- 取消提交，调整至“收款申请新增”界面，再次编辑收款申请。 |
| 业务分支 | 收款申请保存后，可进行查看、删除、提交审批操作；<br>收款申请提交后，可进行查看、审批操作。 |
| 特殊需求 | 相同的结算单位、相同的币种，才能够创建收款申请。 |
| 关联功能 | 1.收款申请列表；<br>2.收款核销。 |
