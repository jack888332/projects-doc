## 10. 建议开发拆分

| 开发包 | 内容 | 可并行条件 |
| --- | --- | --- |
| A | 返款主表、币种汇总、查询和状态 API | P0-0 完成后可开始 |
| B | 返款页面真实接口联调 | A 的 DTO 和接口冻结后 |
| C | `CodRefundBillTypeStrategy` 和签收返款生成 | P0-1 完成后 |
| D | 实际回款流水、分配和未回款风险 | 数据源口径确认后，可与 A 并行 |
| E | 返款打款和结清 | A 完成后，可与 C/D 并行 |
| F | 调账、对账和报表 | C/D/E 稳定后 |

推荐首个可交付版本：

```text
P0-0 + P0-1 + P1 + P2 + P4
```

该版本先支持签收返款的账单生成、复核、返款打款和结清；回款返款、未回款风险和复杂资金对账在 P3/P5 接入。若实际回款数据源已经稳定，也可以将 P3 与 P2 并行实施。
