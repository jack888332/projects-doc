## 2. 工作台共用展示规则

<a id="doc-279CFF369E-role-task-list-common"></a>
### 2.1 角色待办统计与任务列表

本节适用于空运、航晟物流及财务结算各角色的工作台；各角色的任务范围和快捷入口由对应场景定义。

**界面原型概述 · 待办统计与任务列表**

- **区域字段或业务元素**：总待办、待办任务进度条、我的待办最近更新时间；待办任务概览包含编号、任务类型、详情、时间、发起人、立即处理。
- **区域级通用规则**：统计与列表按[工作台数据范围](PRD.高捷物流系统.第064篇.角色与访问权限.5E31456F30.md#doc-5E31456F30-workspace-scope)展示；点击“立即处理”进入该任务规定的业务页面。

| 字段或控件特例 | 适用条件 | 界面特例或可见反馈 |
| --- | --- | --- |
| 总待办 | 展示待办统计时 | 显示全部未处理任务的数量。 |
| 待办任务进度条 | 展示待办统计时 | 进度比例=未处理任务数/（已处理任务数+未处理任务数）。 |
| 我的待办最近更新时间 | 待办任务进度条变化时 | 显示进度条最后一次变化的时间。 |
| 待办任务概览 | 展示待办列表时 | 按任务创建时间升序展示全部未处理任务，每页最多20条。 |

<a id="doc-279CFF369E-department-display-common"></a>
### 2.2 部门统计周期与自定义显示

工作进展使用以下统计周期；工作进展和每日待办共用自定义显示规则。各部门的指标、取值集合和跳转目标见各部门场景。

选择统计周期：默认是本月，可选择今天、本周、本月、本年

自定义显示：点击后弹出界面，可自定义内容显示和上下移动排序。

至少保留一个，当关闭最后一个显示项时，弹出提示：至少要展示一个数据项。

<a id="doc-279CFF369E-account-message-common"></a>
### 2.3 当前账号消息展示

展示当前账号收到的消息通知，未读用红点标志，已读则不再显示红点。

查看更多：点击后跳转到消息中心首页。

消息标题：点击后跳转到消息详情页。

<a id="doc-279CFF369E-wechat-message-common"></a>
### 2.4 企业微信消息展示

适用于空运客服、空运客服主管、航线运营、航线操作、亏损审批角色、航晟卡车部及财务结算工作台。
