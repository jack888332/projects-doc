#### 1.2.5 逆向流程节点说明

| --- | --- | --- | --- |
|  | 普货退货管理 | 普货整批货退货，重新入库，则按照新的入库流程执行。 |  |

#### 1.3.3 业务规则说明

| 场景名称 | 创建仓库订单 |
| --- | --- |
| 范围/概述 | 录入创建仓库订单的信息。 |
| 主要参与者 | 高捷物流-空运事业部或航晟物流-客服部 |
| 前置条件 | 从空运系统模块的“创建仓库订单”按钮进入 |
| 业务结果 | 对输入信息进行输入校验 |
| 主业务流程 | 1. 按照“字段定义”中的规则校验输入内容的必填项和输入类型长度，若不符合输入要求，则输入框直接highlight，“提交”按钮置灰不可点击。<br>1. 对输入的“入仓号”进行仓库订单数据的重复性校验，如当前已存在，则系统提示“您创建的入仓号已存在，请重新输入！”<br>1. 客户订单号：由创建者手动录入，进行去重校验。系统并按照生成规则自动生成一个相应的入仓号（仓库订单号），此类入仓号的编码规则要能够体现是外部独立客户的仓库订单。<br>- 仓库代码+YYMMDD（6位）+4位流水；<br>- 比如：WH0012012170001<br>参考《编码规则》文档；<br>1. 如果是空运事业部录入的订单，则在仓库订单管理页面的该订单记录显示客户为“高捷物流-空运部”（全称）。若是航晟物流-客服部录入的订单，则在仓库订单管理页面的该订单记录显示客户为“具体所选择的客户全称，如UPS的全称”。 |
| 业务分支 | 修改订单：<br>1. 订单=待入库状态，所有信息可修改；<br>1. 订单=已入库或部分出库状态，除入仓号和客户以外的信息，均可修改；<br>1. 其他订单状态（已出库或已取消），不可修改； |
| 关联功能 | 此创建订单的功能原计划提供给高捷物流-空运部和航晟物流-客服部（通过空运模块功能），进行单独创建仓库订单。创建后：<br>- 委托方信息的特殊处理：如果是航晟物流-客服部创建的仓库订单，譬如其输入的委托方是UPS（全称），则到了“仓库订单管理”的页面管理时，此时显示的委托方仍旧显示为“UPS”（全称）。<br>- 如果是空运过来的仓库订单，则在“仓库订单管理”的页面管理时，此时显示的委托方仍旧显示为“高捷物流集团-空运事业部”（全称，以具体配置的名称为准）。 |
