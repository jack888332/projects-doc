### 1.1 订舱页面交互规则

<a id="doc-6A0360EC35-section-a80402f8cda0"></a>
#### 1.1.1 列表与提交行为

- 订单列表页面，默认分页结构，每页默认10条记录显示。

- 提交订舱信息时显示“提交”“取消”按钮；修改订舱信息时显示“保存”“取消”按钮。

#### 1.3.3 订舱处理与盈利校验规则

| 场景名称 | 订舱管理-订舱 |
| --- | --- |
| 范围/概述 | 填写订舱服务信息，生成订舱业务单据。 |
| 主要参与者 | 空运航线运营、空运航线操作、航晟客服 |
| 前置条件 | 进入订舱管理界面，点击订单状态=“待订舱”的订单。 |
| 业务结果 | 航线运营确认航班后订舱服务变为“服务中”；航线操作或航晟客服完成订舱后，订舱服务变为“服务已完成”，订舱信息同步回订单。 |
| 主业务流程 | 1. 空运航线运营可编辑航程信息和航程补充，操作按钮为“取消”“确认航班”。空运航线操作只能查看航程信息，可编辑航程补充，操作按钮为“取消”“订舱完成”。航晟客服可编辑航程信息和航程补充，操作按钮为“取消”“订舱完成”。<br>2. 航线运营填写后点击“确认航班”，提交订舱信息并同步回客服订单，订舱服务状态变为“服务中”。航线操作填写后点击“订舱完成”，提交订舱信息并同步回客服订单，订舱服务状态变为“服务已完成”。对应通知按[消息推送规则](PRD.高捷物流系统一期.第030篇.消息推送.5F950AB3B1.md#doc-5F950AB3B1-section-ef4930471a81)发送。<br>3. 订单状态为“待订舱”“待补录”或“待出提单”时，航线部可修改除提单属性外的字段，修改结果同步回客服订单；状态为“已出提单”“已交单”“待审核”或“已作废”时不得修改。<br>4. 必填项缺失或输入长度、格式不符合要求时，相应字段高亮提示，“确认航班”“订舱完成”按钮置灰且不可点击。 |
| 关联功能 | 1. 预计盈利校验：航线运营根据当季航司市场成本、客户运费卖价和客户提供的预计毛件体，填写订单实际毛件体的允许区间。货物入仓后取实际毛件体；未选择入仓服务时，由客服手工录入客户再次提供的实际毛件体。实际毛件体不在允许区间内时，订单在客服“主订单管理”列表前置并标红，同时触发异常通知。客服与客户确认后修改毛件体和运费卖价并保存；修改后仍不符合预计盈利规则的，由航线部调整预计盈利规则。补料环节删除分单后，客服须手工修改预计毛件体和入仓毛件体；预计件数与入仓件数不一致且预计毛重与入仓毛重相差超过3%时，触发改单通知。以上通知按[消息推送规则](PRD.高捷物流系统一期.第030篇.消息推送.5F950AB3B1.md#doc-5F950AB3B1-section-ef4930471a81)发送。<br>2. 允许亏损：默认不勾选。不勾选时，空运成本大于运费卖价则禁止提交。勾选后，若空运成本大于运费卖价，且`|(运费卖价-空运成本-0.3)*计费重|<=5000`，提交时弹出航线总监审核确认；提交审核后业务单据和订舱服务状态均变为“待审核”，审核通过后客服主订单状态变为“待补录”。该场景用于合同板未达到基准载重时避免航司惩罚金。<br>3. 航班修改：订单状态为“待补录”或“待出提单”时，航线部可修改航班信息；修改后，订舱服务状态由“服务已完成”变为“服务中”。 |

#### 1.3.5 合成主订单订舱聚合规则

| 场景名称 | 订舱管理-订舱 |
| --- | --- |
| 范围/概述 | 客服发出订舱指令后，航线部在订舱管理页面填写订舱信息。 |
| 主要参与者 | 空运航线部、航晟物流部 |
| 前置条件 | 客服录入补料信息并发出订舱服务指令后，订单进入“待订舱”状态。航线部可点击订单进入订舱页面。 |
| 业务结果 | 航线部可查看合成主订单的聚合信息，并按订舱规则填写和提交订舱信息。 |
| 主业务流程 | 合成主订单使用前述订舱字段和页面规则。航线部看到的数据按以下规则取值：<br>- 订单号：合成后的主订单号。<br>- 客户：展示全部子订单的客户。<br>- 始发港、目的港、航司产品、订舱要求：取客服合成主订单时填写的值。<br>- 中文品名：聚合全部分单的中文品名；每个分单最多显示三个，超过三个时以省略号标识，悬停可查看全部品名。<br>- 特殊货物：聚合全部分单的特殊货物。<br>- 预报毛件体：全部分单毛件体之和。<br>- 预计送货时间：取全部分单中最晚的送货时间。<br>- 运费卖价=`Σ(分单卖价*分单收客户重量)/Σ分单收客户重量`。<br>- 后段卡车卖价=`Σ分单卡车总费用/Σ分单提单计费重`。<br>- 卡车总费用=卡车单价*分单计费重。<br>- 分单计费重取`分单体积*166.66`与毛重中的较大值。 |
