### 1.2 产品概述

<a id="doc-45DB5A5118-section-04bf6d0e490f"></a>
#### 1.2.1 产品整体描述

此文档主要描述结算中心的应用层财务结算的操作页面和字段展示。

财务中心作为业务中台之一，其在高捷的业务域包括：订单成本、结算对账、收付款申请、销项票管理、收付款核销。

财务结算模块内容为业务部门和财务部门共同使用。有：订单成本维护、调整单维护、结算成本审批、结算费用查询；应付对账单维护、应付对账单审批、应收对账单维护、应收对账单审批、对账单查询；付款申请维护、付款申请审批、收款申请维护、收款申请审批、收付款申请查询；销项发票申请、手工发票补录、开票申请查询；付款核销、付款核销打回、收款核销、收款核销打回、收付款核销查询。

| 场景名称 | 付款核销申请管理-付款核销申请新增 |

#### 1.3.28 收款核销业务规则说明

| 场景名称 | 收款核销申请管理-收款核销申请新增 |
| --- | --- |
| 范围/概述 | 勾选对应的财务审批通过的收款申请信息，选择收款账户、收款日期，填写实际收款金额、本次核销金额（原币）完成收款核销申请新增 |
| 主要参与者 | 财务会计 |
| 前置条件 | 进入收款核销-> 收款核销申请列表，进入“待收款核销申请列表”页面；<br>选择结算数据，点击“创建”进入此页面 |
| 业务结果 | 页面操作功能可正常使用，输入符合格式和规则校验，可成功提交或提示输入错误。<br>保存后的数据在收款核销申请列表界面能够查看到，可进行查看、提交、删除操作；<br>保存并提交后的数据，在收款核销申请列表界面能够查看到，可进行查看、审批操作。 |
| 主业务流程 | 勾选“结算明细”数据，进入收款核销申请新增页面，分别输入：是否代收、选择收款银行账号、收款日期，填写实际收款金额、本次核销金额（原币）。<br>选择是否代收：<br>- 非必填，勾选，默认为“不勾选”；<br>- 未保存前，可修改；<br>- 勾选“是否代收”后，则收款单位必填；取消勾选“是否代收”后，则收款单位置空。<br>收款账号：<br>- 必填；LOV选择，根据在基本信息-银行账号录入的信息自动带出，下拉框选择；<br>- 未保存前，可修改。<br>收款日期：<br>- 必填；日期格式；<br>- 未保存前，可修改。<br>实际收款金额：<br>- 必填；文本格式；<br>- 未保存前，可修改。<br>本次收销金额（原币）：<br>- 必填；文本格式；<br>- 未保存前，可修改。<br>点击“保存”进行提交保存，弹出保存确认弹框。<br>- 确认：一闪而过的提示语“保存成功”，跳转到“待收款核销申请列表”界面，该收款核销申请状态变为“新建”。<br>- 无法提交：若必填项未输入，则该输入项红色highlight提醒，保存按钮置灰不可点击<br>- 取消保存，跳转至“收款核销申请新增”界面，再次编辑收款核销申请。<br>点击“保存并提交”进行提交保存，弹出提交确认弹框。<br>- 确认：一闪而过的提示语“提交成功”，跳转到“待收款核销申请列表”界面，该收款核销申请状态变为“已提交”。<br>- 无法提交：若必填项未输入，则该输入项红色highlight提醒，保存按钮置灰不可点击。<br>- 取消提交，跳转至“收款核销申请新增”界面，再次编辑收款申请。 |
| 业务分支 | 收款核销申请保存后，可进行查看、删除、提交操作；<br>收款核销申请提交后，可进行查看、打回操作。 |
| 特殊需求 | 相同的结算单位、相同的币种，才能够创建收款核销申请。 |
