### 1.1 页面交互规则

<a id="doc-32C78B8106-section-38a2067ce1cc"></a>
#### 1.1.1 通用页面行为

- 订单列表默认分页显示，每页 50 条记录。

- 创建订单时提供“提交”和“取消”按钮；修改订单时提供“保存”和“取消”按钮。

- 提交成功后，页面短暂显示“已提交成功！”。

- 输入内容不符合格式要求或必填项为空时，对应输入项高亮提示，“提交”和“保存”按钮置灰且不可点击。

#### 1.3.3 业务规则说明

| 场景名称 | 用车订单管理-新建用车订单 |
| --- | --- |
| 范围/概述 | 输入订单信息，提交订单 |
| 主要参与者 | 航晟客服 |
| 前置条件 | 进入订单管理页面，点击《新建订单》按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，输入符合格式和规则校验，可成功提交或提示输入错误。 |
| 主业务流程 | 进入《新建订单》页面，分别输入：委托方信息、货物信息、提货信息和送货信息。<br>1. 委托方信息：<br>- 委托方的可选对象必须取自合作方档案管理中的合作公司主体，且与航晟物流的合作关系为“客户”。<br>- 可输入委托方联系人信息，联系人姓名、联系电话和邮箱地址为一个委托方联系人的信息，可支持通过点击“+”输入多个委托人联系人。<br>- 输入的委托方联系人的邮箱地址，将由系统按照订单节点自动发送系统邮件到该邮箱地址。<br>- 委托方联系人信息可下拉选择该合作方档案中的业务联系人信息，也可重新单独全部重新输入。若重新输入，则新输入的委托方联系人信息（姓名、联系方式和邮箱地址）在该订单提交成功后，自动保存自合作方档案管理中的业务联系人信息（新增保存）。<br>1. 货物信息：<br>- 按照字段定义，进行可选输入。<br>- 尺寸需要分成长、宽、高分别对应输入。<br>1. 提货信息：<br>- 期望提货时间，可支持只录入到“天”的日期，也可支持录入到“HH:MM”。<br>- 通过点击“+”，支持输入多个提货地址，新增一行的“提货信息”支持分别录入监管车、特种车和尾板车的信息。<br>其中，新增的提货点/卸货点必须与第一个提货点/卸货点的省市2级保持相同，而区级与详细地址信息可不同。<br>1. 送货信息：<br>- 期望送货时间，可支持只录入到“天”的日期，也可支持录入到“HH:MM”。<br>- 通过点击“+”，支持输入多个送货地址。<br>点击《提交》进行提交保存。<br>- 提交成功：一闪而过的提示语“提交成功”，调转到订单管理页面。<br>- 无法提交：若必填项未输入，或输入长度格式不符合要求，则该输入项红色highlight提醒，《提交》按钮置灰不可点击。 |
| 业务分支 | 报价匹配逻辑：<br>- 若出现多个提货地址或送货地点，则系统默认取第一个提货地点和送货地点进行路线报价的匹配。<br>- 空运与航晟用车的的订单数据，基于API进行交互：<br>- 空运发送用车订单；<br>- 航晟接收后，反馈创建成功或失败的状态；<br>- 创建订单成功后，在订单列表页面上显示的“订单号”都是根据系统编码规则重新生成的订单号：T+101+YYMMDD（6位）+5位流水；（如：T10120121700001）<br>- 需要支持多笔订单带重复的订单号的情况，因为客户可能会对一批货进行多次部分提货。 |
| 特殊需求 | “业务类型”字段：若是上游系统的订单，则约定上游系统明确传值；若是航晟自行创建的用车订单，则需要必选选择。此值主要作用于财务结算。 |
| 关联功能 | 自动接收空运系统擦传输过来的新订单（通过API） |

#### 1.3.7 订单状态定义

| 订单状态 | 状态说明 |
| --- | --- |
| 未调度 | 未曾对该订单录入任何调度信息 |
| 已调度 | 当前订单上有履约中的调度信息，既存在运单状态≠已卸货或已取消的运单。 |
| 已取消 | 订单在“未调度”状态下取消 |
| 已完成 | 该订单中的运单状态全部=已卸货或已取消 |
| 异常中 | 该订单中至少有一个运单状态=异常中 |
