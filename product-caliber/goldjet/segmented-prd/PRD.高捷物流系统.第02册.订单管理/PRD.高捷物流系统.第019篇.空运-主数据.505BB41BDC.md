### 1.2 空运主数据维护功能与规则

<a id="doc-505BB41BDC-section-3880b60e45b6"></a>
#### 1.2.1 航司管理入口与操作

- 航司管理-新增功能，可新增航司。

- 航司管理-查看功能，可查看航司信息。

- 航司管理-编辑功能，可编辑航司。

- 航司管理-删除功能，可删除航司。

- 航司管理-批量删除功能，可批量删除航司。

**界面原型概述 · 航司查询与列表**

- **区域字段或业务元素**：查询栏含航司代码、公司名称、查询；列表含航司代码、公司名称、提单前缀、提单打印抬头、ISSUINGCAR、IATACode、选择、编辑、删除，以及新增、导入入口。
- **区域级通用规则**：按查询条件查看航司资料，列表数据只读，维护操作从对应入口打开。

导入入口保留；模板、重复记录处置及失败反馈尚未定义，不能据入口推定覆盖已有航司信息。

<a id="doc-505BB41BDC-section-331742fd30ad"></a>
#### 1.2.2 航司管理字段

**界面原型概述 · 航司管理**

- **区域字段或业务元素**：航司代码、供应商名称、公司名称、提单前缀、提单打印抬头、ISSUINGCAR、IATACode、AccountNo。
- **区域级通用规则**：字段均可编辑。

| 字段或控件特例 | 界面特例或可见反馈 |
| --- | --- |
| 航司代码 | 航司二字代码。唯一；选填。 |
| 供应商名称 | 支持多选；关联供应商档案。多选；必填。 |
| 公司名称 | 航司全称（中文）。唯一；必填。 |
| 提单前缀 | 3 位数字，用于提单号管理中生成新提单号；不唯一；必填。 |
| 提单打印抬头 | 用于提单制作-提单编辑页面；选填。 |
| ISSUINGCAR | 承运人；选填；默认值：GUANGDONG GOLDJET INT’L LOGISTICS CO.,LTD。 |
| IATACode | 承运人在航司系统中的代码；选填。 |
| AccountNo | 选填。 |

<a id="doc-505BB41BDC-section-6b96b4f94651"></a>
#### 1.2.3 航司新增、删除与编辑规则

航线专员、财务专员在航司管理页面打开新增、编辑或删除弹窗，维护航司代码、供应商名称、公司名称、提单前缀、提单打印抬头、ISSUINGCAR和IATACode。新增用于录入并提交航司信息，编辑用于更新已有信息，删除用于移除该航司基础信息；操作后的返回、刷新与反馈见[主数据提交与删除反馈](#doc-505BB41BDC-master-data-operation-feedback)。

**界面原型概述 · 航司维护弹窗**

- **区域字段或业务元素**：上述航司基础字段、保存、确定、取消。
- **区域级通用规则**：新增、编辑时按航司管理字段约束录入；保存通过校验后提交，删除须在确认弹窗点击“确定”。

**航司校验与下游取值**

- 航司代码、公司名称不允许重复。
- 供应商名称取自供应商档案，允许多选。
- 提单前缀不允许重复，用于识别航司、提单编辑和提单号管理。
- 系统按提单前缀将提单打印抬头带入提单编辑页面。
- ISSUINGCAR（承运人）默认为“GUANGDONG GOLDJET INT’L LOGISTICS CO.,LTD”，显示在对应提单的编辑页面。
- IATACode是承运人在航空公司的代码，用于发送电子提单信息。

#### 1.2.5 空港字段与维护规则

**界面原型概述 · 空港管理**

- **区域字段或业务元素**：三字代码、机场名（中文）、机场名（英文）、国家（英文）、国家代码、城市（英文）、城市代码、洲。
- **区域级通用规则**：字段均必填、可编辑。

| 字段或控件特例 | 界面特例或可见反馈 |
| --- | --- |
| 三字代码、机场名（中文）、机场名（英文） | 唯一。 |
| 洲 | 选项：北美洲、大洋洲、东南亚、东欧、非洲、南美洲、欧洲、亚洲、中东。 |

公布运价按机场三字代码展示 -45、+45、+100、+300、+500 及 M 档位；各档位与提单计价的取值关系仍待确认，不把示例价格作为固定价格。

**界面原型概述 · 空港查询与列表**

- **区域字段或业务元素**：查询栏含三字代码、机场名、查询；列表含三字代码、机场名（中文）、机场名（英文）、国家（英文）、国家代码、城市（英文）、城市代码、洲、选择、编辑、删除，以及新增、导入入口。
- **区域级通用规则**：按查询条件查看空港资料，列表数据只读；导入模板、重复记录处置及失败反馈仍待确认。

**空港新增、删除与编辑规则**

航线专员在空港管理页面打开新增、编辑或删除弹窗，维护三字代码、机场名（中文）、机场名（英文）、国家（英文）、城市（英文）和洲。新增用于录入并提交空港信息，编辑用于更新已有信息，删除用于移除该空港基础信息；操作后的返回、刷新与反馈见[主数据提交与删除反馈](#doc-505BB41BDC-master-data-operation-feedback)。

**界面原型概述 · 空港维护弹窗**

- **区域字段或业务元素**：上述空港基础字段、国家代码、城市代码、保存、确定、取消。
- **区域级通用规则**：新增、编辑时按空港管理字段约束录入；保存通过校验后提交，删除须在确认弹窗点击“确定”。

| 字段或控件特例 | 适用条件 | 界面特例或可见反馈 |
| --- | --- | --- |
| 国家（英文）、城市（英文） | 新增空港时 | 从候选项中选择。 |

新增时，三字代码、机场名（中文）和机场名（英文）均不允许重复。

| 字段或控件 | 个别界面约束或可见反馈 |

| 到达时间 | 常见取值为 0 或 1。 |
| 截单天数 | 常见取值为 -1 或 0；必填；可编辑。 |
| 飞机类型 | 选项：货机、客机；必填；可编辑。 |

**界面原型概述 · 航班号维护弹窗**

- **区域级通用规则**：新增、编辑时按航班号管理字段约束录入；保存通过校验后提交，删除须在确认弹窗点击“确定”。

| 字段或控件特例 | 适用条件 | 界面特例或可见反馈 |

#### 1.2.7 板型管理字段与维护规则

- 板型管理-新增功能，可新增板型。

- 板型管理-编辑功能，可编辑板型信息。

- 板型管理-删除功能，可删除板型。

**界面原型概述 · 板型查询与列表**

- **区域字段或业务元素**：查询栏含航司代码、机型、板型、板型别称、体积、查询；结果区列表含航司代码、飞机类型、板型、别称、体积（m³）、板型尺寸、限重、选择、编辑，以及新增、导入、批量删除入口。
- **区域级通用规则**：按查询条件查看板型资料，列表数据只读；导入模板、重复记录处置及失败反馈仍待确认。

查询项“机型”与维护项“飞机类型”的映射，以及板型尺寸截图的厘米标注与下述米单位之间的关系仍待确认，不作自动换算。

**界面原型概述 · 板型管理**

- **区域字段或业务元素**：航司代码、飞机类型、板型、别称、体积、板型尺寸、限重。
- **区域级通用规则**：除所列特例外，字段均必填、可编辑。

| 字段或控件特例 | 界面特例或可见反馈 |
| --- | --- |
| 航司代码 | 取自主数据-航司管理的航司代码。 |
| 飞机类型 | 选项：货机、客机。 |
| 板型 | 唯一。 |
| 别称 | 手工录入；选填。 |
| 板型尺寸 | 长×高×宽，单位：m。 |
| 限重 | 单位：t。 |

**板型新增、删除与编辑规则**

航线专员在板型管理页面打开新增或编辑弹窗，维护航司代码、飞机类型、板型、别称、体积、板型尺寸和限重。新增用于录入并提交板型信息，编辑用于更新已有信息；删除时先勾选目标板型，再点击“批量删除”打开确认弹窗。操作后的返回、刷新与反馈见[主数据提交与删除反馈](#doc-505BB41BDC-master-data-operation-feedback)。

**界面原型概述 · 板型维护弹窗**

- **区域字段或业务元素**：上述板型基础字段、保存、批量删除、确定、取消。
- **区域级通用规则**：新增、编辑时按板型管理字段约束录入；保存通过校验后提交，批量删除须在确认弹窗点击“确定”。

航司和机型从候选项中选择，航司取自航司主数据。板型和体积供配板管理使用；板型尺寸用于判断货物是否过长。

<a id="doc-505BB41BDC-master-data-operation-feedback"></a>
#### 1.2.8 主数据提交与删除反馈

本节适用于航司、空港、航班号和板型维护，操作完成后返回对应的主数据管理页面。

| 操作 | 条件 | 业务结果与界面反馈 |
| --- | --- | --- |
| 新增保存 | 必填项及业务格式校验通过 | 新增对应主数据，提示“提交成功”，关闭弹窗并返回管理页面。 |
| 新增保存 | 必填项未输入或业务格式不符合要求 | 不提交；错误输入项高亮，“保存”按钮置灰且不可点击。 |
| 编辑保存 | 必填项及格式校验通过 | 保存修改，提示“提交修改成功”，关闭弹窗并返回管理页面。 |
| 编辑保存 | 航司、空港、航班号的必填项未输入或输入长度格式不符合要求 | 不提交；错误输入项红色高亮，“保存”按钮置灰且不可点击。 |
| 编辑保存 | 板型的必填项未输入或业务格式不符合要求 | 不提交；错误输入项高亮，“保存”按钮置灰且不可点击。 |
| 删除确认 | 在删除弹窗点击“确定” | 删除对应主数据，提示“删除成功”，关闭弹窗并刷新管理页面。 |
| 删除取消 | 在删除弹窗点击“取消” | 不删除；关闭弹窗并返回管理页面。 |
