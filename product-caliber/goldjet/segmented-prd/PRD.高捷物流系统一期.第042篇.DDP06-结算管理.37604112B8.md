### 1.1 航晟物流：结算管理的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 运单详情管理 | 航晟物流 | 基于运单维度，进行应收付账单的结算管理。 | 2 |  |
| 2 | 已调度？ | 航晟物流 | 判断该订单是否已完成调度？ | 1或3 |  |
| 3 | 3.根据报价管理算出默认应收<br>（空运要看其应付） | 航晟物流 | 若订单已调度，则系统根据供应商报价和对客户的报价信息生成默认的应收账单。 | 6 | 是 |
| 4 | 运单执行 | 司机 | 司机执行运输任务，可通过小程序反馈状态。 | 5 |  |
| 5 | 其他杂费上报 | 司机 | 司机可上报其他停车费、清关费等杂费。 | 8 |  |
| 6 | 审核上报杂费 | 航晟物流 | 航晟对司机上报的各类杂费进行审核。 | 7 |  |
| 7 | 生成杂费应收付记录 | 航晟物流 | 审核通过，生成相应科目的应收付记录。 | 9 |  |
| 8 | 确认卸货完成 | 司机 | 司机在小程序上确认卸货已完成 | 9 |  |
| 9 | 生成运费的应付账单 | 航晟物流 | 生成运费的应付账单科目项。 | 10 |  |
| 10 | 应收付手动调整 | 航晟物流 | 若仍有其他待补充或修改的科目，航晟仍可在后台进行补充和修改录入。 | 11 |  |
| 11 | 导出账单 | 航晟物流 | 支持对单条账单进行导出应收或应付账单，也可以支持对多条账单一次性导出应付账单或应收账单。 |  |  |

#### 1.1.2 关键控制点

| 所属步骤 | 关键控制点描述 |
| --- | --- |
| 3 | 根据供应商和客户的报价标准，对订单生成默认的账单数据：<br>1. 直接调取提货费或者根据单价*重量（与最小收费对比）来算出提货费；<br>1. 提货费*车辆数量（累加）算出总提货费；<br>1. 应收和应付账单中的车型可能不一致，需要提供手动支持修改调整车型标准的功能；<br>1. 支持手动录入各类杂费；<br>1. 司机反馈的候时和压车数据将反映到应收付账单中；<br>1. 应收付账单的对象主体需要全称显示； |
