## 1. 航晟用车订单


**业务入口：** [用车调度](http://localhost:10530/#/fulfillment/ground-dispatch)

**字段定义：** [数据字典 · 地面运输、车队、司机端、仓库与货站字段](PRD.高捷物流系统一期.第050篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-ground-business)


### 1.1 业务范围、菜单与角色

<a id="doc-1A065EB637-section-653c26e251a8"></a>
#### 1.1.1 业务目标与范围

航晟用车订单管理覆盖提货订单和中转订单的创建、修改与查询。

<a id="doc-1A065EB637-section-e65693934469"></a>
#### 1.1.2 操作入口

| 系统 | 一级菜单 | 二级菜单 | 说明 |
| --- | --- | --- | --- |
| 航晟物流工作台 | 用车订单管理 | 提货订单 | 展示除中转仓订单以外的订单，此部分订单需要客服调度操作。 |
|  |  | 中转订单 | 特定展示中转仓订单的类型，此部分订单不需要客服人员手动调度。 |

<a id="doc-1A065EB637-section-89bdc38b8a84"></a>

### 1.2 航晟用车订单功能与规则

<a id="doc-1A065EB637-section-a81261da4ae2"></a>

- 订单创建页面，可创建各客户的用车订单。

<a id="doc-1A065EB637-section-b944f3a8b31d"></a>
#### 1.2.2 字段定义

字段定义见 [数据字典 · 航晟用车订单创建字段](PRD.高捷物流系统一期.第050篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-024-001)。

<a id="doc-1A065EB637-section-0e415fa42290"></a>
#### 1.2.3 业务规则说明

| 场景名称 | 用车订单管理-新建用车订单 |
| --- | --- |
| 范围/概述 | 输入订单信息，提交订单 |
| 主要参与者 | 航晟客服 |
| 前置条件 | 进入订单管理页面，点击《新建订单》按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，输入符合格式和规则校验，可成功提交或提升输入错误。 |
| 主业务流程 | 进入《新建订单》页面，分别输入：委托方信息、货物信息、提货信息和送货信息。<br>1. 委托方信息：<br>- 委托方的可选对象必须取自合作方档案管理中的合作公司主体，且与航晟物流的合作关系为“客户”。<br>- 可输入委托方联系人信息，联系人姓名、联系电话和邮箱地址为一个委托方联系人的信息，可支持通过点击“+”输入多个委托人联系人。<br>- 输入的委托方联系人的邮箱地址，将由系统按照订单节点自动发送系统邮件到该邮箱地址。<br>- 委托方联系人信息可下拉选择该合作方档案中的业务联系人信息，也可重新单独全部重新输入。若重新输入，则新输入的委托方联系人信息（姓名、联系方式和邮箱地址）在该订单提交成功后，自动保存自合作方档案管理中的业务联系人信息（新增保存）。<br>1. 货物信息：<br>- 按照字段定义，进行可选输入。<br>- 尺寸需要分成长、宽、高分别对应输入。<br>1. 提货信息：<br>- 期望提货时间，可支持只录入到“天”的日期，也可支持录入到“HH:MM”。<br>- 通过点击“+”，支持输入多个提货地址。<br>1. 送货信息：<br>- 期望送货时间，可支持只录入到“天”的日期，也可支持录入到“HH:MM”。<br>- 通过点击“+”，支持输入多个送货地址。<br>点击《提交》进行提交保存。<br>- 提交成功：一闪而过的提示语“提交成功”，调转到订单管理页面。<br>- 无法提交：若必填项未输入，或输入长度格式不符合要求，则该输入项红色highlight提醒，《提交》按钮置灰不可点击。 |
| 业务分支 | 报价匹配逻辑：<br>- 若出现多个提货地址或送货地点，则系统默认取第一个提货地点和送货地点进行路线报价的匹配。<br>空运与航晟用车的的订单数据，基于API进行交互：<br>1. 空运发送用车订单；<br>1. 航晟接收后，反馈创建成功或失败的状态； |
| 关联功能 | 自动同步空运新订单（通过API） |
