## 1. 航晟用车订单


**业务入口：** 用车调度页面。

**字段定义：** [数据字典 · 地面运输、车队、司机端、仓库与货站字段](PRD.高捷物流系统一期.第049篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-ground-business)


### 1.1 业务范围、菜单与角色

<a id="doc-1A065EB637-section-653c26e251a8"></a>
#### 1.1.1 业务目标与范围

航晟用车订单管理覆盖提货订单和中转订单的创建、修改与查询。

<a id="doc-1A065EB637-section-e65693934469"></a>
#### 1.1.2 操作入口

| 系统 | 一级菜单 | 二级菜单 | 说明 |
| --- | --- | --- | --- |
| 航晟物流工作台 | 用车订单管理 | 提货订单 | 展示除中转仓订单以外的订单，此部分订单需要客服调度操作。 |
|  |  | 中转订单 | 特定展示中转仓订单的类型，此部分订单不需要客服人员手动调度。 |

<a id="doc-1A065EB637-section-89bdc38b8a84"></a>
#### 1.1.3 受控术语

<a id="doc-1A065EB637-section-0e415fa42290"></a>
#### 1.2.3 订单创建规则

| 场景名称 | 用车订单管理-新建用车订单 |
| --- | --- |
| 范围/概述 | 输入订单信息，提交订单 |
| 主要参与者 | 航晟客服 |
| 前置条件 | 进入订单管理页面，点击《新建订单》按钮，进入此页面 |
| 业务结果 | 输入符合格式与校验规则时成功提交；不符合时提示输入错误。 |
| 主业务流程 | 进入《新建订单》页面，分别输入委托方信息、货物信息、提货信息和送货信息。<br>1. 委托方信息：<br>- 委托方的可选对象必须取自合作方档案管理中的合作公司主体，且与航晟物流的合作关系为“客户”。<br>- 可输入委托方联系人信息；每组联系人信息包括姓名、联系电话和邮箱地址，并可通过点击“+”录入多组联系人。<br>- 系统按照订单节点，向委托方联系人邮箱自动发送邮件。<br>- 委托方联系人信息可从该合作方档案的业务联系人中选择，也可完整重新录入。重新录入的联系人姓名、联系方式和邮箱地址在订单提交成功后，自动新增至合作方档案的业务联系人信息。<br>1. 货物信息：<br>- 按照字段定义进行可选输入。<br>- 尺寸需分别录入长、宽、高。<br>1. 提货信息：<br>- 期望提货时间支持仅录入日期，也支持录入至“HH:MM”。<br>- 通过点击“+”，支持输入多个提货地址。<br>1. 送货信息：<br>- 期望送货时间支持仅录入日期，也支持录入至“HH:MM”。<br>- 通过点击“+”，支持输入多个送货地址。<br>点击《提交》保存订单。<br>- 提交成功：显示“提交成功”提示，并跳转到订单管理页面。<br>- 无法提交：若必填项未输入，或输入长度、格式不符合要求，则高亮提示对应输入项，《提交》按钮置灰且不可点击。 |
| 业务分支 | 报价匹配逻辑：<br>- 若出现多个提货地址或送货地点，则系统默认取第一个提货地点和送货地点进行路线报价的匹配。<br>空运与航晟用车的订单数据基于 API 交互：<br>1. 空运发送用车订单。<br>1. 航晟接收后反馈创建成功或失败的状态。 |
| 关联功能 | 自动同步空运新订单（通过API） |
