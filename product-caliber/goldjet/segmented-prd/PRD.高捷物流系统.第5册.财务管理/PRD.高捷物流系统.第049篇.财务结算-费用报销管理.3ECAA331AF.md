### 1.2 报销单据与付款核销

<a id="doc-3ECAA331AF-section-8fa54b98e5f0"></a>
#### 1.2.1 报销列表页面

报销列表页面可搜索和查看“钉钉”推送的费用报销信息，并将数据同步至金蝶；同步失败时允许再次推送。列表数据范围见[财务数据访问范围](../PRD.高捷物流系统.第6册.运营支撑/PRD.高捷物流系统.第062篇.角色与访问权限.5E31456F30.md#doc-5E31456F30-finance-scope)。

**操作与反馈**

- 付款：跳转至“付款编辑”界面。“付款”操作一次只能够勾选一条付款申请数据。

- 核销：跳转至“核销编辑”界面。“核销”操作一次能够勾选多条数据，但是必须都是同个往来单位、承担组织的数据。

- 按勾选导出：勾选数据，导出勾选的数据。

- 按查询条件导出：按照查询条件，导出数据（存在一次导出大量数据的场景）。

- 查询：按填写的条件查询；未设置条件时查询全部记录。查询结果按照“单据编号”倒序排列。

- 重置：重置所有查询条件。

- 查看：跳转至对应的明细页面。如果是“费用报销单”，跳转至“费用报销单明细”界面；如果是“员工借支单”，跳转至“员工借支单明细”界面；如果是“付款退款单”，跳转至“付款退款单明细”界面。

**界面原型概述 · 报销列表查询栏**

- **区域字段或业务元素**：单据编号、单据类型、费用承担组织、费用承担部门、往来单位、申请人、申请日期、申请金额从、申请金额至、付款状态、单据状态、事由、同步金蝶状态。
- **区域级通用规则**：除所列特例外，查询条件均选填、无预设值。

| 字段或控件特例 | 界面特例或可见反馈 |
| --- | --- |
| 单据编号 | 填写单据编号，支持模糊查询。 |
| 单据类型 | 填写单据类型，支持模糊查询。 |
| 费用承担组织 | 可以选择到组织架构内所有的组织。 |
| 费用承担部门 | 可以选择到组织架构内所有的部门。 |
| 往来单位 | 往来单位，支持模糊查询。 |
| 申请人 | 填写申请人，支持模糊查询。 |
| 申请日期 | 日期范围框，支持模糊匹配；不选择则默认全部。 |
| 申请金额从、申请金额至 | 手工录入金额，支持范围查询。 |
| 付款状态 | 选择（全部/未付款/部分付款/已付款）；不选择则默认全部。 |
| 单据状态 | 选择（全部/未结清/已结清）；默认未结清；有默认值。 |

| 同步金蝶状态 | 选择（导入成功/导入失败）；不选择则默认全部。 |
