### 1.3 合作方报价维护功能与规则

<a id="doc-92B1FD526A-section-718819a2bceb"></a>
#### 1.3.1 供应商报价管理

- 供应商报价管理页面，可创建、修改、查看、删除供应商提供的报价。

<a id="doc-92B1FD526A-section-4485691bd328"></a>
#### 1.3.2 供应商报价新增

**操作与反馈**
- 提交：提交时对必填信息、报价信息进行校验，若必填项为空时，则系统提交时会标红提示该错误，并不允许提交；如果报价相同且有效日期重叠，那么提交时失败，并提示“已存在报价，请勿重复添加”。根据字段：供应商车行、提货点、卸货点、车行、监管类型、特种车、尾板车、有效期判断。如果供应商、路线信息、车辆信息相同且生效日期重叠，则判断为相同报价。

- 取消：取消当前新增供应商报价，返回供应商报价列表页面。

- 复制：复制当前序号的报价内容，右击可以粘贴到另一行。

- 删除：删除当前序号的报价。

- 新增行：新增页面默认10条报价行，如果报价行不够，点击该按钮添加一行。

**界面原型概述 · 供应商运输报价新增**

- **区域字段或业务元素**：供应商车行、税率（%）、币种、提货点、卸货点、车型、监管类型、单价、单位、运输费、起步价、压日费、返空费<br>（%）、尾板车、起始日期、有效期、特种车、备注。
- **区域级通用规则**：字段均可编辑。

| 字段或控件特例 | 特例约束或业务结果 |
| --- | --- |
| 供应商车行 | 所有供应商车行，由系统合作方档案管理类型为“供应商”带出；必填。 |
| 税率（%） | 提交时校验税率；取值范围为 0～100，最多保留两位小数；必填。 |
| 币种 | 币种代码；必填。 |
| 提货点、单位 | 必填。 |
| 卸货点 | 必填省市二级，区为选填，最后选填写详细地点；必填。 |
| 车型 | 选项：1.5T；4.2车；6.8车；7.6车；3T；5T；8T；10T；12T；20尺柜；40尺柜；40/45尺柜；必填。 |
| 监管类型、尾板车 | 选项：是、否；选填。 |
| 单价、运输费 | 保留小数点后2位；字段组校验见[合作方报价业务规则](PRD.高捷物流系统一期.第005篇.合作方报价-报价管理.92B1FD526A.md#doc-92B1FD526A-section-4485691bd328)；必填。 |
| 起步价 | 保留小数点后2位；选填。 |
| 压日费 | 压车产生的费用；选填。 |
| 返空费<br>（%） | [计算/聚合规则见关联业务规则](PRD.高捷物流系统一期.第005篇.合作方报价-报价管理.92B1FD526A.md#doc-92B1FD526A-section-4485691bd328)；必填。 |
| 起始日期 | 格式“YYYY-MM-DD”，默认当天；必填。 |
| 有效期 | 格式“YYYY-MM-DD”；报价状态判定见[合作方报价业务规则](PRD.高捷物流系统一期.第005篇.合作方报价-报价管理.92B1FD526A.md#doc-92B1FD526A-section-4485691bd328)；必填。 |
| 特种车 | 危险品、冷藏车、气垫车、平板车；选填；无预设值。 |
| 备注 | 选填。 |

**返空费计算规则：**
- `返空费 （%）`：系统根据运单状态为“已取消”的对运单计算返空费。返空费=运输费*返空费比例。百分比数值，数值取值范围0-100，保留小数点后2位

1. 字段说明

**场景：** 供应商报价管理-供应商报价新增

**范围：** 填写供应商信息、路线信息、车辆信息、报价信息，完成报价新增。

**参与角色：** 航晟客服、主管

**触发与入口：** 进入供应商报价管理，点击“新增报价”按钮，进入此页面

**业务结果：** 校验通过后新增供应商报价并返回报价列表；校验失败时不保存并提示原因。

**处理规则**

进入“新建报价”页面，填写：供应商信息、路线信息、车辆信息、报价信息。

**供应商信息**

- 供应商车行：所有供应商车行，由系统合作方档案管理类型为“供应商”带出。

- 税率（%）：填写税率，保留小数点2位。

- 币种：选择结算的币种代码，和结算系统的币制代码一致。

- 未保存前，可重新修改供应商信息。

**路线信息**

- 提货点：省市二级联动选择，最后填写的是详细地点。

- 卸货点：省市二级联动选择，最后填写的是详细地点。

- 是否往返：选择往返或者是单程车。

- 未保存前，可重新修改路线信息。

**车辆信息**

- 车型：添加、编辑一个报价时只能选择一种车型。

- 监管类型：添加、编辑一个报价时只能选择一种监管型。

- 特种车：添加、编辑一个报价时只能选择一种特种车。

- 运输时效：该路线车辆任务完成的预计用时。

- 未保存前，可重新修改车辆信息。

**报价信息**

- 运输费：车辆完成一次任务后的航晟应付的金额，单位（元/车）。单程、往返类型都只按照价格算一次。

- 返空费（%）：运单状态更新为“已取消”。系统根据报价管理中的“返空费比例”乘以运输费。此处填写返空费比例，保留小数点后2位。

- 起始日期：生效日期默认为提交报价当天。录入的为有效期，格式“YYYY-MM-DD”。

- 有效期：录入的为有效期，格式“YYYY-MM-DD”。

- 未保存前，可重新修改报价信息。

点击“确认”进行提交保存。

- 提交成功：显示“保存成功”提示，跳转到“供应商报价管理列表”界面。

- 无法提交：若必填项未输入，则该输入项红色高亮提示；

**业务分支**

供应商列表页面“上传报价”按钮，支持通过excel表格批量上传，按照上传模板填好必填的信息。上传时会校验必填信息和去重已存在的报价。支持xls、xlsx格式

- 报价方式校验：（单价、单位）和运输费只能2选一，其中一项必填。
- 报价状态判断：有效期结合起始日期判断报价状态“生效”“失效”“待生效”。

- 报价状态判断：有效期结合起始日期判断报价状态“生效”“失效”“待生效”。

#### 1.3.10 报价批量上传规则

**场景：** 客户收费报价管理-客户收费报价上传、供应商报价管理-供应商报价上传

**范围：** 批量上传客户收费报价和供应商报价

**参与角色：** 航晟客服、主管

**触发与入口：** 分别进入客户收费报价列表和供应商报价列表，点击《上传报价》按钮，弹出上传 Excel 的弹窗。

**业务结果：** 文件全部通过校验时批量生成报价并返回对应列表；任一行校验失败时整份文件不导入，并提示错误行及原因。

**处理规则**

进入报价上传弹窗，按新增报价规则上传Excel文件，支持`.xls`、`.xlsx`格式。

- 标红项为必填项。上传时校验供应商车行名称是否与系统数据一致，以及必填项和格式是否正确。任一行校验失败时整份文件上传失败，并按“第<行号>行必填项为空”或“第<行号>行供应商车行未找到匹配项”的格式提示错误。

- 上传报价与已生效的相同报价重复时，提交失败并提示“已存在报价，请不要重复添加”。

点击“确认”提交。

- 提交成功：提示“上传成功”，并根据上传入口返回“供应商报价管理列表”或“客户应收报价管理列表”。
