# BMS 原型交互与视觉规范

## 1. 文档目的

本规范汇总账单系统与成本中心原型已经确认的交互和视觉结论，作为后续新增页面、调整页面和验收原型的统一依据。

执行原则：

1. 后续结论覆盖早期方案；已明确撤回的设计不再采用。
2. 账单系统与成本中心共用同一套框架、设计令牌、共享组件和交互方式。
3. 页面优先复用共享组件，不在业务页面内重新实现条件块、统计卡片、表格工具栏、分页、导入、导出或弹窗。
4. 本规范描述验收可见的行为，不记录常识性、纯实现性或不影响验收的细节。
5. 业务规则、字段口径或关键状态发生变化时，同步维护原型、PRD 与 CERD；纯视觉微调仅维护原型和本规范。

## 2. 设计基线

### 2.1 主色与语义色

- 主色采用不偏冷、不偏暖的蓝紫色，基准色为 `#4f4aa8`。
- 深色、激活和聚焦状态使用同一蓝紫色族，不再新增另一套主色。
- 绿色、橙色、红色和蓝色仅用于成功、提醒、风险、信息等语义，不用于大面积装饰。
- 页面背景为浅灰，数据区、表格和弹窗主体为白色。
- 不使用渐变色、装饰性光斑、发光下划线或大面积单一色铺陈。

### 2.2 字体

- 中文界面字体统一为 `Microsoft YaHei`、`PingFang SC` 等系统无衬线字体。
- 正文、表格主信息和控件文字统一为 `13px`。
- 次要信息、辅助文案、导航面包屑和表格工具栏统计文案使用 `12px`。
- 原型最小字号为 `12px`，不得出现 `10px` 或更小字号。
- 面板标题使用 `18px`，区块标题使用 `16px`，统计主数值使用 `24px`。
- 表格主信息不加粗；通过 `13px` 主信息与 `12px` 次信息建立层级。
- 数值使用等宽数字特性，所有文字字距为 `0`。

### 2.3 间距与圆角

- 间距以 `4px` 为基础单位，常用值为 `4/8/12/16/20/24/32px`。
- 同一分组内的子元素间距必须一致。
- 条件块和条件区按钮水平间距统一为 `8px`。
- 表格工具栏内方块按钮水平间距统一为 `8px`。
- 条件筛选区、统计栏、标签栏和表格区之间统一使用 `12px` 的区块间距；业务上需要强化分区时可增加到 `16px`，但同级区块必须一致。
- 条件块、普通按钮采用 `2px` 圆角；常规面板和统计卡片圆角不超过 `7px`。
- 不允许卡片嵌套卡片，也不把整个页面区块做成悬浮卡片。

## 3. 全局页面框架

### 3.1 顶部栏

- 顶部栏高度固定为 `50px`。
- 左侧显示 BMS 标识和当前供应链名称。
- 一级模块只保留两个标签：`账单系统`、`成本中心`。
- 默认选中 `账单系统`；切换一级模块时，左侧菜单同步切换。
- 一级标签通过背景明暗表达选中状态，不显示底部高亮线或发光线。
- 一级标签字号应克制，不能压过业务内容。
- 顶部栏保持蓝紫色，不因具体页面改变主题色。

### 3.2 左侧菜单

- 左侧菜单随一级模块切换，账单系统与成本中心不得混用菜单项。
- 菜单上方不显示“账单系统/成本中心”重复标题，也不保留该标题的分隔线。
- 菜单按业务分组展示；分组标题使用次要色和 `12px` 字号。
- 菜单项可使用统一的线性图标；行操作菜单中的文字选项不得带图标。
- 当前菜单项使用蓝紫色文字、浅蓝紫背景和左侧高亮边。
- 数量徽标只在确有待办数量时显示。

### 3.3 导航栏与面包屑

- 顶部栏下方为灰底导航栏，高度固定为 `44px`。
- 导航栏使用平面灰底和底部分隔线，不添加投影或发光效果。
- 面包屑首页统一显示 `BMS`，后接当前页面名称。
- 所有页面不再单独显示页面主标题，也不在标题上方或下方展示灰色说明文案。
- 导航栏不放页面级方块按钮；导入、导出、下载、刷新、新增等动作进入对应数据区的表格工具栏。
- 二级、三级页面存在返回路径时，在导航栏最右侧显示与导航栏等高的“返回”按钮。
- 返回按钮仅承担返回上级页面，不套用方块按钮样式。

### 3.4 页面内容区

- 页面内容区从条件筛选、统计、标签和数据表直接开始，不额外制造标题占位。
- 页面区块按业务阅读顺序排列：条件筛选区、统计栏、状态/子标签栏、表格工具栏、表格、分页栏。
- 多数据区页面各区块独立遵循同一顺序，不共享含义不清的悬浮按钮行。
- 区块标题前使用 `◤` 作为识别符，不再使用实心方块或竖条。
- 区块标题下方不加无业务意义的灰色说明。

## 4. 按钮规范

### 4.1 方块按钮

- 除链接按钮、图标按钮、查询/重置外，明确命令使用统一方块按钮。
- 方块按钮高度为 `32px`，圆角为 `2px`，无阴影。
- 默认白底、细边框、深色文字；主要动作可使用蓝紫底白字。
- 聚焦时显示蓝紫色外发光描边，悬停时增强边框和文字颜色。
- 所有方块按钮文字前统一使用鼠标点击样式图标，图标尺寸 `15px`，图标与文字间距 `6px`，上下居中对齐。
- 不为“排序”等按钮另造专属图标；统一图标用于建立按钮识别，而非解释业务含义。
- 禁用状态保留可识别轮廓，降低对比度，不使用阴影。

### 4.2 查询与重置

- 查询按钮使用主色实底，重置按钮使用白底边框。
- 查询和重置高度、内边距、圆角与条件块一致。
- 条件筛选区仅有一个条件块时，不显示查询按钮，条件变化可直接更新对应数据区。
- 条件块多于一个时显示查询按钮；条件值只进入待查询状态，点击查询后数据区才更新。
- 普通条件筛选区仅当条件块多于 `5` 个时显示重置按钮。
- 参与联合查询的多个条件筛选区，无论条件块数量多少都显示重置按钮。

### 4.3 动作归属

- 表格数据维护动作，如新增、批量删除、批量修改，放在该表格工具栏中。
- 影响业务流程执行的动作，如审核、重跑、刷新状态，也放在对应表格工具栏中。
- 导入、导出动作放在对应数据区的表格工具栏中。
- 不在页面标题行、导航栏或表格外额外生成独立按钮行。
- 没有表格的独立数据区，可在该数据区的工具栏放置动作，但不得冒充页面标题动作。

## 5. 条件筛选区

### 5.1 条件块外观

- 所有筛选条件统一使用 `ConditionFilter` 条件块，不混用裸输入框、传统下拉框或独立日期输入框。
- 条件块采用“字段标题 + 回显值 + 下拉/清除图标”结构。
- 空值统一回显 `请填入`，不再使用 `请选择`。
- 除有业务默认值的日期/月范围外，条件块默认均为空。
- 有值时使用浅蓝紫背景和主色边框，并显示清除按钮；空值时显示下拉箭头。
- 条件块高度固定为 `32px`，宽度根据标题和实际回显文字自适应，不设固定最小宽度。
- 条件块不得在右侧仍有可用空间时提前显示省略号；只有受到容器可用宽度限制时才允许截断。
- 条件块圆角、内边距和高度与查询/重置按钮一致。

### 5.2 筛选区布局

- 条件筛选区背景透明，不嵌入独立白框或卡片。
- 条件块按内容宽度从左向右排列，空间不足时整体换行。
- 查询/重置紧随最后一个条件块，不单独占一行。
- 条件筛选区与统计栏、表格工具栏保持统一的 `12px` 垂直间距。
- 多数据区页面的条件筛选区归属于各自数据区，不跨区漂移。

### 5.3 浮层

- 浮层优先左边缘对齐触发条件块；只有右侧空间不足时才向左修正位置。
- 浮层弹出和退出不使用延时或过渡动画。
- 浮层包含输入框时，打开后自动聚焦输入框。
- 下拉选项之间不显示横向分隔线。
- 选项使用整行悬停/选中背景，主信息与次信息左右排布。
- 条件块清除后立即恢复 `请填入`。

### 5.4 输入与回车

- 文本型条件浮层允许输入自由值，不强制从候选项选择。
- 按 Enter 可提交当前输入值；空值也允许按 Enter 提交并关闭浮层。
- Enter 提交后关闭浮层、移除文本选区和临时聚焦框，不在条件块内保留输入态边框。
- 候选项仅用于辅助选择，不限制原型演示输入。

### 5.5 日期与账期

- 日期条件的默认触发器仍使用统一条件块外观。
- 打开日期条件后直接展示日历或月份面板，不重复显示一层无意义的日期输入框。
- 日期范围面板允许选择起止日期；月份范围面板允许选择起止月份。
- 账期范围可配置为仅日期、仅月份，或同时支持“月份范围/日期范围”两种模式。
- 月份范围的右侧年份必须大于或等于左侧年份，不允许出现时间倒序。
- 营收总览的账期范围默认当前月，并同时支持月份范围和日期范围。

### 5.6 联合查询

- 多个条件筛选区可通过 `useLinkedQueryAreas` 配置为联合查询。
- 联合查询只显示一个查询按钮，按钮固定在配置指定的数据区；营收总览固定显示在店铺数据区。
- 点击查询后，一次性提交全部关联条件区的待查询值。
- 联合查询重置会同时恢复全部关联条件区及数据结果。
- 营收总览中：店铺统计由“店铺 + 账期范围”查询；客户统计由店铺条件与客户区条件联合查询。
- 客户区条件不得反向影响店铺统计值。

## 6. 统计栏

- 统计栏统一使用 `MetricGrid`。
- 统计卡片只展示指标，不允许作为筛选条件或可点击筛选入口。
- 卡片为白底、细边框、顶部 `3px` 语义色线、最大 `7px` 圆角。
- 每张卡片只显示指标名称和主数值；主数值下方不允许出现灰色说明文案。
- 不显示装饰性图标、数据库图标或与指标无关的图形。
- 同一统计栏卡片等宽、等高，动态内容不得改变布局尺寸。
- 金额必须同时显示数值和币种，使用千分位和等宽数字。
- 营收总览店铺统计金额统一折算并显示为人民币 `CNY`。
- 当统计结果不适用时显示 `--`，不得显示“不适用”。

## 7. 标签栏与分段切换

- 列表上方状态标签、页面子标签统一采用透明背景的简约标签栏。
- 标签栏不使用按钮组实底，不放在白色卡片中。
- 选中项使用主色文字和底部细线；未选中项使用中性色。
- 标签项之间保持充足水平间距，标签宽度由文字自适应。
- 子标签切换只切换当前数据区，不改变一级模块和左侧菜单。
- 生成任务页使用两个子标签：`任务列表`、`基础配置`；左侧菜单不再单列“基础配置”。

## 8. 表格规范

### 8.1 表格框架

- 每个表格统一使用 `DataTableFrame`。
- 每个表格必须包含表格工具栏和分页栏，即使当前没有业务按钮。
- 表格工具栏、表头、数据行和分页栏形成一个连续数据区域，不得彼此脱离或留下异常空白。
- 表格工具栏与分页栏使用相同的视觉高度，当前基准为 `56px`；如整体微调，两者必须同步。
- 表格横向内容超出时允许表格内部横向滚动，不允许撑宽整个页面。

### 8.2 表格工具栏

- 所有表格工具栏左右内边距统一为 `16px`，行数信息和最右侧动作均不得贴边。
- 左侧显示 `共 N 行`；表格支持勾选时显示 `共 N 行 | 已选 M 行`。
- 行数及已选行数文案使用 `12px`，两段文案与分隔符之间保持 `12px` 间距。
- 工具栏右侧放置方块按钮；没有动作时保留行数，不保留尴尬的空按钮区。
- 按钮从左到右的优先级为：业务流程按钮组、数据维护按钮组、导入导出按钮组、排序。
- 同组按钮间距统一为 `8px`，不同组不额外制造特殊空隙或锯齿/粗竖分隔线。
- 工具栏只放方块按钮，不放灰色提示、刷新时间、筛选结果或重复表格标题。
- 工具栏越出可视区时吸附窗口顶部，但不得遮挡固定顶部栏。

### 8.3 列排序

- 每个表格默认启用 `排序` 按钮，可通过表格配置关闭。
- 排序按钮位于工具栏动作区最后侧，使用普通方块按钮样式和统一点击图标。
- 点击后弹出排序面板，可拖动调整列顺序；每个可排序字段使用一个升降序按钮，按“未排序 → 升序 → 降序 → 未排序”循环切换。
- 列位置、升降序及恢复默认操作均即时生效，浮层不显示取消或应用按钮，关闭浮层只负责收起面板。
- 同一表格一次只允许一个字段生效排序。调整后表头与数据列必须真正同步换位、数据必须按所选方向真实排序，不能只做视觉演示。
- 排序浮层与表头共用统一升降序图标。未排序时上下三角均为灰色；升序时上三角为红色、下三角为灰色；降序时上三角为灰色、下三角为红色。
- 未设置排序时表头默认不显示升降序图标；鼠标移入任一可排序表头时，其字段名右侧显示灰色升降序图标。点击图标按“未排序 → 升序 → 降序 → 未排序”循环切换并即时更新数据。
- 表头字段名、表头升降序图标与 `排序` 面板共用同一排序状态；点击字段名或图标均按相同顺序切换排序，任一入口发生切换后，其余入口必须显示同步状态。
- 排序状态仅通过表头升降序图标表达，表头和数据单元格均保持表格默认背景色，不对排序列增加整列背景高亮。
- 选择列、展开列和操作列不进入排序面板。
- 冻结数据列进入排序面板，其列位置保持锁定、禁止拖动，但允许配置数据升序或降序。
- 鼠标移入字段左侧拖动或锁定图标时，气泡提示 `列位置排序`；移入字段右侧升降序图标时，气泡提示 `列数据排序`。
- 汇兑损益等业务要求固定的列保持冻结，不允许配置位置。

### 8.4 表头与单元格

- 所有列表表格保留完整网格分隔；表头与数据单元格之间统一显示 `1px` 纵向分隔线，不能因页面未单独声明边框而缺失。
- 表头高度统一为 `44px`，表头文字 `13px`、半粗体。
- 普通数据字段可在 `排序` 浮层、表头字段名或表头升降序图标中配置排序；表头图标仅在悬停或排序生效时显示。
- 选择列、序号列、展开列和操作列不支持排序；特殊模板列通过共享列配置指定实际排序字段。
- 表头列宽应优先完整容纳字段名与当前生效的单个排序符号，二者始终同行显示；仅在可视区确实不足时截断字段名。表头字段名出现省略号时，鼠标移入必须通过气泡展示完整字段名。
- 普通数据单元格默认启用溢出提示；凡文本以省略号截断，鼠标移入后必须通过气泡展示完整文本。
- 同一张表根据内容选定统一行高，不允许同表各行随内容任意变化。
- 可选行高档位：紧凑 `48px`、默认 `60px`、多行 `64px`、堆叠信息 `84px`。
- 所有表头和单元格文字左对齐，包括金额和数量；数字使用等宽数字特性。
- 单元格主信息 `13px`、常规字重；次信息 `12px`、中性色。
- 主次信息必须分行或使用明确间距，禁止直接粘连。
- 单元格中的“不适用”统一显示为 `--`。
- 表格右侧操作列冻结；有明确业务要求的字段列可在操作列左侧冻结。

### 8.5 分页栏

- 每个表格都必须有分页栏。
- 分页栏左侧显示上一页、页码、下一页；页码紧密连续排列。
- `N 行/页` 下拉框放在分页栏右侧，并保留边框。
- 分页控件全部中文，不出现 `page`、`Go to` 等英文。
- 总行数不在分页栏重复显示，由表格工具栏负责。
- 当前页使用主色实底；其他页码使用白底边框。
- 分页栏越出可视区时吸附窗口底部，并保持与当前表格同宽。

## 9. 行操作

- 操作列中“详情/查看”使用统一详情图标，不显示“详情”文字。
- 所有表格操作列必须使用共享组件 `TableActionColumn`，不得在页面内重复配置列宽、右侧冻结、内边距或溢出样式。
- 单个操作使用 `<TableActionColumn compact>`，列宽统一为 `52px`；两个操作使用 `<TableActionColumn>`，列宽统一为 `84px`。
- 操作列默认右侧冻结，内容在列内水平居中，左右内边距统一为 `8px`，操作项间距统一为 `5px`，不得通过定位偏移。
- 操作列禁止使用文本截断省略号；仅允许显示明确配置的详情图标和更多操作图标。
- 详情图标使用 `detail.svg`，有效图形与更多图标视觉等大；基准图形尺寸 `16px`。
- 除详情外，其余行操作收纳到更多菜单中。
- 更多入口使用统一省略图标，无外圈方框、无焦点矩形边框、右侧保留呼吸空间。
- 更多菜单通过鼠标悬停打开，不要求点击；菜单项不带图标。
- 菜单弹出和收起应即时、稳定，不因光标从入口移动到菜单产生断层。
- 删除等危险操作使用红色文字，其他操作使用常规文字。
- 没有额外操作时不显示更多入口。

## 10. 导入、导出与下载

### 10.1 命名

- 所有上传、选择文件、导入类的表格工具栏按钮统一命名为 `导入`。
- 所有下载、导出类的表格工具栏按钮统一命名为 `导出`。
- 工具栏不直接出现“下载模板”“选择文件”“导出任务”等分散命名。

### 10.2 导入弹窗

- 工具栏只显示一个“导入”按钮。
- 全局使用统一导入弹窗，弹窗内包含模板下载和文件选择。
- 有模板时先展示模板名称和“下载”，再展示文件选择及“导入”确认。
- 成本账单导入是例外：无导入模板，因此弹窗不显示模板下载区。
- 原先并列的“下载模板 + 选择文件”必须合并到导入弹窗。

### 10.3 导出弹窗

- 只有一种导出方式时可直接执行；有多种格式或范围时，在居中导出弹窗中选择。
- 工具栏按钮仍统一显示“导出”，不把具体方式写进按钮名称。
- 导出过程和完成反馈在弹窗或消息反馈中表达。

## 11. 弹窗规范

### 11.1 通用行为

- 所有抽屉式弹窗改为屏幕居中的模态弹窗。
- 弹窗挂载到页面根层，打开时有遮罩，关闭后销毁临时内容。
- 弹窗不得过窄；内容超高时只滚动弹窗正文，标题和底部按钮保持可见。
- 弹窗最大高度为 `视口高度 - 32px`，桌面端四周至少保留 `16px`。
- 移动端弹窗宽高均为 `视口 - 16px`，四周至少保留 `8px`。

### 11.2 尺寸分级

| 级别 | 宽度 | 适用场景 |
| --- | ---: | --- |
| 小型 | `560px` | 单一选择、导出方式、简单确认 |
| 标准 | `760px` | 导入、简单编辑、普通配置 |
| 大型 | `980px` | 多区表单、任务详情、对比信息 |
| 超宽 | `1500px` | 账单详情、复杂配置、完整业务工作台 |

- 弹窗宽度同时受视口宽度限制，不允许溢出屏幕。
- 新增弹窗必须选择上述档位，不在页面内写任意宽度。
- 高度默认内容自适应，不设置无业务意义的固定高度。

### 11.3 弹窗内动作

- 底部按钮右对齐，主动作置于最右侧。
- 取消为次按钮，提交/应用/确认使用主色按钮。
- 多步骤弹窗按“取消、上一步、下一步/提交”排列。
- 表格详情类弹窗内部仍使用统一表格工具栏、排序和分页规范。

## 12. 状态与反馈

- 成功、警告、失败、信息状态使用统一语义色和浅色底标签。
- 禁用按钮必须明确不可用，但仍能识别原动作。
- 命令执行成功或失败使用轻量消息反馈；需要二次确认的危险操作使用居中确认弹窗。
- 页面不显示实现过程、技术阶段或无验收价值的运行提示。
- 统计卡片和页面标题附近不显示灰色解释文案。

## 13. 业务页面特例

### 13.1 营收总览

- 顶部已选定供应链，页面展示该供应链下店铺及客户统计。
- 店铺区条件为店铺和账期范围；账期范围默认当前月，支持月份范围和日期范围。
- 店铺统计统一使用 `CNY`，不依赖客户区任何条件。
- 客户区可按客户、结算币种、未收状态筛选，并与店铺区条件联合查询。
- 联合查询只显示一个查询按钮，固定在店铺区；重置同时重置两个条件区。

### 13.2 应收账单与返款账单

- 列表使用统一条件块、统计栏、状态标签、表格工具栏和分页栏。
- 详情使用超宽居中弹窗，不使用右侧抽屉。
- 应收账单详情的费项明细保留费项横表/纵表、币种、业务单号查询和补录费项等业务结构。
- 编辑页以已确认的线上页面业务结构为基准，外观仍遵循本规范。

### 13.3 回款管理

- 汇兑损益列始终显示，不提供“显示/隐藏汇兑损益”选项。
- 汇兑损益列及其右侧列冻结，禁止调整列位置，但仍允许配置数据升序或降序。

### 13.4 调账中心

- “下载模板”和“选择文件”合并为统一“导入”弹窗。
- 审核通过、移除等批量业务动作位于表格工具栏。

### 13.5 生成任务

- 页面包含 `任务列表` 和 `基础配置` 两个子标签。
- 任务列表不展示“任务执行阶段”。
- 触发方式仅允许 `定时` 或 `手动`。
- 错误摘要仅在任务详情中显示。
- 账单生成方式显示首次生成、补充生成、替换生成；非账单生成任务显示 `--`。
- 补充生成和替换生成必须有可演示的交互流程和结果关系。
- 高级筛选项全部直接展示，不保留“显示/隐藏高级筛选项”按钮。

### 13.6 汇率配置

- 页面采用“基准汇率表 + 客户特调汇率”双数据区布局。
- 两个数据区分别拥有独立表格工具栏和分页栏。
- 本页关闭列排序。
- 基准汇率表的抓取、导入，以及客户特调汇率的添加，都放入各自表格工具栏。

### 13.7 成本中心

- 成本中心与账单系统共用相同的条件块、统计卡片、表格、分页、按钮和弹窗基础设施。
- 成本总览统计卡片不显示主数值下方灰字。
- 成本账单导入不提供模板下载，是全局导入弹窗的明确特例。

## 14. 数据与演示一致性

- 所有演示数据统一保存在当前浏览器 IndexedDB 中，页面不得维护另一套散落的硬编码状态。
- 不同浏览器或不同浏览器配置文件拥有独立 IndexedDB 数据。
- 模拟数据管理提供导出、导入和恢复初始数据能力。
- 演示数据、字段名称、业务状态和统计结果应与 PRD、CERD 保持一致。

## 15. 响应式与可用性

- 固定顶部栏、侧栏、表格工具栏和分页栏不得互相遮挡。
- 小屏幕下侧栏可收起，导航栏允许换行但不改变信息顺序。
- 条件筛选区在窄屏按条件块整体换行，不压缩到文字不可读。
- 统计栏按可用宽度降列，卡片最小宽度不得导致主数值溢出。
- 表格优先内部横向滚动，冻结列和操作列仍保持可用。
- 所有交互元素需要可聚焦，并提供清晰的聚焦状态和可读的 `title/aria-label`。

## 17. 原型迭代与验收

- 原型微调默认通过 Vite 热更新由产品人员人工验收。
- 未经用户明确要求，不因样式或小交互改动运行完整构建、Playwright、截图或全项目验证。
- 轻量修改只检查受影响文件的语法和明显冲突。
- 用户明确提出“完整验证”或阶段性交付时，才执行 `npm run verify` 或 `npm run verify:full`。
- 任何新增通用规范应优先更新共享组件和本文件，避免逐页复制修改。
