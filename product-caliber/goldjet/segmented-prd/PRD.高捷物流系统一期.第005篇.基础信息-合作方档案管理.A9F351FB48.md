### 1.1 合作方档案业务范围、术语与角色

本篇按三个逻辑子域维护：供应商档案（1.3.1–1.3.17）、客户档案（1.3.18–1.3.34）、客户授信额度（1.3.35–1.3.39）。三个子域共用合作方主数据和审批框架，暂不拆成新的固定篇号；字段定义统一回链[数据字典](PRD.高捷物流系统一期.第050篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-air-business)。

#### 1.1.1 产品整体描述

此文档主要描述供应商中心和客户中心的应用层的操作页面和字段展示。合作方档案管理作为业务中台之一，其在高捷的业务域包括：供应商管理、客户管理、客户授信额度管理。

合作方档案管理模块内容为业务部门和财务部门共同使用。有：供应商新增、供应商维护、供应商审批；客户新增、客户维护、客户审批；授信额度申请、授信额度审批。

#### 1.2.5 供应商新增保存原型界面

（1）供应商新增保存原型界面

供应商新增维护原型界面，点击“保存”按钮，弹出“保存确认”弹框。

（2）按钮说明

- 确认：确定保存该供应商新增申请。保存时校验必填字段是否填写，若必填字段未填写，无法保存；同时校验该供应商的统一社会信用码或供应商中文名称，在该组织下是否存在相同的且状态非“已删除”状态的数据，若存在，也无法保存成功。保存完成后，返回供应商列表原型界面。根据该编辑操作人员，自动更新该供应商的更新人和更新日期，其中更新日期为保存时的系统日期。

- 取消：取消保存操作，返回供应商新增维护原型界面。

<a id="doc-A9F351FB48-section-ff8abf2a0e3c"></a>
#### 1.2.6 供应商新增提交原型界面

（1）供应商新增提交原型界面

供应商新增维护原型界面，点击“提交”按钮，弹出“提交确认”弹框。

（2）按钮说明

- 确认：确定保存并提交该供应商新增申请。保存时校验必填字段是否填写，若必填字段未填写，无法保存；同时校验该供应商的统一社会信用码或供应商中文名称，在该组织下是否存在相同的且状态非“已删除”状态的数据，若存在，也无法保存成功。保存完成后，根据该编辑操作人员，自动更新该行的更新人和更新日期，其中更新日期为保存时的系统日期，同时该订单状态变为“已提交”，等待财务审批。

- 取消：取消保存操作，返回供应商新增维护原型界面。

#### 1.2.7 供应商编辑原型界面

（1）供应商编辑界面（同3.1.3.1）

供应商列表界面，点击“编辑”按钮，跳转至“供应商维护”原型界面。新建、已生效状态的供应商才有“编辑”功能。已提交、已失效状态的供应商没有“编辑”功能。

（2）按钮说明（同3.1.3.1）

- 附件上传：超链接，可上传附件，必须上传。

- (银行账户信息)新增：在银行账户栏新增一行银行账户信息。

- (银行账户信息)删除：删除该用户账户。

- (联系人信息)新增：在联系人栏新增一行联系人信息。

- (联系人信息)删除：删除该联系人。

- (邮箱收件人信息)新增：在邮箱收件人新增栏新增一行邮箱收件人。

- (邮箱收件人信息)删除：删除该邮箱收件人。

- 保存：保存该供应商，校验必填字段。保存成功自动生成供应商编码。规则：“组织编码+编码”，不改变该供应商的状态。

- 提交：提交审批。新建状态的才有提交按钮，已提交状态的无提交按钮。先进行保存后进行提交。保存时校验必填字段，自动生成供应商编码。提交后，该供应商状态变为“已提交”，只有新建状态的供应商有该状态。

- 取消：取消新增供应商，返回供应商列表原型界面。

| 范围/概述 | 填写申请额度，提交审批 |
| 主要参与者 | 业务/财务 |
| 前置条件 | 进入我的合作伙伴->我的客户，进入我的客户列表，点击“额度申请”按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，能够正常录入信息，可保存数据、可提交财务审批，可成功提交或提示输入错误。 |
| 主业务流程 | 进入“我的客户”页面，点击新增进入客户维护界面，填写本次申请额度、上传附件，完成额度申请。<br>1.本次申请额度：<br>- 手工录入，数字格式，保留2位小数。<br>- 未保存前，可重新录入修改。<br>- 保存时校验额度申请需≥（-原授信额度）<br>2.上传附件<br>上传附件，文本图片格式。<br>- 附件大小需≤20M。<br>保存/提交时，需进行校验：<br>必填信息“本次申请额度”是否填写完毕，若格式不满足，则无法保存成功 |
| 业务分支 | 客额度申请保存后，点击“提交”，提交给财务审批<br>- 提交后，该行数据状态变为“已提交”，无法继续对该客户数据进行编辑。<br>财务审批，财务在业务员提交审批的客户申请上进行审批<br>- 财务审批通过，该行数据状态变为“已生效”。<br>- 财务审批拒绝，该行数据状态变为“财务审批拒绝”，需给对应申请人发送消息提醒。申请人可在审批拒绝的单据上继续编辑、删除和提交。 |
| 特殊需求 | 1.提交审批时，财务部门需有相关的消息推送。<br>2.审批拒绝时，需要给申请人发送消息推送。 |
| 关联功能 | 1.各订单（下各订单时，需校验该客户的额度是否小于等于0，若小于等于0则无法继续下单）<br>2.订单成本录入（录入应收时，扣减额度；该客户的应收行如果删除，则需加回客户的额度。在收款核销完成后，需加回核销金额的额度。） |

- 本次批复额度：审批通过时需校验：批复额度≥（-原始额度）。
