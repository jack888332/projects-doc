### 1.2 产品概述

### 1.3 产品功能需求

#### 1.3.1 登录页面

- 司机登录小程序。

- 小程序名称：高捷物流

<a id="doc-92E2D8A803-section-6eb9a0fd9fc4"></a>
#### 1.3.2 业务规则说明

| 场景名称 | 用户登录页面 |
| --- | --- |
| 范围/概述 | 可通过短信验证码校验或者微信快捷登录方式完成登录。 |
| 主要参与者 | 司机 |
| 前置条件 | 在订单调度时，录入了调度的司机联系方式。 |
| 业务结果 | 可成功登录，并进入小程序。 |
| 主业务流程 | 1. 输入手机号：进行手机号格式校验（11位数字）；<br>1. 点击获取验证码：先要通过图形识别校验（防刷），通过后自动点击“获取验证码”并倒计时60s，60s后可重新再次获取验证码；<br>1. 保持登录状态：默认为“已勾选”，可手动取消。勾选代表每次可自动登入，未勾选，则下次需要重新输入并重新校验登录。<br>1. 点击“登录”按钮，验证码校验通过则自动调整进入首页。校验失败，则提示语提示“验证码错误，请重新输入！”<br>1. 可直接通过点击微信图标，进行微信授权登录（获取匹配微信绑定手机号的方式）。<br>1. 点击帮助按钮，进入帮助页面：<br>- 点击具体的问题，进入问题详情页面：<br>1. 点击“隐私”按钮，进入页面：<br>1. 点击“条款”按钮，进入页面： |
| 业务分支 | 初始的内容，可通过数据库配置完成。 |

#### 1.3.3 “当前任务”页面

- 提供该运单各状态和节点的变化记录。

<a id="doc-92E2D8A803-section-915ff8931b46"></a>
#### 1.3.4 业务规则说明

| 场景名称 | 当前任务 |
| --- | --- |
| 范围/概述 | 查看当前进行中的运单任务。 |
| 主要参与者 | 司机 |
| 前置条件 | 司机登录成功，名下有匹配的进行中的任务。 |
| 业务结果 | 正确展示进行中任务的概要信息。 |
| 主业务流程 | 1. 页面排序规则：统一按照提货时间正序排序（时间早的，排序靠前）。<br>1. 状态：显示该运单的状态。<br>1. 毛件体：在调度的时候，若填了具体的毛件体，则显示具体值；若没有填，则调度时便计算了该运单均摊的毛件体。<br>1. 异常状态：若该运单有“异常中”的状态，则右上角显示“异常中”的角标。同理，若“异常已关闭”状态，也进行相应显示。<br>1. 提货点和卸货点：取运单上的提货点和卸货点。若有多个提货点或卸货点，则将其全部显示。<br>1. “单据上传”按钮：点击后可快捷进入上传单据的页面。<br>1. 单号：关联到订单的单号，若关联的订单“订单号”有值，则显示“订单号：XXX”；若订单号无值，则显示“子单号：XXXX”；若子单号无值，则显示“批次号：XXX”。<br>1. 期货时间：若该运单已提货，则显示“期望送达时间”，若该字段无值或该运单未提货，则显示“期望提货时间”。 |
| 业务分支 | 若当前页面中的运单状态变更为“已卸货”或“已取消”时，则该运单记录从当前页面消失，移往“历史任务”页面。 |
