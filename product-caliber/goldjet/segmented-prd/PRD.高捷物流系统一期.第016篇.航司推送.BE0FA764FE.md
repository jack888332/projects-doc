#### 1.2.2 翌飞批量发送与防重规则

| 场景名称 | 发送运单 |
| --- | --- |
| 范围/概述 | 批量向翌飞发送主运单和分运单。 |
| 主要参与者 | 客服、打单员 |
| 前置条件 | 订单已有提单号，客服或打单员在提单管理列表选择待发送数据。 |
| 业务结果 | 符合条件的数据按主单后分单的顺序发送；成功项更新发送状态，失败项显示翌飞返回的异常信息。 |
| 主业务流程 | 1. 发送条件：仅已有提单号的订单可使用“批量发送运单”。可选择主单、分单或整票数据发送至翌飞。<br>2. 发送顺序：必须先发送主单运单信息，包括航班信息、起飞港、降落港、件数和重量；主单成功后方可发送分单。未发送主单而直接发送分单时，展示翌飞返回的错误信息。<br>3. 两分钟防重：任一主单或分单发送成功后的2分钟内不得重复提交，否则展示翌飞返回的错误信息。例如，一个主单包含两个分单，其中分单1已发送成功；2分钟内全选整票发送时返回错误，超过2分钟后全选则重新发送该主单及全部分单，包括分单1。<br>4. DescriptionCode：提单号前缀为784（CZ）、043（KA）、131（JL）或235（TK）时，该字段必填，选项为EAP（默认）和EAW；前缀为999（CA）时，选项为EAP（默认）、EAW和中性提单999，中性提单支持手工录入。EAP、EAW发送至CCSP的国际电子运单模块，中性提单999发送至CCSP的国际主单-中性运单制单模块。其他航司的DescriptionCode为空，且不在弹窗中展示。弹窗仅展示本次所选数据中需要填写DescriptionCode的提单号。<br>5. 状态：主单发送状态、分单发送总状态和分单发送子状态均包括“待发送”“发送中”“成功”“异常中”；状态为“异常中”时必须显示异常标识和翌飞返回信息。<br>6. 选择：勾选主单序号前的复选框时，默认选择该主单下的全部分单；也可在下拉项中单独选择主单或某个分单。 |

<a id="doc-BE0FA764FE-section-b27d10bc025a"></a>
#### 1.2.3 推送状态展示与选择规则

| 场景名称 | 发送运单 |
| --- | --- |
| 范围/概述 | 在提单编辑和分单编辑页面查看发送状态并选择待发送运单。 |
| 主要参与者 | 客服、打单员 |
| 前置条件 | 客服、打单员在提单管理提单编辑、分单编辑操作后触发 |
| 业务结果 | 页面分别展示主单、分单汇总和分单明细状态，用户可切换并按规则批量发送。 |
| 主业务流程 | 1. 通过页签在主单与分单之间切换。<br>2. 主单页签依次展示选择状态、提单号、发送航司提单状态、头程航班、提单件数、提单重量和提单体积。<br>3. 分单汇总依次展示分单数、分单总件数、分单总重量、分单总体积和发送航司分单总状态。<br>4. 分单页签依次展示选择状态、分单号、发送航司分单子状态、分单件数、分单重量和分单体积。<br>5. 点击“批量发送运单”后，按[翌飞批量发送与防重规则](#doc-BE0FA764FE-section-36be6b5a98f3)处理。 |
