### 1.2 产品概述

<a id="doc-3ECAA331AF-section-92154fca749e"></a>
#### 1.2.1 产品整体描述

此文档主要描述结算中心的应用层财务结算的操作页面和字段展示。财务作为业务中台之一，其在高捷的业务域包括：订单成本、结算对账、收付款申请、销项票管理、收付款核销、费用报销查询。

财务结算模块内容为业务部门和财务部门共同使用。有：订单成本维护、调整单维护、结算成本审批、结算费用查询；应付对账单维护、应付对账单审批、应收对账单维护、应收对账单审批、对账单查询；付款申请维护、付款申请审批、收款申请维护、收款申请审批、收付款申请查询；销项发票申请、手工发票补录、开票申请查询；付款核销、付款核销打回、收款核销、收款核销打回、收付款核销查询。

### 1.3 结算功能需求-费用报销管理

<a id="doc-3ECAA331AF-section-8fa54b98e5f0"></a>
#### 1.3.1 报销列表原型

报销列表页面，可搜索所有“钉钉”推送的费用报销信息，可查看对应数据，自动导入金碟，当同步金碟失败后，允许再次推送。列表界面只能查看到费用承担部门部门为对应用户所在组织的数据。

（1）报销列表界面

（2）按钮说明

- 付款：跳转至“付款编辑”界面。“付款”操作一次只能够勾选一条付款申请数据。

- 核销：跳转至“核销编辑”界面。“核销”操作一次能够勾选多条数据，但是必须都是同个往来单位、承担组织的数据。

- 按勾选导出：勾选数据，导出勾选的数据。

- 按查询条件导出：按照查询条件，导出数据（存在一次导出大量数据的场景）。

- 查询：在不选择任何查询字段下，点击“查询”按钮，默认所有查询条件。选择对应的查询条件，则显示符合结果的数据。查询出的数据，按照“单据编号”倒序排列。

- 重置：重置所有查询条件。

- 查看：跳转至对应的明细页面。如果是“费用报销单”，跳转至“费用报销单明细”界面；如果是“员工借支单”，跳转至“员工借支单明细”界面；如果是“付款退款单”，跳转至“付款退款单明细”界面。

#### 1.3.13 业务规则说明

| 场景名称 | 报销列表-核销编辑 |
| --- | --- |
| 范围/概述 | 勾选多条同个往来单位、承担组织的数据，输入核销金额，点击保存或保存并提交，完成核销编辑 |
| 主要参与者 | 财务会计 |
| 前置条件 | 进入报销管理-> 报销列表，进入“报销列表”页面；<br>勾选核销数据，点击“核销”进入此页面 |
| 业务结果 | 页面操作功能可正常使用，输入符合格式和规则校验，可成功提交或提示输入错误。<br>保存后的数据在报销列表界面能够查看到，可进行查看操作；<br>保存并提交后的数据，在报销付款列表界面能够查看到，可进行查看、编辑、提交、删除、打回操作。 |
| 主业务流程 | 勾选“报销列表”页面的数据，点击“核销”按钮，进入核销编辑页面，输入：核销金额。<br>本次核销金额：<br>- 必填；<br>- 数字格式；<br>- 未保存前，可修改。<br>点击“保存”进行提交保存，弹出保存确认弹框。<br>- 确认：弹出一闪而过的提示语“保存成功”，跳转到“报销付款列表”界面，该报销申请状态变为“新建”。<br>- 无法提交：若必填项未输入则该输入项红色highlight提醒，保存按钮置灰不可点击。若“借支核销金额”不等于“报销核销金额”+“退款核销金额”，也无法保存成功。<br>- 取消保存，调整至“核销编辑”界面，再次核销编辑。<br>点击“保存并提交”进行提交保存，弹出提交确认弹框。<br>- 确认：一闪而过的提示语“提交成功”，跳转到“报销付款列表”界面，该核销申请状态变为“已提交”。<br>- 无法提交：若必填项未输入，则该输入项红色highlight提醒，保存按钮置灰不可点击。若“借支核销金额”不等于“报销核销金额”+“退款核销金额”，也无法保存成功。<br>- 取消提交，调整至“核销编辑”界面，再次核销编辑。 |
| 业务分支 | 保存后，可进行查看、编辑、删除、提交审批操作；<br>提交后，可进行查看、打回操作（管理员才能打回）。 |
| 特殊需求 | 相同的往来单位、相同的承担组织，才能够核销申请。 |
| 关联功能 | 1. 报销核销列表。 |
