## 2. 出库流程（陆运/中港车模式，标题为推断）

```plantuml
@startuml
title BC/CC进口出库（陆运/中港车模式）
start
:1.订单;
:2.预估税金;
:3.下快递;
:4.接收订单通知;
:5.拣货、打包、包裹称重;
:6.打托、称重;
:7.导出当天出库明细;
:8.获得出库明细;

  :9B.约中港车;

    :11B.维护载货清单和车辆资料表;
  fork again
    :10A.收到过关资料并打印给司机;
    :11A.装车出库;
  end fork
end fork
:12.录入原始舱单;
:13.录入承运确报;
:14.承运确报结果发送给司机;
-> 司机过皇岗口岸;
:15.在白云快件自助进出区系统录入车辆数据;
fork
  :16A.订单申报;
  fork
    if (订单是否异常) then (是)
      :订单异常子流程;
    else (否)
      :放行;
    endif
  fork again
    :17A.绑定干线信息;
    :18A.返回干线信息;
  end fork
fork again
  :16B.预约快递车辆;
  :17B.车辆进出区申报;
fork again
  -> 司机将货送到快件中心;
  :16C.发送运抵数据给白云快件中心;
end fork
:18B、对接白云物流系统，抓取信息;
:车辆入区;
:装车锁库;
:出区;
:19.跟踪快递;
stop
@enduml
```

## 转换说明

- 两个区域为同一出库流程的两种模式：空运/海外提货（准备海外出口申报材料、货站提货）与陆运/中港车（约中港车、过关材料、皇岗口岸）。
- 原图中“13B.返回干线信息→结束”（空运模式）与“18A.返回干线信息→结束”（陆运模式）为直达结束的支线；活动图语法无法表达支线提前结束，此处并入主线汇聚，差异以本说明为准。同理“订单异常子流程→结束”在原图中直达结束。
- “10.收到提单信息”（空运）与“15.在白云快件自助进出区系统录入车辆数据”（陆运）后的多路无条件分支按 fork/join 表达。
- 原图中的“文档”类注释形状（车辆信息表、承运确报单、打托称重说明等）未纳入流程图。
