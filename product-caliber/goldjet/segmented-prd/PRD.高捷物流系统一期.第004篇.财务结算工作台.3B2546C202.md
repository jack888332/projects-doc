## 1. 财务结算工作台


**业务入口：** 结算工作台

### 1.1 财务结算工作台业务范围

<a id="doc-3B2546C202-section-e39087ae21fb"></a>
#### 1.1.1 财务结算工作台覆盖范围

财务结算工作台集中展示合作方、客户授信额度、订单成本、付款申请、收付款核销、报销付款和销项发票相关待办，并按任务类型进入对应业务页面处理。

<a id="doc-3B2546C202-section-9d078adf6465"></a>
### 1.2 财务结算工作台任务与规则

<a id="doc-3B2546C202-section-27938b6f0caa"></a>
#### 1.2.1 财务结算工作台适用角色

- 财务人员登录后进入财务结算工作台。

- 业务人员具备财务结算功能权限时，工作台展示其有权处理的任务类型。

#### 1.2.3 财务结算工作台展示与快捷入口

| 场景名称 | 财务结算工作台 |
| --- | --- |
| 范围/概述 | 拥有对应功能的角色具备对应的任务。 |
| 主要参与者 | 业务、业务主管、分管副总、财务 |
| 前置条件 | 用户已登录并具备对应财务结算功能权限 |
| 业务结果 | 工作台展示当前角色可处理的任务、快捷入口和消息通知 |
| 主业务流程 | 1. “总待办”显示所有未处理任务的数量。<br>1. 待办任务进度条=未处理任务数/（已处理任务数+未处理任务数）。<br>1. “我的待办”最近更新时间显示待办任务进度条最后一次变化的时间。<br>1. 快捷入口包括供应商审批明细、供应商列表、客户审批明细、客户列表、客户授信额度审批、订单成本审批明细、付款申请审批明细、付款申请编辑列表、付款核销编辑和收款核销编辑。<br>1. 待办任务概览按创建时间升序展示所有未处理任务，每页最多20条。<br>1. 消息通知展示企业微信通知的消息类型和内容，每页最多10条。 |
