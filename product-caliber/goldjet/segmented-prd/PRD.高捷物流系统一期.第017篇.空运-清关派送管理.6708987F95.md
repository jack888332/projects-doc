#### 1.2.3 业务规则说明

| 场景名称 | 清关派送管理-清关派送列表 |
| --- | --- |
| 范围/概述 | 海外部客服下载相关清关派送材料，修改清关派送状态 |
| 主要参与者 | 海外部客服 |
| 前置条件 | 空运客服发出清关派送服务指令 |
| 业务结果 | 页面查询等功能正常使用。 |
| 主业务流程 | 1. 进入《清关派送管理》页面，根据条件查询清关派送订单。排序顺序按照创建时间依次倒序排列。<br>1. 按钮说明：<br>1. 上传:<br>上传文件：<br>- 必填；<br>- 手工上传附件（支持rar、zip、docx、doc、xls、xlsx，pdf、jpg，限制大小为20M）；<br>未保存前，可删除重新上传附件<br>2)下载：空运客服发送服务指令时，会上传相应清关派送材料。海外部客服在清关派送列表上点击下载，列表展示所有空运客服上传的材料。支持单个或批量下载。<br>系统默认根据航司从模板管理生成出相应的提单（有格式）、分单（有格式）、舱单的pdf格式给予海外部同事下载，其余文件则以空运客服上传的为准<br>3)状态管理：<br>勾选“目的地提货”<br>显示“操作时间”字段和数量字段，操作时间默认为当前时间，确认保存后清关派送的服务状态从“服务中”变为“服务已完成”，订单状态变为“目的地提货”<br>剩余毛件体：提单剩余数量-当前录入数量<br>支持多次提交<br>勾选“清关送达”<br>显示“操作时间”字段和数量字段，操作时间默认为当前时间，确认保存后清关派送的服务状态变为“服务已完成”，订单状态变为“清关送达”<br>剩余毛件体：提单剩余数量-当前录入数量<br>支持多次提交<br>1. 接单<br>记录用户名和操作时间 |
