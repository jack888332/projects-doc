# 财务报表导出格式

以下格式基于 `aidocs/product-caliber/bms/prototype/财务给出报表` 目录内的样本文件整理，原则是：

1. 保留能影响金额、归属、追溯的字段。
2. 删除大面积空白的非费项冗余列，比如 `备用1/2/3`、单独的占位 `1`、纯分隔空列、图片占位列。
3. 明细列尽量统一命名，常见别名合并展示。
4. 账单头部信息、明细区、汇总区分开，便于导出后直接核对。
5. 币种和汇率计算口径承接 `aidocs/product-caliber/bms/prd/财务系统.PRD.md` 第 13 章【金额汇兑】；导出账单只展示计算后的结算币种金额，不展示原始币种金额、汇率、财务本位币金额或历史快照。

- 账单级字段：账单编号、账期、客户名称、业务板块、目的国

- 金额级字段：费项结算币种金额
- 追溯级字段：出库时间、末条时间、末条信息、凭证、录入时间、录入人、备注

## 三、应收与返款明细整合字段

当客户需要把应收账单和返款账单的明细放到一起汇总时，可基于两个导出文件的 Sheet 2 形成一张统一明细表。统一明细表不替代原始导出文件，只用于客户自助汇总、筛选和透视。

整合原则：

1. 一行仍对应一条可对账明细。
2. 用 `账单类型` 区分应收账单和返款账单。
3. 用 `明细类型` 区分应收费项、返款明细、扣减费项等业务含义。
4. 金额字段拆成两个口径，避免应收和返款混在同一金额列里。
5. 不补充客户看不懂或不应展示的内部字段，例如来源表、汇率、快照、内部操作人、审核记录。

### 2. 汇总使用规则

客户汇总时建议按以下维度透视：

- 按 `账单类型 + 账单编号` 查看每张账单明细。
- 按 `账单类型 + 明细类型 + 费项名称` 汇总费用或返款。
- 按 `订单号`、`承运单号 / 转单号码` 回查具体订单或包裹。
- 应收金额只汇总 `费项结算币种金额`。
- 返款金额只汇总 `货款结算币种金额`。

两个金额字段不得合并成一个“金额”字段，避免把应收和返款方向混淆。
