### 1.2 产品概述

<a id="doc-DA6DFB99AE-section-e7ac5bbe233c"></a>
#### 1.2.1 产品整体描述

此文档主要描述结算中心的应用层财务结算的操作页面和字段展示。财务作为业务中台之一，其在高捷的业务域包括：订单成本、结算对账、收付款申请、销项票管理、收付款核销。

财务结算模块内容为业务部门和财务部门共同使用。有：订单成本维护、调整单维护、结算成本审批、结算费用查询；应付对账单维护、应付对账单审批、应收对账单维护、应收对账单审批、对账单查询；付款申请维护、付款申请审批、收款申请维护、收款申请审批、收付款申请查询；销项发票申请、手工发票补录、开票申请查询；付款核销、付款核销打回、收款核销、收款核销打回、收付款核销查询。

#### 1.3.16 销项发票补录提交原型

（1）销项发票补录提交界面

（2）按钮说明

#### 1.3.18 业务规则说明

| 场景名称 | 财务结算管理-销项发票补录 |
| --- | --- |
| 范围/概述 | 特殊业务下，不需要开票或已提前开票，为结清各特殊开票业务，需要使用销项发票补录功能。 |
| 主要参与者 | 财务会计 |
| 前置条件 | 进入销项发票管理->销项发票列表，点击“待补录发票列表”，选择需要进行销项发票补录的开票申请号，点击“编辑”按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，能够正常新增税务发票信息，可成功提交或提示输入错误。 |
| 主业务流程 | 选择销项发票补录的开票申请号，进入“销项发票补录维护”页面，填写/选择发票号，保存完成税务发票手工补录，提交该补录的销项票申请。<br>1.发票号：<br>- 手工填写或LOV选择（若LOV选择，只能选到该开票申请单相同的购买方、纳税识别号下的未被关联的税务发票）。<br>- 未保存前，可重新录入修改。<br>录入完成，点击保存；或录入错误点击删除重新维护。<br>点击“提交”完成该销项发票补录工作。<br>- 提交校验：当原币币种=CNY时，校验税务发票行开票金额合计与头的申请金额金额(原币)是否相同，若不同则弹框提醒。“‘销项发票申请金额XX’与‘税务发票合计金额XX’不一致，无法保存提交”。 |
| 业务分支 | - 若客户不需要开票，则该信息可保留在销项票补录界面；若需要进行清理，可手工维护开票信息，进行手工清理。 |
