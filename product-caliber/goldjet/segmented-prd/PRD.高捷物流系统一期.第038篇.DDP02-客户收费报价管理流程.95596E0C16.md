### 1.1 航晟物流：客户收费报价管理的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 录入客户报价 | 航晟物流客服 | 客服新建客户报价记录。 | 2 | 是 |
| 2 | 选择计费模式 | 航晟物流客服 | 客户报价采用单价计费或按车收取提货费，两种模式只能选择一种。 | 3或4 |  |
| 3 | 按车收取提货费 | 航晟物流客服 | 未录入单价（元/kg）时，按提货费（元/车）收费。 |  |  |
| 4 | 单价（元/kg）×重量×车型数量与最小收费比较 | 航晟物流客服 | 录入单价（元/kg）时可以同时录入最小收费。单价（元/kg）乘以实际重量的结果低于最小收费时，按最小收费计费；未录入最小收费时，按单价乘以实际重量计费。 | 5 |  |
| 5 | 查看报价列表 | 航晟物流客服 | 列表展示已录入的客户报价，并提供筛选和搜索。 | 6 |  |
| 6 | 判断是否修改 | 航晟物流客服 | 报价录入错误或需要更新时，客服进入报价编辑。 |  |  |
| 7 | 编辑或删除报价记录 | 航晟物流客服 | 客服可以编辑或删除单条报价，也可以批量删除多条报价。 |  |  |
