### 1.1 新增与模板上传通用异常处理

本节仅适用于明确引用本节的基础代码与名录页面。各页面的进入位置、导入步骤和同键数据替换规则仍在对应场景定义。

| 上传模板固定格式被修改 | 重新上传模板。 |

### 2.1 HS Code数据页面

HS Code数据列表，用于BC出口关务的客户订单资料加工。数据源可以通过导入或来自BC出口关务成功归类历史。更新HS Code数据，可以查看历史版本。

<a id="doc-2B53B730E8-8f4f2c6d7132"></a>
#### 2.1.1 HS Code唯一性规则

| 业务字段 | 规则与形成结果 |
| --- | --- |
| HS Code | 去重校验即可 |

**界面原型概述 · HS Code数据页面**

| 字段或控件 | 个别界面约束或可见反馈 |
| --- | --- |
| HS Code | 必填；只读；按[本区域业务规则](#doc-2B53B730E8-8f4f2c6d7132)展示或校验 |
| 编码描述 | 必填；只读 |
| 申报要素 | 默认：若选择，则自动带出 |
| 计量单位 | 默认：若选择，则自动带出 |
| 监管条件 | 默认：若选择，则自动带出 |
| 检验检疫类别 | 按本场景操作 |
| 出口退税率 | 正整数即可 |
| 出口关税 | 正整数即可 |
| 最惠国税率 | 正整数即可 |
| 进口增值率 | 正整数即可 |
| 普通税率 | 正整数即可 |
| 消费税 | 必填；默认：手动输入；正整数即可 |

**业务范围**：输入HS Code数据信息，提交数据

**参与角色**：管理员

**前置条件**：进入HS Code数据列表页面，点击【新增】按钮，弹出新增弹窗

**业务结果**：输入通过格式和规则校验后可提交；校验不通过时提示输入错误。

**处理规则**：新增数据：
管理员进入基础数据-HS Code数据列表页；
下载模板并编辑数据；
上传模板；
刷新数据列表，显示全部数据。

**分支与异常**：执行[新增与模板上传通用异常处理](#doc-2B53B730E8-reference-create-import-exceptions)。

4a-1、数据中HS Code相同，替换旧的数据。

**业务范围**：查看HS Code历史版本，并修改数据

**参与角色**：管理员

**前置条件**：进入HS Code数据页面

**业务结果**：进入页面可以查看数据列表，可以修改数据。

**处理规则**：进入HS Code数据列表，点击进入历史版本列表
点击【查看详情】，打开新页面进入数据列表
点击【修改】，进入到编辑页面
在编辑页面点击保存，保存修改后的数据
修改生效和失效数据

**分支与异常**：1a-1、没有历史数据，显示空白页；
5a-1、保存失败，失效日期不能早于生效日期。
