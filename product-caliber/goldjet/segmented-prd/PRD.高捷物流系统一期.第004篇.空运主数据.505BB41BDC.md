### 1.2 空运主数据维护功能与规则

<a id="doc-505BB41BDC-section-3880b60e45b6"></a>
#### 1.2.1 航司管理入口与操作

- 航司管理-新增功能，可新增航司。

- 航司管理-查看功能，可查看航司信息。

- 航司管理-删除功能，可删除航司。

- 航司管理-批量删除功能，可批量删除航司。

<a id="doc-505BB41BDC-section-331742fd30ad"></a>
#### 1.2.2 航司管理字段

**航司管理字段及场景约束：**

| 字段 | 取值与格式 | 字段属性 | 规则说明 |
| --- | --- | --- | --- |
| 航司代码 | 取值形式：文本；长度或格式：1-10 | 非必填；可修改 | 航司二字代码。唯一 |
| 供应商名称 | 取值形式：多选 | 必填；可修改 | 关联供应商档案。多选。 |
| 公司名称 | 取值形式：文本；长度或格式：2-50 | 必填；可修改 | 航司全称（中文）。唯一 |
| 提单前缀 | 取值形式：数字；长度或格式：1-10 | 必填；可修改 | 3 位数字，用于提单号管理中生成新提单号；不唯一。 |
| 提单打印抬头 | 取值形式：文本；长度或格式：1-150 | 非必填；可修改 | 用于提单制作-提单编辑页面。 |
| ISSUINGCAR | 取值形式：文本；长度或格式：1-150 | 非必填；默认值：GUANGDONG GOLDJET INT’L LOGISTICS CO.,LTD；可修改 | 承运人 |
| IATACode | 取值形式：文本；长度或格式：1-10 | 非必填；可修改 | 承运人在航司系统中的代码 |
| AccountNo | 取值形式：文本；长度或格式：1-20 | 非必填；可修改 |  |

<a id="doc-505BB41BDC-section-6b96b4f94651"></a>
#### 1.2.3 航司新增、删除与编辑规则

| 场景名称 | 航司管理-新增页面 |
| --- | --- |
| 范围/概述 | 输入航司信息，提交信息 |
| 主要参与者 | 航线专员、财务专员 |
| 前置条件 | 进入航司管理页面，点击《新增》按钮，出现新增航司弹窗 |
| 业务结果 | 校验通过后新增航司并返回航司管理页面；校验不通过时标识错误字段且不提交。 |
| 主业务流程 | 在《航司管理-新增》弹窗中录入航司代码、供应商名称、公司名称、提单前缀、提单打印抬头、ISSUINGCAR 和 IATACode。<br>- 按字段定义录入。<br>- 航司代码不允许重复。<br>- 供应商名称取自供应商档案，允许多选。<br>- 航空公司名称不允许重复。<br>- 提单前缀不允许重复；该前缀用于识别航司，并用于提单编辑和提单号管理。<br>- 系统根据提单前缀，将提单打印抬头自动带入提单编辑页面。<br>- ISSUINGCAR（承运人）默认为“GUANGDONG GOLDJET INT’L LOGISTICS CO.,LTD”；承运人信息显示在对应提单的编辑页面。<br>- IATACode 是承运人在航空公司的代码，用于向航空公司发送电子提单信息。<br>点击《保存》提交。<br>- 提交成功：显示“提交成功”提示，关闭弹窗并返回航司管理页面。<br>- 无法提交：必填项未输入，或输入长度、格式不符合要求时，相应输入项高亮提示，《保存》按钮置灰且不可点击。 |

| 场景名称 | 航司管理-删除 |
| --- | --- |
| 范围/概述 | 删除航司 |
| 主要参与者 | 航线专员、财务专员 |
| 前置条件 | 进入航司管理页面，点击《删除》按钮，出现删除航司确认弹窗。 |
| 业务结果 | 确认后删除航司并刷新列表；取消后关闭弹窗且不删除。 |
| 主业务流程 | 进入《航司管理》页面，删除航司基础信息：航司代码、供应商名称、公司名称、提单前缀、提单打印抬头、ISSUINGCAR、IATACode。<br>点击《确定》进行删除操作。<br>- 删除成功：显示“删除成功”提示，关闭弹窗，刷新航司管理页面。<br>点击《取消》取消删除操作。<br>- 取消成功：关闭弹窗，返回航司管理页面。 |

| 场景名称 | 航司管理-编辑 |
| --- | --- |
| 范围/概述 | 编辑航司信息 |
| 主要参与者 | 航线专员、财务专员 |
| 前置条件 | 进入航司管理页面，点击《编辑》按钮，出现编辑航司信息弹窗 |
| 业务结果 | 校验通过后保存航司信息并返回航司管理页面；校验不通过时标识错误字段且不提交。 |
| 主业务流程 | 进入《航司管理》页面，编辑航司基础信息：航司代码、供应商名称、公司名称、提单前缀、提单打印抬头、ISSUINGCAR、IATACode。<br>点击《保存》进行提交保存。<br>- 提交成功：显示“提交修改成功”提示，关闭弹窗，跳转到航司管理页面。<br>- 无法提交：若必填项未输入，或输入长度格式不符合要求，则该输入项红色高亮提示，《保存》按钮置灰不可点击。 |

#### 1.2.7 板型管理字段与维护规则

- 板型管理-新增功能，可新增板型。

- 板型管理-编辑功能，可编辑板型信息。

- 板型管理-删除功能，可删除板型。

**板型管理字段及场景约束：**

| 字段 | 取值与格式 | 字段属性 | 规则说明 |
| --- | --- | --- | --- |
| 航司代码 | 取值形式：下拉选择；长度或格式：1-10 | 必填；可修改 | 取自主数据-航司管理的航司代码 |
| 飞机类型 | 取值形式：下拉选择；长度或格式：1-10 | 必填；可修改 | 选项：货机、客机。 |
| 板型 | 取值形式：文本；长度或格式：1-10 | 必填；可修改 | 手工录入；唯一。 |
| 别称 | 取值形式：文本；长度或格式：1-10 | 非必填；可修改 | 手工录入。 |
| 体积 | 取值形式：数字；长度或格式：1-10 | 必填；可修改 |  |
| 板型尺寸 | 取值形式：文本；长度或格式：1-50 | 必填；可修改 | 长×高×宽，单位：m。 |
| 限重 | 长度或格式：1-10 | 必填；可修改 | 单位：t。 |

| 场景名称 | 板型管理-新增页面 |
