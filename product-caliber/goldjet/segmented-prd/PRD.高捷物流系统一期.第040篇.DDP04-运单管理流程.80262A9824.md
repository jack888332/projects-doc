### 1.1 航晟物流：运单管理的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 查看运单列表 | 航晟物流 | 运单列表展示各运单，并支持筛选和搜索。 | 2 |  |
| 2 | 查看运单详情 | 航晟物流 | 运单详情展示运单状态和司机反馈记录。 | 3 |  |
| 3 | 运单进入“提货中” | 航晟物流 | 司机确认开始前往提货后，运单状态变更为“提货中”。该状态用于细化过程跟踪，运单不要求必须经历此状态。 | 4 |  |
| 4 | 查看运输轨迹 | 航晟物流 | 系统结合司机反馈的节点数据和 GPS 轨迹数据展示运输轨迹。 | 12 |  |
| 5 | 登录小程序 | 司机 | 司机通过手机号和验证码的方式登录司机端小程序。 | 6 |  |
| 6 | 查看任务列表 | 司机 | 司机可以查看自己的进行中任务和已完成历史任务。 | 7 |  |
| 7 | 查看任务详情 | 司机 | 司机可以查看具体任务的明细。 | 8 | 是 |
| 8 | 确认开始前往提货 | 司机 | 司机在小程序中确认“开始前往提货”。 | 9或10 |  |
| 9 | 确认到达仓库 | 司机 | 司机到达仓库后在小程序中确认到达，确认时间用于计算候车费。 | 4或11或13 |  |
| 10 | 展示到达预报<br>（提货和卸货） | 航晟仓库 | 运单的提货点或卸货点为航晟仓库时，仓库可以查看预计到达时间。 | 13 |  |
| 11 | 判断候车时长是否超过免费时长 | 司机 | 系统根据供应商候车费规则和司机的实际候车时长判断是否收取候车费。 | 12 |  |
| 12 | 查看候车记录和费用 | 航晟物流 | 运单展示已产生的候车记录和候车费。 | 15 |  |
| 13 | 实际到达 | 航晟仓库 | 司机实际到达仓库的时间（以司机自行上报为主）。 |  |  |
| 14 | 判断是否产生压车费 | 司机 | 系统结合供应商压车收费规则判断是否收取压车费。 | 15 |  |
| 15 | 查看压车记录和费用 | 航晟物流 | 运单展示已产生的压车记录和压车费。 | 17 |  |
| 16 | 确认已提货并上传凭证 | 司机 | 司机通过小程序上传提货凭证。 | 17或18 |  |
| 17 | 运单进入“已提货” | 航晟物流 | 运单状态变更为“已提货”，并展示提货凭证。 | 19 |  |
| 18 | 判断是否上报异常 | 司机 | 运输过程发生异常时，司机通过小程序上报异常。 | 20 |  |
| 19 | 查看和处理异常 | 航晟物流 | 运单展示司机提交的异常上报记录，供航晟物流处理。 | 21 |  |
| 20 | 确认到达卸货点 | 司机 | 司机到达卸货点后在小程序中确认到达。 | 22 |  |
| 21 | 运单进入“已到达卸货点” | 航晟物流 | 运单状态变更为“已到达卸货点”。 | 23 |  |
| 22 | 确认已卸货并上传凭证 | 司机 | 司机通过小程序上传卸货凭证。 | 23 |  |
| 23 | 运单进入“已完成” | 航晟物流 | 运单状态变更为“已完成”，并展示卸货凭证。 |  |  |
