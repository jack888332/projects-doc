### 1.1 地面服务单据扫描上传的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 登录小程序 | 地面人员 |  | 2 |  |
| 2 | 选择对应的扫码上传类型 | 地面人员 | 可选择单证上传、回单上传、出仓扫描、货站到达扫描、安检扫描、组板扫描、打板扫描和退货操作的操作。 | 3 | 是 |
| 3 | 扫描单号 | 地面人员 | 对着单号扫一扫，可自动识别单号，也可直接选择无法识别，进入手动编辑单号。 | 4 |  |
| 4 | 单据是否已上传？ | 地面人员 | 根据单号，判断此单号是否在本类别下已操作过，若已操作，则进入修改；若未操作，则进入创建。 | 5或7 |  |
| 5 | 确认单号<br>（可编辑单号） | 地面人员 | 确认识别的单号是否正确，如需要修改，可编辑。 | 6 |  |
| 6 | 拍照或上传图片 | 地面人员 | 可选选择上传相关图片照片等。 |  |  |
| 7 | 查看已上传单据 | 地面人员 | 如此单号已上传，可查看相关记录数据。 | 8 |  |
| 8 | 是否修改 | 地面人员 | 可选择是否重新修改已上传的内容。 | 9 |  |
| 9 | 修改单据信息 | 地面人员 | 可删除已上传的图片，重新上传新的单据照片等。 |  |  |
