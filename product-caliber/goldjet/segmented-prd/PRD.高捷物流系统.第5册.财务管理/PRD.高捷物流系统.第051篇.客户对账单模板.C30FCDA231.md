## 1. 客户对账单模板

<a id="doc-C30FCDA231-section-6229d4936ad5"></a>
### 1.1 模板选用与计算口径

- 按所属公司选用对账单模板，发送给对方核对。

- 业务发送对账单邮件时，自动根据对应公司发送对账单。

对账单模板的计算口径、字段名称、取值来源及展示结构如下。

| 适用模板与字段 | 计算口径 |
| --- | --- |
| 航晟-客户通用对账单 · 合计 | 每个费用价格的汇总。 |
| 航晟-地面操作出口账单模板 · 体积重 | 体积*166.66。 |
| 航晟-地面操作出口账单模板 · 应收金额 | 每个费用价格的汇总。 |
| 航晟-UPS账单模板（清关的账单）· 航晟仓租天数 | 出库日期-卸货日期。 |
| 航晟-UPS账单模板（清关的账单）· 应收金额 | 每个费用价格的汇总。 |
| 航晟-马航账单模板 · 小计 | 每个费用价格的汇总。 |
| 航晟-中赞账单模板 · 总金额 | 每个费用价格的汇总。 |
| 高捷-现金客户账单模板 · RMB | 每个费用价格的汇总。 |
| 高捷-艾莎账单模板 · 杂费 | 费用项除空运费外的费用项合计。 |
| 高捷-艾莎账单模板 · 结算金额（不含税） | 每行【人民币金额/（1+税率）】。 |
| 高捷-得斯威账单模板 · 合计 | 每个费用价格的汇总。 |
| 高捷-利斯账单模板 · Total Amount (总金额) | 每个费用价格的汇总。 |
| 高捷-全球国际账单模板 · 应收金额 | 每个费用价格的汇总。 |
| 高捷-信捷通账单模板 · 总数 | 每个费用价格的汇总。 |
| 高捷-义达账单模板 · 合计 | 每个费用价格的汇总。 |

### 1.2 航晟-客户通用对账单

**界面原型概述 · 航晟-客户通用对账单**

- **区域字段或业务元素**：结果区：日期、单号、件数、装货地址、卸货地址、车牌、车型、动态费用项列、合计、到达工厂时间、装货时间、卸货时间、公司户名、开户银行、帐号RMB。
- **区域级通用规则**：结果区只读展示上述指标。

**模板字段来源与展开规则**

| 模板字段 | 取值、计算或展示规则 |
| --- | --- |
| 日期 | 结算成本里订单的业务日期。 |
| 单号 | 结算成本里的订单号。 |
| 件数 | 结算成本里的数量。 |
| 装货地址 | 运单对应主订单的提货地址。 |
| 卸货地址 | 运单对应主订单的送货地址。 |
| 车牌 | 运单中的车牌号。 |
| 车型 | 运单中的车型。 |
| 动态费用项列 | 按结算成本中的费用项逐项展开为结果列；相关合计字段按展开后的费用列汇总。 |
| 合计 | 结算成本费用项；计算口径见[模板计算口径](#doc-C30FCDA231-section-6229d4936ad5)。 |
| 装货时间 | 订单对应的提货时间。 |
| 公司户名 | 银行账号信息基本户的账户名称。 |
| 开户银行 | 银行账号信息基本户的银行名称。 |
| 帐号RMB | 银行账号信息基本户的银行账号。 |
