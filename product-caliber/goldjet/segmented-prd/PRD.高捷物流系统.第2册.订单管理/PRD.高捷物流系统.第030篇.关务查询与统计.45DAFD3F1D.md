（4）整体业务数据-字段定义

**待确认边界（CUSTOMS-B042）**：日期归属、跨币种金额换算、零分母、取消或终止服务在完成率的归属未定义；南沙合计将业务票数与查验/差错工作量相加，须确认是独立服务量还是操作工作量。 下文涉及该边界的来源约束仅保留待确认，不视为已确定的执行规则。

**待确认边界（CUSTOMS-B043）**：部门汇总的总提单按订单号计数，成员工作量按总运单号计数；指标名称相同但对象粒度不同，应确认是否应分名或统一口径。 下文涉及该边界的来源约束仅保留待确认，不视为已确定的执行规则。

| 统计指标 | 统计口径 |
| --- | --- |
| 业务类型 | 与上方筛选项的业务类型一致 |
| 票数 | 根据业务类型，统计已完成的关务服务单中报关单的数量，一个海关编号就对应一张报关单，要去重 |
| 总提单数 | 根据业务类型，统计已完成的关务服务单中订单号的数量，一个订单号对应一个总提单，要去重 |
| 分单数 | 根据业务类型，统计已完成的关务服务单中分单号的数量，一个分单号对应一个分单，要去重 |
| 总重量 | 根据业务类型，统计已完成的关务服务单中所有报关单上的总毛重，一个报关单只统计一次 |
| 金额 | 根据业务类型，统计已完成的服务单中所有报关单上的总价，一个报关单只统计一次 |
| 运输方式分布统计 | 根据业务类型，统计已完成的服务单中运输方式=空运/海运/陆运的数量，每个服务单只统计一次。 |
| 服务单完成情况 | 根据业务类型，统计未完成、已完成的服务单占比，每个服务单只统计一次。 |
