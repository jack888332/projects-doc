## 1. 报表管理

本篇定义经营、财务和利润指标的查询与统计。对外发送的账单格式见[客户对账单模板](../PRD.高捷物流系统.第5册.财务管理/PRD.高捷物流系统.第053篇.客户对账单模板.C30FCDA231.md#doc-C30FCDA231-statement-templates)。

**业务入口：** 报表管理页面。

**概念模型：** [数据字典 · 派生读模型与业务指标](PRD.高捷物流系统.第063篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-domain-read-models)

### 1.1 报表范围、菜单与角色

报表按经营运营、财务与账龄、业绩利润和对账单模板分组。可独立复用的读模型、指标含义和单位见[数据字典 · 派生读模型与业务指标](PRD.高捷物流系统.第063篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-domain-read-models)；各报表的取值、计算、筛选、字段组合和模板口径在对应场景中定义。

<a id="doc-CF2AF4B8B2-section-2627f0f4404b"></a>
#### 1.1.1 报表范围

报表管理汇总仓储、陆运、空运、电商和财务结算数据，提供经营监控、账龄分析、业绩利润分析与对账单输出。

<a id="doc-CF2AF4B8B2-section-01be2de98e7d"></a>
#### 1.1.2 报表入口与使用角色

以下报表入口均位于“高捷物流平台 → 报表管理”。

各入口的使用角色见[报表与运营大屏访问权限](PRD.高捷物流系统.第064篇.角色与访问权限.5E31456F30.md#doc-5E31456F30-report-entry)。报表查看与导出遵循[关联对象与跨入口访问](PRD.高捷物流系统.第064篇.角色与访问权限.5E31456F30.md#doc-5E31456F30-related-object-access)；指标与业务筛选不替代授权范围。

<a id="doc-CF2AF4B8B2-section-fa3c63032341"></a>
### 1.2 仓储与陆运经营报表

仓储和陆运各月报的生成日期可分别配置，默认每月3日生成上月记录。具体执行时点、指标冻结与重算边界见问题清单 GJ-PRD-218。

### 1.6 陆运月度总览

<a id="doc-CF2AF4B8B2-section-336aafdb8518"></a>
#### 1.6.1 航晟陆运月报

- 查看陆运月度的整体业务概览情况。

- 生成日期可单独配置，默认每月3日生成上月记录；固定执行时点及冻结、重算边界遵循本篇第1.2节。

- 按照月份倒序排序。

**界面原型概述 · 航晟陆运月报**

- **区域字段或业务元素**：查询栏：月份；结果区：月份、调度订单数、完成运输订单数、完成中转订单数、完成总订单数、总应收、总应付、预计盈利。
- **区域级通用规则**：查询栏提供月份筛选，结果区只读展示匹配指标；取值、计算和统计口径按本节后文规则执行。

| 指标 | 取值或计算规则 | 统计口径 |
| --- | --- | --- |
| 月份 | 月份数依次倒序展示，从系统中第一笔订单的月份开始 | 月份为筛选项 |
| 调度订单数 | 该月总已完成的调度订单数（只要订单提交过调度就算） |  |
| 完成运输订单数 | 该月已完成的运输订单总数，运输订单状态=已完成，变更时间为该月 |  |
| 完成中转订单数 | 该月已完成中转订单总数，中转订单状态=已完成，变更时间为该月 |  |
| 完成总订单数 | 完成总订单数=完成运输订单数+完成中转订单数 |  |
| 总应收 | 该月已完成的所有订单的订单应收金额累计（取业务主管审批通过后的数据即可） |  |
| 总应付 | 该月已完成的所有订单的订单应付金额累计（取业务主管审批通过后的数据即可） |  |
| 预计盈利 | 预计盈利=总应收-总应付 |  |
