### 1.2 仓库报价维护功能与规则

<a id="doc-26A37BCF5F-section-6c1bf616eba4"></a>
#### 1.2.1 报价管理页面

仓库管理页面，可以查看、新增、修改所有的仓库报价信息。

<a id="doc-26A37BCF5F-section-5170c8593ebb"></a>
#### 1.2.2 仓库报价新增原型页面

（1）仓库报价新增界面

1. 按钮说明

- 提交：提交时对必填信息、报价信息进行校验，若必填项为空时，则系统提交时会标红提示该错误，并不允许提交；如果报价相同且有效日期重叠，那么提交时失败，并提示“已存在报价，请勿重复添加”。根据字段：客户、报价科目、生效日期、截止日期判断。如果客户、报价科目相同且生效日期重叠，则判断为相同报价。

- 取消：取消新增仓库报价，并返回仓库报价列表。

- 查询：在不选择任何查询字段下，点击“查询”按钮，默认所有查询条件。选择对应的查询条件，则显示符合结果的数据。查询出的数据，按照客户首个字母拼音顺序排列。

- 重置：重置查询条件。

- 修改：点击跳转前，确认是否保存当前报价，跳转至“修改仓库报价记录”页面。

- 失效/启用：“生效”的报价在未到截止日期可以人为点击“失效”停用该报价。点击“启用”可以重新使“失效”并且还在“截止日期”内的报价生效。

- 新增：重置当前的新增中的报价。

1. 字段说明

字段定义见 [数据字典 · 仓库报价新增字段](PRD.高捷物流系统一期.第050篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-008-001)。

1. 业务规则说明

| 场景名称 | 仓库客户报价管理-仓库客户报价新增 |
| --- | --- |
| 范围/概述 | 填写客户信息、报价信息，提交完成报价新增。 |
| 主要参与者 | 航晟客服、主管 |
| 前置条件 | 进入仓库客户报价管理，点击“新增报价”按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，选择客户，可成功提交或提示输入错误。 |
| 主业务流程 | 进入“新建报价”页面，填写：客户信息、报价信息。<br>1. 客户信息：<br>- 客户：所有客户，由系统合作方档案管理类型为“客户”带出。<br>- 税率（%）：填写税率，最大值不能大于100，提交时校检，保留小数点2位。<br>- 币种：选择结算的币种代码，和结算系统的币制代码一致。<br>- 未保存前，可重新修改客户信息。<br>1. 报价信息：<br>- 报价科目：选择一个报价科目。<br>- 报价金额：录入数值，保留小数点后2位。<br>- 未保存前，可重新修改报价信息。<br>- 生效日期：生效日期默认为提交报价当天。录入的为截止日期，格式“YYYY-MM-DD”。<br>- 截止日期：录入的为截止日期，格式“YYYY-MM-DD”。<br>- 未保存前，可重新修改报价信息。<br>点击“确认”进行提交保存。<br>- 提交成功：一闪而过的提示语“保存成功”，跳转到“仓库客户报价管理列表”界面。<br>- 无法提交：若必填项未输入，则该输入项红色highlight提醒； |
| 业务分支 | 供应商列表页面“上传报价”按钮，支持通过excel表格批量上传，按照上传模板填好必填的信息。上传时会校检必填信息和去重已存在的报价。支持xls、xlsx格式 |
