<a id="doc-7A78DCFDE1-section-f72acc128a83"></a>
### 1.3 空运报关单处理功能与规则

<a id="doc-7A78DCFDE1-section-5541f601deef"></a>
#### 1.3.1 报关单管理

- 报关行客服完成报关服务。

<a id="doc-7A78DCFDE1-section-7065db37e683"></a>
#### 1.3.2 报关单列表筛选项

**界面原型概述 · 报关单列表筛选栏**

- **区域字段或业务元素**：报关服务号、提单号、始发港、目的港、客户、出港日期、创建日期、报关状态。

| 字段或控件特例 | 适用条件 | 特例约束或业务结果 |
| --- | --- | --- |
| 报关服务号、提单号、客户 |  | 支持模糊查询。 |
| 始发港、目的港 |  | 默认值：全部。 |
| 出港日期、创建日期 |  | 按日期筛选；如果不筛选，默认为全部。 |
| 报关状态 |  | 全部/单证预审/报关审结/报关查验/放行/已结关。 |

<a id="doc-7A78DCFDE1-section-90f9ce4536e5"></a>
#### 1.3.3 报关材料与状态管理规则

| 场景名称 | 报关单管理-报关单列表 |
| --- | --- |
| 范围/概述 | 报关行客服接受材料，修改报关状态 |
| 主要参与者 | 报关行客服 |
| 前置条件 | 空运客服发出报关服务指令 |
| 业务结果 | 列表展示符合条件的报关单；报关行客服可下载已有材料、发起材料补齐通知并维护报关状态。 |
| 主业务流程 | 1. 进入《报关单管理》页面后按条件查询，报关单按创建时间排序。<br>2. 材料下载：空运客服发送服务指令时明确报关类型和单证类型，并按单证类型上传报关材料。报关行客服点击“下载”后查看全部已上传材料，支持单个或批量下载；未上传的材料不显示PDF下载按钮。<br>3. 材料补齐：材料不符合要求时，报关行客服可单个或批量发起补齐通知，通知规则见[消息推送规则](PRD.高捷物流系统一期.第030篇.消息推送.5F950AB3B1.md#doc-5F950AB3B1-section-ef4930471a81)。<br>4. 状态管理：报关单初始状态为“单证预审”。 |
