1. 列表说明

- 排序规则：页面中的字段排序参照原型，查询的数据排列规则优先按照司机状态排序，状态为“正常”和“休假”的优先排序，“已离职”则较低，然后按照司机姓氏首个拼音字母顺序排序。

- 驾驶证期限、资格证有效期：日期格式为“YYYY-MM-DD”，证件期限的前一个月，系统会通过小程序发送一条通知给该司机。如：xxx驾驶证还有一个月即将到期，请及时处理更新。在司机列表页面上标红显示。

- 当年累计任务执行：系统查询运单，不可编辑修改。根据司机姓名统计当年执行的任务次数，统计条件包括运单“已完成”状态，单位（次），正整数。

- 本月任务执行：系统查询运单，不可编辑修改。根据司机姓名统计本月执行的任务次数，统计条件包括运单状态为“已完成”状态的，单位（次），正整数。

- 本周任务执行：系统查询运单，不可编辑修改。根据司机姓名统计本周执行的任务次数，统计条件包括运单状态为“已完成”状态的，单位（次），正整数。

- 当年累计运单应收：系统查询运单，不可编辑修改。根据司机姓名统计当年执行的任务统计应收金额，运单应收统计条件包括运单“已完成”、“已取消”状态的，单位（元），保留小数点后2位。

1. 业务规则说明

| 场景名称 | 油耗管理--新增油耗记录 |
| --- | --- |
| 范围/概述 | 输入车辆油耗记录，提交完成新增油耗记录。 |
| 主要参与者 | 航晟主管 |
| 前置条件 | 在油耗管理页面，点击《新增油耗》按钮，跳转到此页面 |
| 业务结果 | 录入新增油耗记录的必填信息，且符合规范要求，则新增提交成功。 |
| 主业务流程 | 进入《新建油耗》页面，输入：车辆信息、油耗管理信息和油卡管理信息。<br>车辆信息：<br>- 车牌号：由航晟内部在车辆管理录入的车牌号带出，下拉搜索框可以联想搜索，如输入“港F”，则显示和“港F”相关的车牌号，为必填项。<br>- 油卡号：录入油卡号数字19位，为必填项。<br>- 日期：车辆油耗的时间，由操作员按实际填写，格式“2020-01-01”，为必填项。<br>油耗管理：<br>- 当前行驶总里程：单位（KM），由操作员按实际填写，保留小数点后2位，为必填项。<br>- 加油油量：单位（L），由操作员按实际填写，保留小数点后2位，为必填项。<br>- 加油里程=本次的当前行驶总里程-上次的行驶总里程，单位为（KM）。填写后当前行驶总里程后系统自动运算，保留系统小数点后2位。<br>- 百公里油耗=100*（上一次的加油量/加油里程），单位（L），保留小数点后2位，填写后当前行驶总里程后系统自动运算。<br>- 油价：单位（元/L），油价=支付金额/加油油量，填写完油量和支付金额时由系统实时自动计算，保留小数点2位数。<br>油卡管理<br>- 充值金额：操作员据油卡充值额度填写，单位（元），保留小数点后2位。<br>- 支付金额=加油油量*油价，填写完油量和支付金额时系统自动计算，保留小数点2位数。<br>- 油卡结存=历次充值金额总值-历次支付金额总值，填写完油量和支付金额时系统自动计算，保留小数点2位数。<br>点击《提交》进行提交保存。<br>- 提交成功：一闪而过的提示语“提交成功”，跳转到油耗管理页面。<br>- 无法提交：若必填项未输入，或输入长度格式不符合要求，则该输入项红色highlight提醒，《提交》按钮置灰不可点击。 |
| 业务分支 | 提交成功后，系统会根据车牌号、油卡号查询到最近的一次油耗记录，并取相应的数据运算。如果车辆或者油卡号是第一次新增油耗记录，那么默认车辆或者车牌的上一次数据都为0。 |
| 关联功能 | 新增油耗记录时，相关的车牌号会在对应的详情页面展示该油耗记录。 |
