#### 1.1.2 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 录入客户报价信息 | 航晟物流客服 | 通过新建对客户的报价记录的方式录入报价。 | 2 | 是 |
| 2 | 是否录入单价？ | 航晟物流客服 | 由于在业务中，报价分成2种不同的计费模式，单价和提货费两者2选1 录入，不可同时录入。 | 3或4 |  |
| 3 | 按照提货费（元/车）收费。 | 航晟物流客服 | 若未录入单价（元/kg），则按照提货费（元/车）进行收费。 |  |  |
| 4 | 单价（元/kg）*重量*车型数量>最小收费，则按前者收费，反之按照最小收费计费。 | 航晟物流客服 | 若录入了单价（元/kg），则可同时录入最小收费。最小收费与单件（元/kg）*实际重量对比，若不足最小收费，则按最小收费计算。若未录入最小收费，则直接按照单价（元/kg）*实际重量计费。 | 5 |  |
| 5 | 查看报价信息 | 航晟物流客服 | 对已录入的客户报价会在列表页面上进行展示，而且提供各种方便的快捷筛选项功能便于快速筛选过滤查找。 | 6 |  |
| 6 | 是否需要修改？ | 航晟物流客服 | 如发现录错的报价记录或需要编辑更新，则可通过对该报价记录进行编辑的方式，进行管理维护。 |  |  |
| 7 | 编辑报价记录<br>（含删除） | 航晟物流客服 | 对报价记录可进行编辑和删除，并可选中多条记录进行批量删除。 |  |  |

<a id="doc-95596E0C16-section-1023cdfad791"></a>
#### 1.1.3 关键控制点

| 所属步骤 | 关键控制点描述 |
| --- | --- |
| 2 | 新增客户报价记录，可录入如下信息：<br>1. 客户；（取财务建档的供应商选择，全称显示）<br>2．税点（%）；<br>3．币种；<br>4. 有效期截止；（报价有效期）<br>5. 提货点；<br>6. 卸货点；<br>7. 车型；<br>8. 车辆信息；<br>9. 提货费；<br>10. 单价（元/车）；（提货费与单价只能2选1录入）<br>11. 最小收费；（可选录入）<br>12. 运输实效(小时）；<br>13. 温控；（是否冷藏车）<br>14. 是否往返；（单程还是往返）<br>15. 压车费；（压车规则待定？）<br>16. 候车费；（候车费规则？）<br>17. 备注； |
