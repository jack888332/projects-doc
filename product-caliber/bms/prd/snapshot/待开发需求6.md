# 待开发需求：实付返款算法、返款汇率与汇兑损益金额

## 1. 需求概要

| 项目 | 内容 |
| --- | --- |
| 需求目的 | 明确返款账单怎样从应付返款计算实付返款、返款汇率从哪里取得、汇兑损益怎样计算和展示，避免用订单费用报表导入的返款汇率或实付返款代替账单计算。 |
| 变更范围 | 返款账单金额计算顺序、返款汇率定义与锁定、订单费用报表导入范围、汇兑损益计算与展示、历史数据保留。 |
| 需求类型 | 修改项 |
| 主要结果 | 后续订单费用报表只导入`实收回款`和`回款汇率`；返款账单按`货款原始币种 → 货款结算币种`锁定返款汇率，并按方案 2 计算`实付返款`；汇兑损益只在返款账单中计算和展示。 |

## 2. 本次变更

### 2.1 实付返款算法

#### 2.1.1 变更前

| 适用场景 | 原有处理 | 原有结果 |
| :--- | :--- | :--- |
| 返款账单金额顺序 | 先按`货款换算汇率`把`应付返款`换算为货款结算币种，得到`实付返款（准）`，再扣除指定扣减费项得到`实付返款（正）` | 指定扣减费项在换算后扣减，扣减金额使用货款结算币种 |
| 汇率来源 | 订单费用报表可导入`返款汇率`和`实返货款`；返款账单不使用它们计算，但保留为来源展示 | `货款换算汇率`由配置取得，来源汇率仅用于追溯和人工核对 |
| 汇兑损益 | 回款管理按回款金额与`实付返款（准）`比较，币种不一致时显示`--` | 回款管理始终展示汇兑损益 |

#### 2.1.2 变更后

| 步骤 | 处理口径 | 不满足时的处理 |
| :--- | :--- | :--- |
| 1. 识别应付返款 | `应付返款（即代收货款） = 到付金额 - 到付附加费总额`，使用货款原始币种 | 缺少到付金额或应付返款本金时，受影响业务订单不得进入本次返款账单 |
| 2. 汇总指定扣减 | 将返款账单指定扣减费项统一换算为货款原始币种后汇总 | 缺少必要汇率时，受影响业务订单不得进入本次返款账单 |
| 3. 计算换算前返款 | `实付返款（准） = 应付返款 - 返款账单指定扣减费项`，结果仍使用货款原始币种 | 结果触发负数处理规则时，按`7.5`配置顺延或反向计入应收 |
| 4. 锁定返款汇率 | 按真实的货款原始币种和货款结算币种取得`返款汇率`并随账单保存快照；同币种固定为`1` | 按`15.3.1`汇率层级处理 |
| 5. 计算实付返款 | `实付返款 = 实付返款（准） × 返款汇率`，币种为货款结算币种 | 缺少必要汇率时，受影响业务订单不得进入本次返款账单 |
| 6. 校验收款账户 | 客户收款账户币种必须等于货款结算币种 | 未配置同币种账户时，配置不得保存，受影响账单不得生成或执行返款 |

#### 2.1.3 本次规则变化

| 规则主题 | 修改前 | 修改后 |
| :--- | :--- | :--- |
| 金额顺序 | 先换算、后扣减 | 先扣减、后换算 |
| 汇率定义 | `货款换算汇率`，来源值仅作展示 | `返款汇率 = 货款原始币种 → 货款结算币种`，随账单锁定 |
| 报表导入 | 可导入`返款汇率`和`实返货款` | 只导入`实收回款`和`回款汇率`；历史`实付返款`和`返款汇率`停止新增 |
| 汇兑损益位置 | 回款管理展示 | 只在返款账单详情和面向财务的内部导出展示 |

### 2.2 汇兑损益金额怎样计算（修改）

1. 返款金额基数是换算前的`实付返款（准）`，不是已经换算为货款结算币种的最终`实付返款`：`汇兑损益金额 = 实付返款（准） ×（标准化回款汇率 - 标准化返款汇率）`。
2. 两个汇率相减前必须具有完全相同的左侧币种、右侧币种和汇兑方向；比较货币对以回款汇率的货币对和汇兑方向为准。
3. 返款汇率与回款汇率货币对一致时，直接作为标准化返款汇率；不一致时，使用账单已锁定的汇率换算为回款汇率货币对，不得直接相减。例如回款汇率为`TWD → CNY`、返款汇率为`TWD → USD`时，须通过账单锁定的`USD → CNY`汇率计算`标准化返款汇率 = TWD → USD × USD → CNY`；中间汇率方向相反时先取倒数再参与换算。
4. 货款原始币种与回款汇率左侧币种不一致时，须先按账单锁定汇率把`实付返款（准）`换算为比较货币对的左侧币种，再代入公式。
5. 缺少回款汇率且实收回款继续使用货款原始币种时，标准化回款汇率按同币种汇率`1`处理；若返款汇率也为同币种，汇兑损益金额为`0`。除此之外，缺少回款汇率或必要换算汇率时，返款账单仍须显示`汇兑损益金额`字段，字段值为`--`并说明缺失项。
6. 汇兑损益金额只在返款账单详情和面向财务的内部导出中展示，回款管理、客户页面、客户邮件和面向客户的对账报表均不得展示。
7. 汇兑损益不参与`实付返款`、已返金额、待返金额或核销金额，也不回写订单费用报表的`实收回款`和`回款汇率`。

例如：到付金额为`70 TWD`，到付附加费为`10 TWD`，指定扣减费项为`20 TWD`，则`实付返款（准） = 40 TWD`。回款汇率为`0.2`、返款汇率为`0.15`且货币对均为`TWD → CNY`时，`汇兑损益金额 = 40 ×（0.2 - 0.15）= 2 CNY`。

## 3. 变更后的边界与结果

| 内容 | 本次规则 |
| :--- | :--- |
| 生效范围和时点 | 适用于按当前返款账单配置新生成的账单，以及规则允许重算的未发出账单；账单生成时锁定本次使用的返款汇率。 |
| 存量数据与已生效结果 | 历史包裹侧`实付返款`和`返款汇率`只保留原记录，不再展示，不参与返款账单的结算币种、返款汇率、金额计算或核销；已发出、已结清或其他不允许重算的账单不自动改写。 |
| 来源缺失 | 缺少返款汇率时，受影响业务订单不得进入本次返款账单；未配置同币种客户收款账户时，配置不得保存，受影响账单不得生成或执行返款。缺少回款汇率但实收回款继续使用货款原始币种时，按同币种汇率`1`处理；其它缺少回款汇率或必要换算汇率时，汇兑损益显示为`--`并说明缺失项。 |
| 展示边界 | 汇兑损益仅财务可见，不进入客户页面、客户邮件和面向客户的对账报表。 |
| 下游结果 | 返款账单详情展示完整金额链路和汇兑损益；`实付返款`、已返金额、待返金额和核销金额不因汇兑损益改变。 |
