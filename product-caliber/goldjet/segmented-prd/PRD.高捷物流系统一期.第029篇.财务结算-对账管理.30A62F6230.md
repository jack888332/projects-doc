### 1.1 结算业务范围、角色与流程

<a id="doc-30A62F6230-section-ca8ee6274cde"></a>
#### 1.1.1 产品整体描述

此文档主要描述结算中心的应用层财务结算的操作页面和字段展示。

财务中心作为业务中台之一，其在高捷的业务域包括：订单成本、结算对账、收付款申请、销项票管理、收付款核销。

财务结算模块内容为业务部门和财务部门共同使用。有：订单成本维护、调整单维护、结算成本审批、结算费用查询；应付对账单维护、应付对账单审批、应收对账单维护、应收对账单审批、对账单查询；付款申请维护、付款申请审批、收款申请维护、收款申请审批、收付款申请查询；销项发票申请、手工发票补录、开票申请查询；付款核销、付款核销打回、收款核销、收款核销打回、收付款核销查询。

#### 1.2.8 新建应付对账单保存原型

（1）新建对账单保存界面

新建应付对账单原型界面，点击“保存”按钮，弹出“保存确认”弹框。

（2）按钮说明

- 确认：完成保存，自动生成对账单单号，规则BL+6位年月（YYMMDD）+5位流水。保存完成后返回“待对账单列表”界面，将对账单数据状态变为“新建”。

- 取消：取消保存操作，返回“新建应付对账单”界面。

<a id="doc-30A62F6230-section-aa7c71547735"></a>
#### 1.2.9 新建应付对账单确认原型

（1）新建对账单提交界面

新建应付对账单原型界面，点击“保存并确认”按钮，弹出“确认对账单无误”弹框。

（2）按钮说明

- 确认：供应商已确认该对账单无误，自动生成对账单单号，规则BL+6位年月（YYMMDD）+5位流水。保存完成后返回“待对账单列表”界面，将对账单数据状态变为“已确认”。

- 取消：取消保存操作，返回“新建应付对账单”界面。

#### 1.2.11 业务规则说明

| 场景名称 | 应付结算信息管理-应付对账单新增 |
| --- | --- |
| 范围/概述 | 选择结算单位，勾选结算明细数据，录入备注、上传附件，完成应付对账单新增 |
| 主要参与者 | 业务/财务 |
| 前置条件 | 进入结算对账管理->应付对账管理->待对账列表页面，勾选需要生成对账单的订单信息（订单信息必须要同一个结算单位），点击“新增”按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，对勾选的订单、录入的信息已经上传的文件进行校验，可成功提交或提示输入错误。 |
| 主业务流程 | 勾选结算明细数据，进入“新建应付对账单”页面，录入备注和上传附件。<br>1. 备注：<br>- 输入200个字符串以内的内容。<br>- 未保存前，可重新输入备注。<br>1. 附件：<br>- 上传的附件格式只能是文档格式、图片格式，大小限制在20m以内。<br>- 未保存前，可重新上传。<br>明细信息每页显示50页，支持翻页。<br>点击“保存”进行保存确认。<br>- 确认：自动生成对账单号，规则BL+6位年月日（YYMMDD）+5位流水，如BL20112600002，把数据状态改成“新建”状态，跳转到“应付待对账单列表”界面。<br>- 取消：不确认保存该对账单。<br>点击“保存并确认”进行提交保存。<br>- 确认：自动生成对账单号，规则BL+6位年月日（YYMMDD）+5位流水，如BL20112600002，把数据状态改成“已确认”状态，跳转到“应付待对账单列表”界面。<br>- 取消：不确认保存该对账单。 |
| 特殊需求 | 应付对账单模板 |
| 关联功能 | 1.结算成本维护<br>2.付款申请 |

#### 1.2.18 新建应收对账单原型

（1）新建对账单界面

在待对账列表，按照查询条件查询对应的待对账数据，可“按勾选数据”或“按查询条件”创建对账单。只有相同的结算单位才可以创建对账单。

（2）按钮说明

- 保存：点击“保存”按钮，弹出“保存确认”弹框。

- 保存并确认：点击“保存保存并确认”按钮，弹出“确认对账单无误”弹框。

- 返回：取消新增本次对账单，跳转至“待对账列表”界面。

- 导出：按照高捷标准对账单模板，导出对账单数据。
