#### 1.2.3 材料、接单与状态管理规则

| 场景名称 | 清关派送管理-清关派送列表 |
| --- | --- |
| 范围/概述 | 海外部客服下载相关清关派送材料，修改清关派送状态 |
| 主要参与者 | 海外部客服 |
| 前置条件 | 空运客服发出清关派送服务指令 |
| 业务结果 | 列表展示符合条件的清关派送订单；海外部客服可处理材料、接单并记录目的地提货或清关送达结果。 |
| 主业务流程 | 1. 查询：进入《清关派送管理》页面后按条件查询，订单按创建时间倒序排列。<br>2. 上传：附件必填，支持`.rar`、`.zip`、`.docx`、`.doc`、`.xls`、`.xlsx`、`.pdf`、`.jpg`格式，单个附件不超过20 MB；保存前可删除并重新上传。<br>3. 下载：空运客服发送服务指令时上传清关派送材料。海外部客服点击“下载”后查看全部已上传材料，支持单个或批量下载。系统按航司从模板管理生成PDF格式的提单、分单和舱单；其他文件取空运客服上传的材料。<br>4. 目的地提货：勾选后显示“操作时间”和数量字段，操作时间默认取当前时间。确认保存后，清关派送服务状态由“服务中”变为“服务已完成”，订单状态变为“目的地提货”。剩余毛件体=提单剩余数量-当前录入数量，支持多次提交。<br>5. 清关送达：勾选后显示“操作时间”和数量字段，操作时间默认取当前时间。确认保存后，清关派送服务状态变为“服务已完成”，订单状态变为“清关送达”。剩余毛件体=提单剩余数量-当前录入数量，支持多次提交。<br>6. 接单：记录接单用户名和操作时间。 |
