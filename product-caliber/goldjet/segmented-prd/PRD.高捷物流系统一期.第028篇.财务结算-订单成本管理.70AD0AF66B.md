### 1.2 产品概述

<a id="doc-70AD0AF66B-section-e5d5791a938a"></a>
#### 1.2.1 产品整体描述

此文档主要描述结算中心的应用层财务结算的操作页面和字段展示。财务作为业务中台之一，其在高捷的业务域包括：订单成本、结算对账、收付款申请、销项票管理、收付款核销。

财务结算模块内容为业务部门和财务部门共同使用。有：订单成本维护、调整单维护、结算成本审批、结算费用查询；应付对账单维护、应付对账单审批、应收对账单维护、应收对账单审批、对账单查询；付款申请维护、付款申请审批、收款申请维护、收款申请审批、收付款申请查询；销项发票申请、手工发票补录、开票申请查询；付款核销、付款核销打回、收款核销、收款核销打回、收付款核销查询。

#### 1.3.19 业务规则说明

| 场景名称 | 财务结算管理-结算费用新增 |
| --- | --- |
| 范围/概述 | 选择订单数据，点击新增应收/新增应付，进行应收/应付的录入，选择(子)单号、结算单位、成本项目、数量、计费单位、税率(%)、含税单价(原币)、约定汇率、备注、上传附件，完成应收/应付成本的新增 |
| 主要参与者 | 业务 |
| 前置条件 | 进入结算成本管理->订单成本列表，选择需要录入应收应付的订单，点击“成本编辑”按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，能够正常录入信息，可勾选数据提交给主管、财务审批，可成功提交或提示输入错误。 |
| 主业务流程 | 选择订单，进入“订单成本维护”页面，选择(子)单号、结算单位、成本项目、数量、计费单位、税率(%)、含税单价(原币)、约定汇率、备注、上传附件。<br>1. (子)单号：<br>- LOV选择，只能选到主体为该公司的且和该订单关联的订单、分单/服务单。<br>- 未保存前，可重新录入修改。<br>1. 结算单位：<br>- LOV选择，所有与该公司关联的客户，支持手工录入模糊匹配。<br>- 未保存前，可重新录入修改。<br>1. 成本项目<br>- LOV选择，只能选择到订单头“业务类型”关联的“成本项”。需从“业务类型与成本项”关系中选择。<br>- 未保存前，可重新录入修改。<br>1. 数量<br>- 手工录入计费的数量<br>- 未保存前，可重新录入修改。<br>1. 计费单位<br>- 手工录入计费单位<br>- 未保存前，可重新录入修改。<br>1. 币种<br>- LOV选择，默认CNY人民币，可修改为其他币种;<br>- 未保存前，可重新录入修改。<br>1. 税率(%)<br>- LOV选择，默认0税率；不含税则选择0税率。<br>- 未保存前，可重新录入修改。<br>1. 含税单价(原币)<br>- 手工录入含税单价(原币)<br>- 未保存前，可重新录入修改。<br>1. 约定汇率<br>- 系统自动带出，根据选择的币种、该成本行创建日期，带出即期汇率后，默认约定汇率<br>- 未保存前，可重新录入修改。<br>1. 备注<br>- 手工输入该行成本的备注<br>- 未保存前，可重新录入修改。<br>1. 附件<br>- 上传成本行的附件<br>- 未保存前，可重新录入修改。<br>应收应付栏各显示5行数据，支持下拉查看。<br>点击“保存”进行保存确认。<br>- 确认：自动生成对账单号，规则BL+6位年月日（YYMMDD）+5位流水，如BL20112600002，把数据状态改成“新建”状态，跳转到“应收待对账单列表”界面。<br>- 取消：不确认保存该对账单。<br>点击“保存”完成该行成本的录入。<br>- 保存校验：校验是否有必填字段没有填写，若存在必填字段没有填写，无法保存。<br>- 删除：不保存成本。 |
| 业务分支 | 勾选对应数据，点击“提交”，提交给主管、财务审批<br>- 提交后，该行数据状态变为“已提交”，无法继续在该行数据继续编辑。<br>业务部门审批<br>- 业务部门审批通过，该行数据状态变为“业务审批通过”，等待财务进行审批<br>- 业务部门审批拒绝，该行数据状态变为“业务审批拒绝”，该行数据业务员可以进行编辑。<br>财务部门审批，财务部门在业务部门审批通过的数据上继续审批<br>- 财务部门审批通过，该行数据状态变为“财务审批通过”，该数据同步金碟系统；同步的入账日期为“业务部门审批通过的日期”。<br>- 财务部门审批拒绝，该行数据状态变为“财务审批拒绝”，该行数据业务员可以进行编辑。。 |
