#### 1.2.6 逆向流程节点说明

| 流程点 | 异常节点 | 前置条件 | 后续处理 |
| --- | --- | --- | --- |
|  | 取消调度 | 结合订单管理PRD中说明的订单取消场景。<br>此外，运单状态=已卸货或已取消，则不可取消调度。 | 一旦调度取消，运单状态更新为“已取消”。系统根据报价管理中的“返空费比例”乘以运输费（提货总价模式下），自动算出返空费金额，写入该运单的应收付账单中。 |
|  | 修改调度 | 仅在运单状态=“待提货”时，允许修改调度。否则，必须要先取消调度，然后重新录入新调度。 | 修改后的调度信息，实时更新在原运单上。 |
|  | 异常上报 | 只要运单状态≠已取消，司机或航晟客服便可对指定运单上报异常。 |  |

<a id="doc-20AA542560-section-7abde6482646"></a>
#### 1.2.7 场景举例

1. 当前订单状态=已调度或异常中，该订单下属3个运单，其中1个运单状态=已卸货，另外2个运单状态=提货中；

2. 此时，发起取消订单操作；

3. 处理结果：订单状态更新为“已取消”，原“已卸货”状态的运单无影响（其早已生成了相应的应收付记录），而另外2个“提货中”的运单则状态更新为“已取消”，并产生相应的应收付“返空费”。

| 特殊需求 | 接收WMS的调度信息，如出现如下情况，则反馈报错回WMS：<br>1. 无法匹配（状态=“待调度”的同“订单号”中转订单）；<br>1. 供应商名称与合作方档案管理中的数据不匹配；<br>1. 车牌号、供应商名称字段未传值，或传值不符合规范； |

#### 1.3.24 业务规则说明

| 场景名称 | 中转运单详情 |
| --- | --- |
| 范围/概述 | 展示运单详情、轨迹记录、应收付账单、异常管理和单据管理。 |
| 主要参与者 | 航晟客服 |
| 前置条件 | 从中转运单列表页面中的“操作”项下的“查看详情”按钮进入。 |
| 主业务流程 | 1. 运单详细信息部分，新增展示“封条号”字段。<br>1. 轨迹记录：若WMS反馈的调度信息，匹配成功。则该中转运单此时自动生成2条轨迹记录，既“调度完成”和“已提货”的轨迹事件。<br>1. 应收付账单：页面复用运输运单的应收付页面。<br>- 由于是中转的短途运输，所以，提货计费=提货重量（WMS的出库重量）*对应客户/供应商的单价报价标准（一般为0.1元/kg）。由此，算上应收的提货费，而应付的提货费由于届时会配置成0元/kg，所以算出的应付提货费为0元。<br>1. 异常管理：页面复用运输运单的异常管理页面，支持后台录入新增异常。<br>1. 单据管理：页面复用运输运单的单据管理页面，支持后台录入新增单据。 |
