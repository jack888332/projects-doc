#### 1.2.3 专用名词解释

受控术语定义见 [数据字典 · 受控业务术语](PRD.高捷物流系统一期.第050篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-terms-controlled)。

#### 1.3.9 业务规则说明

| 场景名称 | 舱位管理-舱位实时查询 |
| --- | --- |
| 范围/概述 | 查看目前舱位的实际使用情况 |
| 主要参与者 | 业务：查看目前剩余舱位体积数<br>航线运营：查看目前剩余舱位体积数、编辑备注<br>航线操作：查看目前剩余舱位体积数 |
| 前置条件 | 进入舱位实时查询页面，通过浏览和筛选，快捷找到舱位信息 |
| 业务结果 | 页面筛选等操作功能可正常使用 |
| 主业务流程 | 1. 在未搜索前，列表的航班按照出港日期的顺序依次展示。出港日期最近的放在前列。列表呈分页形式，展示10行明细。<br>1. 始发港、目的港、出港日期、起飞时刻、到港时刻、截单时刻取自基础数据。舱位总体积：系统要依据航线部事先维护的舱位产品管理数据，计算出当前高捷在这个航班、这个出港时间所维护的舱位总体积。<br>3、已订舱位体积：已绑定提单号（订舱服务完成）的订单上的货物体积之和。如果此时没入仓库就取客户提供的体积。当入仓后，取仓库提供的体积。当进货站后，取入货站的体积。<br>剩余舱位体积= 舱位总体积-已订舱位体积。<br>3、备注：仅航线运营可以编辑，且只能编辑其在舱位产品管理页面维护的产品的备注。如有另外的运营人员需要编辑备注，则要先修改该产品在舱位产品管理的运营人员名字。该运营人员才可编辑备注。 |
