### 1.1 地面服务单据扫描上传的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 登录小程序 | 地面人员 |  | 2 |  |
| 2 | 选择扫码上传类型 | 地面人员 | 选择单证上传、回单上传、出仓扫描、货站到达扫描、安检扫描、组板扫描、打板扫描或退货操作。 | 3 | 是 |
| 3 | 扫描单号 | 地面人员 | 扫描并自动识别单号；无法识别时，地面人员手工录入单号。 | 4 |  |
| 4 | 判断本类单据是否已上传 | 地面人员 | 系统按上传类型和单号查找记录。已有记录时进入查看和修改；没有记录时创建单据。 | 5或7 |  |
| 5 | 确认单号 | 地面人员 | 地面人员核对识别出的单号，必要时手工修改。 | 6 |  |
| 6 | 拍照或上传图片 | 地面人员 | 地面人员可以拍照或从本地选择图片上传。 |  |  |
| 7 | 查看已上传单据 | 地面人员 | 已有相同类型和单号的记录时，展示已上传内容。 | 8 |  |
| 8 | 判断是否修改 | 地面人员 | 地面人员决定是否修改已上传内容。 | 9 |  |
| 9 | 修改单据信息 | 地面人员 | 地面人员可以删除已有图片并重新上传单据图片。 |  |  |
