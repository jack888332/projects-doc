# 变更需求：将账单配置中的结算币种规则改为表格维护

## 变更原因

目前，应收账单配置中的费项默认结算币种和费项指定结算币种分开维护；返款账单配置中的货款原始币种、货款结算币种和客户收款账户也使用不同的字段或控件维护。财务配置多条币种规则时，无法在同一区域查看明确规则和兜底规则，也难以判断每条规则使用哪个默认值。

本次变更将应收账单和返款账单的结算币种规则改为表格维护。财务可以在同一张表中新增明确规则、查看兜底规则，并为返款币种规则填写客户收款账户。

## 变更范围

- 修改应收账单配置中的“费项结算币种”设置。
- 修改返款账单配置中的“货款结算币种”和“客户收款账户”设置。
- 不修改应收账单配置和返款账单配置中的其他设置。
- 不修改已经生成的应收账单和返款账单。

## 变更内容

### 1. 两类配置共用的表格规则

- 应收账单配置和返款账单配置分别使用一张表维护结算币种规则。
- 每张表必须且只能保留一条兜底行，兜底行始终位于表格末行。
- 点击表格工具栏中的“添加”后，系统在表格首行增加一条明确规则，原有兜底行仍保留在末行。
- 兜底行不能修改用于识别匹配范围的字段，也不能删除。
- 表格不分页，不支持调整列的位置，也不支持按列排序数据。
- 保存配置时，系统必须逐行检查本章规定的必填项、重复规则和兜底行位置。任一规则不符合要求时，系统不得保存配置，并提示具体出错行和出错字段。

### 2. 应收账单配置

#### 2.1 调整表格名称和字段

- 系统移除“费项默认结算币种”设置。
- 系统将“费项指定结算币种”更名为“费项结算币种”。
- 系统移除原表格中的“指定币种”列。
- “费项结算币种”表格只展示“费项”“结算币种”和“操作”三列。
- “费项”和“结算币种”两列使用相同的默认宽度。

#### 2.2 处理兜底行

- 当表格只有兜底行时，兜底行的“费项”显示“全部”。
- 当表格存在一条或多条明确规则时，兜底行的“费项”自动显示“其他”。
- 当财务删除明确规则，表格重新只剩兜底行时，兜底行的“费项”自动恢复为“全部”。
- 兜底行的“费项”使用禁用状态的输入框展示，财务不能修改该字段。
- 兜底行的“结算币种”可以选择“随原始币种”，也可以选择一个明确币种。

#### 2.3 新增和删除明确规则

- 明确规则的“费项”必须选择一个具体费项，候选项中不提供“全部”和“其他”。
- 明确规则的“结算币种”必须选择一个明确币种，候选项中不提供“随原始币种”。
- 财务为明确规则选择费项后，系统将该行的“结算币种”默认设置为该费项的原始币种；财务可以再改为其他明确币种。
- 同一个应收账单配置方案内，同一费项只能出现一次。重复选择费项时，系统不得保存配置，并提示重复规则所在行。
- 财务可以删除明确规则，不能删除兜底行。

#### 2.4 引用费项结算币种模板

- 系统移除原“引用费项币种模板”下拉框，在“费项结算币种”表格工具栏中增加“引用模板”按钮。
- 财务点击“引用模板”后选择一个费项结算币种模板，系统将模板中的规则填入当前表格。
- 引用模板后，表格仍必须满足同一费项不重复、只保留一条兜底行且兜底行位于末行的规则；不满足时不得保存配置。
- 引用模板只复制模板中的规则，不保存模板关联。引用完成后，财务可以修改表格内容；模板后续发生变化时，不自动修改当前账单配置。

### 3. 返款账单配置

#### 3.1 调整表格字段

- “货款结算币种”表格展示“货款原始币种”“货款结算币种”“客户收款账户”和“操作”四列。
- 当表格只有兜底行时，兜底行的“货款原始币种”显示“全部”。
- 当表格存在一条或多条明确规则时，兜底行的“货款原始币种”自动显示“其他”。
- 当财务删除明确规则，表格重新只剩兜底行时，兜底行的“货款原始币种”自动恢复为“全部”。
- 兜底行的“货款原始币种”使用禁用状态的输入框展示，兜底行不显示删除操作。

#### 3.2 新增和删除明确规则

- 明确规则的“货款原始币种”必须选择一个具体币种，候选项中不提供“全部”和“其他”。
- 同一返款账单配置内，同一个货款原始币种只能出现一次。重复选择货款原始币种时，系统不得保存配置，并提示重复规则所在行。
- 财务可以删除明确规则，不能删除兜底行。

#### 3.3 设置货款结算币种

- 新增明确规则后，在财务选择“货款原始币种”之前，该行的“货款结算币种”保持为空且不能选择。
- 财务选择“货款原始币种”后，系统将该行的“货款结算币种”默认设置为相同币种，并允许财务改为其他明确币种。
- 明确规则和兜底行都必须选择一个明确的“货款结算币种”。“货款结算币种”的候选项中不提供“随原始币种”。
- 任一行未选择“货款结算币种”时，系统不得保存配置，并提示缺少结算币种的行。

#### 3.4 设置客户收款账户

- “客户收款账户”单元格使用与“货款结算币种”下拉框相同的外观。
- 财务点击“客户收款账户”单元格后，系统打开编辑弹层。弹层包含“账户名称”和“收款账号”两个输入框。
- “账户名称”和“收款账号”均可以清空。财务在任一输入框中按回车后，系统关闭编辑弹层，并在当前单元格回显已填写的内容。
- 单元格按“账户名称 / 收款账号”的格式回显。仅填写其中一个字段时，只显示已填写的字段，不显示分隔符。
- 每条币种规则分别保存自己的客户收款账户，不得显示或保存其他规则中的账户。
- 配置保存成功后，财务再次打开该配置时，表格必须按保存时的行顺序回显每行的货款原始币种、货款结算币种、账户名称和收款账号。

## 保持不变的内容

- 应收账单配置仍分别在默认方案和各分支方案内维护费项结算币种规则，同一方案内的规则独立生效。
- 返款账单配置中的返款模式、账期类型、账期起始日、账单发出时间、返款账单必要归集金额、直接扣减费项、负数金额处理方式和条款生效周期保持不变。
- 配置变更仍按配置版本和生效周期作用于后续任务，不自动改写已经生成的账单。
