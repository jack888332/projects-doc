## 1. 业务范围与协作

客服在业务运营平台“服务商品”下维护商品库与商品类目，将高捷提供的无形服务作为商品向客户销售。先维护需要的类目，再创建商品并关联末级类目；目标类目不存在时，先创建类目，再关联商品。

<a id="doc-7E1B0092DE-b0dc7cad4eae"></a>
## 2. 服务商品库

按财务组织和部门的授权范围查询商品；无查询条件时展示范围内全部记录，按创建时间倒序，默认每页 50 条。重置清空查询条件。

**界面原型概述 · 查询栏**

| 字段或控件 | 个别界面约束或可见反馈 |
| --- | --- |
| 商品名称 | 模糊查询，范围为当前财务组织及部门内的商品 |
| 商品类目 | 按层级选择并精确查询 |
| 创建人 | 在用户账号名称中模糊选择 |
| 创建部门 | 从当前财务组织下的部门中选择并精确查询 |
| 创建商品 | 打开创建页面 |

**界面原型概述 · 列表栏**

- **区域字段或业务元素**：商品编码、商品名称、商品类目、平台、所属财务组织、所属部门、创建时间、创建人、状态、详情、编辑、删除。
- **区域级通用规则**：展示当前商品记录，数据字段只读，创建时间精确到秒；详情与编辑从当前行进入。

| 字段或控件特例 | 界面特例或可见反馈 |
| --- | --- |
| 状态 | 显示启用或禁用 |
| 删除 | 仅禁用商品显示删除入口 |
| 平台 | 来源尚未明确，见 OPS-35 |

<a id="doc-7E1B0092DE-f8eda7a7e027"></a>
## 3. 创建与维护商品

提交时校验商品名称重复、必填项和输入限制；不满足时指出相应字段并阻止提交。成功后回到商品库，新增商品初始为启用。商品编码在创建后生成，规则为 `Sv+YYYYMMDD+3位流水`。

| 当前状态 | 允许操作 | 形成结果 |
| --- | --- | --- |
| 启用 | 详情、编辑、禁用 | 编辑保存更新当前商品；禁用后状态为禁用 |
| 禁用 | 详情、编辑、启用、删除 | 启用后状态为启用；删除移除当前商品 |

**界面原型概述 · 创建与编辑表单**

| 字段或控件 | 个别界面约束或可见反馈 |
| --- | --- |
| 所属财务组织 | 必填，默认当前账号的财务组织；关联多个组织时选择目标组织 |
| 所属部门 | 必填，默认当前账号在所选财务组织中的部门；多部门时选择目标部门 |
| 商品名称 | 必填，允许中文、字母和数字；正文 120 字符与截图 60 字符的差异见 OPS-34 |
| 商品类目 | 选填，只能关联末级类目；部门过滤与集团共用类目库的关系见 OPS-34 |
| 提交/保存 | 创建显示提交，编辑显示保存；必填缺失或输入不合规时不可操作，字段旁显示错误 |
| 取消 | 不保存本次输入；提交成功以结果提示反馈 |

<a id="doc-7E1B0092DE-a4e008220c67"></a>
## 4. 商品类目

类目最多三级，商品只能关联末级类目。创建时校验类目名称重复；根类目不可删除，子类目支持删除。集团共用类目库与商品选择按部门过滤的范围冲突见 OPS-34，不据此推定额外的数据隔离规则。

**界面原型概述 · 类目树与维护弹窗**

| 字段或控件 | 个别界面约束或可见反馈 |
| --- | --- |
| 新建根类目 | 打开名称输入弹窗 |
| 新建子类目 | 带出当前父级类目 |
| 类目名称 | 必填，最多 120 字符；重复名称不能提交 |
| 删除子类目 | 从当前子类目操作，不为根类目提供删除入口 |

<a id="doc-7E1B0092DE-pending-boundaries"></a>
## 5. 待确认边界

OPS-34、OPS-35 的完整证据与待确认问题记录在 PRD 自洽性问题清单；其中的未定条件不作为正式校验依据。类目删除对已关联商品的影响，来源尚未定义，不补造级联删除规则。
