### 1.1 页面交互规则

<a id="doc-20AA542560-section-b14123584bb4"></a>
#### 1.1.1 通用页面行为

- 运单列表默认分页显示，每页 50 条记录。

- 创建运单时提供“提交”和“取消”按钮；修改运单时提供“保存”和“取消”按钮。

- 提交成功后，页面短暂显示“已提交成功！”。

- 输入内容不符合格式要求或必填项为空时，对应输入项高亮提示，“提交”和“保存”按钮置灰且不可点击。

#### 1.2.6 逆向流程节点说明

| 流程点 | 异常节点 | 前置条件 | 后续处理 |
| --- | --- | --- | --- |
|  | 取消调度 | 结合订单管理PRD中说明的订单取消场景。<br>此外，运单状态=已卸货或已取消，则不可取消调度。 | 一旦调度取消，运单状态更新为“已取消”。系统根据表价管理中的“返空费比例”乘以运输费（提货总价模式下），自动算出返空费金额，写入该运单的应收付账单中。 |
|  | 修改调度 | 仅在运单状态为“待提货”时允许修改调度；其他状态下需先取消调度，再重新录入调度信息。 | 修改后的调度信息实时更新至原运单。 |
|  | 异常上报 | 运单状态不为“已取消”时，司机或航晟客服可对指定运单上报异常。 |  |

<a id="doc-20AA542560-section-7abde6482646"></a>
#### 1.2.7 场景举例

1. 当前订单状态=已调度或异常中，该订单下属3个运单，其中1个运单状态=已卸货，另外2个运单状态=提货中；

2. 此时，发起取消订单操作；

3. 处理结果：订单状态更新为“已取消”，原“已卸货”状态的运单无影响（其早已生成了相应的应收付记录），而另外2个“提货中”的运单则状态更新为“已取消”，并产生相应的应收付“返空费”。

| 主业务流程 | 1. 中转运单的生成：自动接收WMS回传的订单号、车牌号、封条号、供应商名称的信息，对匹配上的订单号进行自动调度。<br>- 此场景下，原中转订单上新增相应的调度记录，调度操作人记录为“WMS”，事件时间取接收到WMS消息的时间。<br>- 此场景下，生成的相应运单的状态，初始为“已提货”。<br>- 若有无法匹配到的“订单号”，则需要将此信息反馈回WMS。<br>1. 新增封条号信息：WMS 的一份报文中包含一个封条号，表示该批货物由同一辆车运输。中转运单列表展示该封条号，以便查询。 |
| 特殊需求 | 接收 WMS 调度信息时，出现以下任一情况则向 WMS 反馈错误：<br>1. 无法匹配状态为“待调度”且订单号相同的中转订单；<br>1. 供应商名称与合作方档案管理中的数据不匹配；<br>1. 车牌号或供应商名称未传值，或传值不符合规范。 |

补充计算与预警规则：

- 预计件数（件）：调度时，若为该调度记录录入了特定毛件体，则显示该值。若未录入，则毛件体分别除以该订单下的总车辆数，尺寸字段留空；结果四舍五入取正整数。
- 截单时间预警：航班起飞时间-当前时间<=11小时且运单状态=“待提货”，则自动加入红色的备注信息“截单时间临近”。航班起飞前10个小时必须中转派车。

#### 1.3.23 中转运单-运单详情

#### 1.3.24 中转运单详情规则

| 场景名称 | 中转运单详情 |
| --- | --- |
| 范围/概述 | 展示运单详情、轨迹记录、应收付账单、异常管理和单据管理。 |
| 主要参与者 | 航晟客服 |
| 前置条件 | 从中转运单列表页面中的“操作”项下的“查看详情”按钮进入。 |
| 主业务流程 | 1. 运单详细信息新增展示“封条号”字段。<br>1. WMS 反馈的调度信息匹配成功后，中转运单自动生成“调度完成”和“已提货”两条轨迹记录。<br>1. 应收、应付账单复用运输运单的应收、应付页面。<br>- 提货费=提货重量（WMS 出库重量）×对应客户或供应商的报价单价。供应商报价配置为 0 元/kg 时，应付提货费为 0 元。<br>1. 异常管理复用运输运单的异常管理页面，支持在后台录入异常。<br>1. 单据管理复用运输运单的单据管理页面，支持在后台上传新单据。 |
