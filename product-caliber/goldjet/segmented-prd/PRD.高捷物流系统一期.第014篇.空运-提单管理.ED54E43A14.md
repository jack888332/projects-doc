#### 1.1.7 提单列表查询与操作规则

| 场景名称 | 提单管理-提单列表 |
| --- | --- |
| 范围/概述 | 查看所有提单，了解提单概况 |
| 主要参与者 | 高捷客服，打单员 |
| 前置条件 | 进入提单管理页面，通过浏览和筛选，快捷找到相关提单 |
| 业务结果 | 列表展示符合条件的提单及其发送状态，并支持批量发送、批量下载和备注维护。 |
| 主业务流程 | 1. 展示范围：列表展示订单状态为“待出提单”“已出提单”“交单”或“已作废”的订单。<br>2. 查询与重置：未选择查询字段时，“查询”按全部条件检索；选择条件时展示匹配数据，并优先展示“待出提单”订单。“重置”清空全部查询条件。<br>3. 批量发送运单：仅已有提单号的订单可选择主单或分单数据发送至翌飞。发送顺序、两分钟防重、DescriptionCode、状态与失败反馈统一按[翌飞批量发送与防重规则](PRD.高捷物流系统一期.第016篇.航司推送.BE0FA764FE.md#doc-BE0FA764FE-section-36be6b5a98f3)处理；发送结果在列表中更新。<br>4. 批量下载提单：打开“批量下载提单”弹窗，默认不选择数据并支持多选；确认后按航司代码从提单模板中取得相应模板并批量下载，不限制数量和时间。<br>5. 提单备注：打开“提单备注”弹窗；确定后保存该票备注并显示在列表中，取消后关闭弹窗且不保存。<br>6. 主分单导航：点击提单号进入对应的提单编辑页面；分单超过两个时以可滚动列表展示，点击分单号进入对应的分单编辑页面。<br>7. 截单时间异常：订单处于“待出提单”状态且截单时间晚于系统当前时间时，显示异常状态。<br>8. 分单发送异常：鼠标移至分单“发送总状态”的“异常中”标识时，浮窗仅展示已发送翌飞且处于异常状态的分单，依次显示分单号、发送航司分单子状态和翌飞返回的异常内容；内容超出展示区域时可滚动查看。 |

<a id="doc-ED54E43A14-section-5625afd14d62"></a>
#### 1.1.8 提单编辑页面

字段定义见 [数据字典 · 主提单编辑字段映射](PRD.高捷物流系统一期.第049篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-014-004)。

**提单计费规则：**

- 当`提单计费重*相应等级的运费卖价<M`时，提单运价取M，并默认使用M等级。
- 当`提单计费重*运费卖价>M`时，提单计费重大于45 kg则按计费重等级生成提单价格并默认使用Q等级；小于45 kg则默认使用N等级。
- 提单计费重取`体积*166.66`与毛重中的较大值，并向上调整为0.5的倍数、保留一位小数。例如，214.3取214.5，214.6取215.0。
- 计费总价=提单计费重*提单运价。

#### 1.1.9 提单编辑与预览下载规则

| 场景名称 | 提单管理-提单编辑页面 |
| --- | --- |
| 范围/概述 | 编辑主提单信息，维护常用联系人和体积、杂费明细，并提交、暂存、预览或下载提单。 |
| 主要参与者 | 客服、打单员 |
| 前置条件 | 进入提单管理，双击某个提单号进入“提单编辑”页面； |
| 主业务流程 | 1. 主分单切换与发送：通过页签在主单和分单之间切换，展示主单、分单汇总及分单明细。展示字段、发送状态、选择和批量发送规则见[航司推送状态展示与选择规则](PRD.高捷物流系统一期.第016篇.航司推送.BE0FA764FE.md#doc-BE0FA764FE-section-b27d10bc025a)。<br>2. 操作按钮：“提交”将订单状态由“待出提单”变为“已出提单”；“暂存”保存当前编辑内容；“预览”和“下载”打开“提单格式选择”弹窗；“托运书预览”打开托运书预览。<br>3. 发货人编辑：名称、地址、电话、邮编、国家、国家代码、省份、城市和别称分别取主单补料中的对应字段，无值时留空；勾选“保存为常用联系人”时保存联系人，并校验别称唯一。取消时关闭弹窗；清空时清除填写区和提单信息展示区；保存时保存两个区域的数据。提单信息展示区取主单补料中的发货人提单信息。常用联系人支持按别称模糊搜索、使用和删除；点击“使用”后，将该联系人内容带入填写区和提单信息展示区。<br>4. 收货人编辑：字段、按钮和常用联系人规则与发货人一致，取值源改为主单补料中的收货人信息。<br>5. 体积明细：默认10行，可添加或删除行。总体积为各行`长*宽*高*件数/1000000`之和，结果四舍五入保留两位小数；总件数为各行件数之和。<br>6. 杂费明细：默认行数取默认杂费项数量；填写单价和计费数量后，每行小计=单价*计费数量。<br>7. 键盘操作：输入状态下按制表键（Tab）移至下一输入格。<br>8. 数据同步：提单管理填写的毛重、件数和体积同步回订单管理对应字段。 |
