# 2026-06-26 BMS 财务报表导出字段映射与开发任务清单

## 1. 文档目的

本文是 `2026-06-26-bms-应收账单与返款账单财务报表导出调整技术方案.md` 的配套落地文档，用于把“方案级结论”继续拆成：

1. 应收账单导出字段映射表
2. 返款账单导出字段映射表
3. 模块级开发任务清单
4. 联调与验收清单

本文默认继承以下已确认口径：

1. 应收账单、返款账单都按“一行一个订单”导出
2. 底层 `fee_detail` 竖表数据转固定金额列横表
3. 返款账单不拆模板
4. 直接按 `aidocs/product-caliber/bms/prd/财务报表导出格式.md` 落地
5. 历史重导不要求还原生成时快照

## 2. 总体拆分原则

### 2.1 职责拆分

1. `bms`
   - 负责结构化导出数据
   - 负责订单聚合、费项归类、汇率链路输出
2. `platform-admin`
   - 负责把结构化数据写成固定模板 `.xlsx`
   - 负责 `明细`、`汇总` sheet 输出
3. `admin_shell`
   - 继续保留原入口
   - 最多只调整下载文件名与后缀

### 2.2 费项横表规则

1. 最终导出粒度是一行一个订单
2. 底层多条 `fee_detail` 先按订单聚合
3. 再按费项分类落入固定金额列
4. 未命中固定类目的费用统一进入“其它费用”

### 2.3 分类规则建议

建议在 `bms/common` 增加“导出费项分类常量/枚举”，避免把费项中文名判断散落在 Service 中。

应收账单建议固定列：

1. 运费
2. 派送费
3. 进店
4. 打包
5. 应收货款
6. 代收手续费
7. 代收回款
8. 其它费用

返款账单建议固定列：

1. 运费
2. 派送费
3. 代收款
4. 代收手续费
5. 回款
6. 退款金额/应退金额
7. 超商取件费
8. 附加服务项目/其他收入
9. 其它费用

3. 金额格式是否统一为财务可直接汇总的数字列

## 8. 建议的开发拆单

如果要继续往研发排期，可以直接拆成 4 张任务单：

1. `BMS-AR-EXPORT-DATA`
   - 应收账单订单横表导出数据接口
2. `BMS-REFUND-EXPORT-DATA`
   - 返款账单订单横表导出数据接口
3. `PORTAL-EXPORT-XLSX`
   - Portal 导出模板从 HTML `.xls` 切换为 `.xlsx`
4. `SHELL-EXPORT-FILENAME`
   - Shell 下载文件名与后缀收尾

这样拆的好处：

1. 后端数据准备和 Portal 模板改造可以并行
2. `admin_shell` 可最后联调，风险最小
