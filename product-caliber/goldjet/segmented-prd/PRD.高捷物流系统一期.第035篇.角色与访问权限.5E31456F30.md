## 1. 访问权限与业务条件

本篇统一定义跨模块的访问边界，以及各模块已明确的页面、操作和数据授权。业务执行条件、状态变化和处理结果仍在对应业务场景定义；控件呈现仍在对应界面原型概述定义。

<a id="doc-5E31456F30-access-decision"></a>
### 1.1 授权判定

执行一项操作必须同时满足：当前用户具有该操作授权，目标对象属于该用户可操作的数据范围，并且满足对应业务场景的状态与前置条件。具有查看权限不等于具有修改权限，具有某项操作权限也不等于可以操作全部数据。

菜单可见、页面可访问和操作可执行分别判断。菜单入口不授予页面内的全部操作；隐藏菜单或按钮也不能代替访问限制。已明确无权访问的页面或数据不得展示，无权执行的操作不得改变业务记录。

默认筛选只决定进入页面时显示哪些授权范围内的数据，不改变实际访问范围。允许切换“全部”时，“全部”仍须按对应对象的授权范围解释，不能把一个页面的范围套到同模块其他页面。

<a id="doc-5E31456F30-related-object-access"></a>
### 1.2 关联对象与跨入口访问

列表、详情、查询结果、待办、消息链接、下载和导出按其涉及的对象与操作执行相同的授权判断。通过链接或待办进入不额外扩大权限；下载和导出不能带出无权查看的数据或字段。

主订单、分单、服务单和费用记录分别判断对象范围。能够查看一个分单或收到它的补齐通知，不自动获得主订单、其他分单或关联费用的访问权限；关联关系本身不构成授权。针对某一对象的通知接收人，也不自动成为全部关联对象的修改人或审批人。

<a id="doc-5E31456F30-access-presentation"></a>
### 1.3 界面权限投影

菜单、按钮和字段的显隐、只读、禁用及提示位置，由对应界面原型概述引用本篇授权规则后说明；状态不满足造成的不可操作，同时引用业务场景条件。多个控件适用相同规则时按区域说明一次，只列例外。

字段查看权限与字段编辑条件分开：有权查看但当前状态不可编辑时，不因此隐藏该字段；无权查看的字段不能仅改为只读后展示。具体字段是否允许查看、修改或脱敏，按各模块的明确授权执行。

<a id="doc-5E31456F30-role-identity"></a>
## 2. 角色与业务身份

角色使用对应业务领域的名称，不因同称“客服”“主管”或“管理员”而自动共用授权。主管和管理员不因名称获得未明确授予的操作、数据或字段权限。

| 身份依据 | 授权判断中的含义 |
| --- | --- |
| 岗位角色 | 区分空运客服、航线运营、航线操作、报关行客服、航晟客服、会计、出纳等业务岗位；具体操作见各模块授权。 |
| 建单人、跟单客服、接单客服 | 分别依据创建和派单关系识别，不能直接视为同一人；派单后的业务变化见订单场景。 |
| 航线产品绑定人、负责航线人员 | 分别按产品与人员的绑定关系、航线责任归属识别；两种关系不自动等同，不同页面的范围分别判断。 |
| 当前审批人、任务处理人 | 依据当前业务节点或任务指派识别；具有同名岗位不代表可处理他人的全部审批或任务。 |
| 当前公司、当前组织、用户权限部门 | 按各场景明确的组织维度判断，不能将公司、组织和部门视为同一范围。 |

尚未明确的角色对应关系、菜单范围及授权组合不从缺失条目推断为允许或禁止，待确认事项集中记录在 [PRD 自洽性问题](../analysis/PRD自洽性问题.md)。

| 财务结算工作台 | 财务人员 | 登录后进入；任务、快捷入口和消息另须具备对应功能权限。 |
| 财务结算工作台 | 业务、业务主管、分管副总 | 登录并具备对应财务结算功能权限。 |

<a id="doc-5E31456F30-workspace-actions"></a>
### 7.2 工作台操作权限

待办任务的实际处理人、处理入口及完成条件按[工作台待办规则](PRD.高捷物流系统一期.第002篇.工作台与待办管理.279CFF369E.md#doc-279CFF369E-section-e7637dfe2e27)确定；快捷入口的显示不额外授予目标业务页面的操作权限。

<a id="doc-5E31456F30-workspace-scope"></a>
### 7.3 工作台数据范围

登录并具备对应功能权限后，工作台仅展示当前角色有权处理的任务、快捷入口与消息；待办统计和列表使用相同任务范围。业务人员的财务结算工作台也只展示其有权处理的任务类型。

## 8. 报表与运营大屏访问权限

报表入口位于“高捷物流平台 → 报表管理”，各入口的使用角色如下；报表定义、查询字段与统计口径见[报表管理](PRD.高捷物流系统一期.第031篇.报表管理.CF2AF4B8B2.md#doc-CF2AF4B8B2-section-4743cdb45c83)。

| 报表入口 | 使用角色 |
| --- | --- |
| 航晟仓库月度报表、仓库客户贡献度月报 | 航晟物流-仓库主管 |
| 用车客户贡献度月报、陆运供应商贡献度月报、陆运不配合司机 | 航晟物流-卡车主管 |
| 航晟陆运月度报表 | 航晟物流-陆运主管 |
| 合作方交易检查表；审批超时报表-结算成本、审批超时报表-付款申请、审批超时报表-收款申请 | 财务结算-财务主管 |
| 应付周期报表、应付账款账龄表、收款周期报表、应收账款账龄表 | 财务结算-财务主管 |
| 公司业绩表、供应商与客户业绩表、公司利润表、业务利润表 | 财务结算-财务主管 |
| 电商利润分析表、电商毛利分析表、电商统计表 | 财务结算-财务主管 |
| 对账单模板 | 客服/业务员 |

上述角色范围不自动扩展为运营大屏权限。报表和大屏的组织、记录及敏感字段范围，以及运营大屏的可访问角色，仍须确认，见 [PRD 自洽性问题](../analysis/PRD自洽性问题.md)。指标覆盖多个业务模块不代表使用者能查看这些模块的全部原始记录。
