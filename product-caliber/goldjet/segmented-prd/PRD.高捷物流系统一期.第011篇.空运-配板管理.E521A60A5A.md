### 1.3 空运配板功能与规则

<a id="doc-E521A60A5A-section-c0227b1edded"></a>
#### 1.3.1 配板管理页面

- 航线部基于已经订舱的订单，确定同一航班号的订单如何配板才能实现当日航班利益最大化。

<a id="doc-E521A60A5A-section-26b24e8d3608"></a>

订舱与配板共用筛选项及场景约束见[对应业务场景](PRD.高捷物流系统一期.第010篇.空运-订舱管理.6A0360EC35.md#doc-6A0360EC35-section-73798dacec26)。

<a id="doc-E521A60A5A-section-2a7591d54113"></a>
#### 1.3.3 配板、利润与分批规则

| 场景名称 | 配板管理-配板操作 |
| --- | --- |
| 范围/概述 | 将已订舱订单匹配到航班板位，并支持卸下、分批、撤回和重配。 |
| 主要参与者 | 航线部 |
| 前置条件 | 订单已经完成订舱服务，并且已绑定提单号、航班号和出港日期 |
| 业务结果 | 已选订单匹配到目标航班，货物总体积、总毛重和预计利润随配板结果更新。 |
| 主业务流程 | 1. 在《配板管理》页面分别从待配板列表和配板列表筛选订单与航班；选择订单和航班后点击“配板”，将已选订单匹配到目标航班。<br>2. 取值规则：舱位总体积取舱位实时查询结果；板数取舱位产品维护中该航班可用的板数；货物总体积和总毛重分别为已配订单体积、毛重之和，并随配板、卸下和分批实时更新；货物毛件体按预计、入仓、提单三类，以毛重/件数/体积展示；货物尺寸取客服录入值，仅托盘货展示；备注由航线运营填写并可随配板情况修改；订单选择了特殊物品时展示该信息。<br>3. 预计利润：CZ、MH航班按`卖价*收客户重量-成本*付航司重量-当前航班剩余基重*合同罚金`计算；TK航班不扣合同罚金；CA航班不计算。卖价取订单运费卖价；收客户重量=`(提单体积重-提单毛重)*分泡率+提单毛重`；成本取航线确认订单时填写的成本；付航司重量取计费重；当前航班合同基重为各板`数量*基准载重`之和；当前航班剩余基重=`当前航班合同基重-各板毛重之和`。 |
| 业务分支 | 功能：<br>1. 卸下：将已经配好板的订单卸下。货物总体积和货物总毛重实时更新。<br>1. 分批：航线发现已配好的订单货物受限于可使用的板体积（货物总体积远大于舱位总体积），只能配上一部分。就可点击“分批”，将货物的毛件体拆分出一个新的订单。<br>默认和原订单同一个航班号和出港日期，支持修改。<br>点击确认后，在配板列表生成新的数据。提单号不变。<br>此时功能按钮为：撤回。点击撤回后，合并成原订单的毛件体。 |
