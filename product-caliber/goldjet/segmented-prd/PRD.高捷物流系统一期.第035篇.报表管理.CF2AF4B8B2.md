### 1.3 报表页面

<a id="doc-CF2AF4B8B2-section-26099e70ac5c"></a>
#### 1.3.1 航晟仓库月度报表

- 查看仓库月度业务整体数据概览。

- 每月3日（可单独配置），固定时间（开发定，最好1~7点之间），将上月的记录新增进来。

- 按照月份倒序排序。

<a id="doc-CF2AF4B8B2-section-fecc9d509d5f"></a>
#### 1.3.2 报表字段

| 序号 | 字段 | 取值来源 | 样式 | 备注 |
| --- | --- | --- | --- | --- |
| 1 | 月份 | 月份数依次倒序展示，从系统中第一笔订单的月份开始 | 2020年7月 | 月份为筛选项 |
| 2 | 总入库订单数 | 实际入库时间发生在该月份的订单总数 | 2322 |  |
| 3 | 总出库订单数 | 实际全部已出库时间发生在该月份的订单总数，部分出库不算 | 3322 |  |
| 4 | 中转出库订单数 | 订单上的“我司中转”为“是”的订单，且其实际全部已出库时间发生在该月份的订单总数，部分出库不算 | 3222 |  |
| 5 | 总应收 | 该月已完成的所有订单的订单应收金额累计（取业务主管审批通过后的数据即可） | ￥34444.00 |  |
| 6 | 总应付 | 该月已完成的所有订单的订单应付金额累计（取业务主管审批通过后的数据即可） | ￥30444.00 |  |
| 7 | 预计盈利 | 预计盈利=总应收-总应付 | ￥4000.00 |  |
