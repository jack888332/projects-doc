#### 1.3.3 业务规则说明

| 场景名称 | 财务结算工作台 |
| --- | --- |
| 范围/概述 | 拥有对应功能的角色具备对应的任务。 |
| 主要参与者 | 业务、业务主管、分管副总、财务 |
| 前置条件 | 成功登录 |
| 业务结果 | 对应的角色看到对应的任务和消息 |
| 主业务流程 | 1. 总待办XXX：显示所有未处理的总任务个数。<br>1. 待办任务进度条：总未处理的任务个数/（总已处理+未处理的任务个数）；<br>1. “我的待办”最近更新：显示最后一次，待办任务进度条数值发生变化的时间；<br>1. 快捷操作：<br>- 我的供应商明细审批界面；<br>- 我的供应商列表界面；<br>- 我的客户明细审批界面；<br>- 我的客户列表界面；<br>- 客户授信额度审批界面界面；<br>- 订单成本明细审批界面；<br>- 付款申请单明细审批界面；<br>- 付款申请单明细编辑列表；<br>- 付款核销明细编辑界面；<br>- 收款核销明细编辑界面<br>1. 待办任务概览：展示所有未处理的待办任务，以创建时间顺序展示（时间早的，排序靠前）。分页展示，每页最多20条记录。<br>1. 消息通知：取原“微信通知推送”的消息类型和内容。分页展示，每页最多10条记录。 |
