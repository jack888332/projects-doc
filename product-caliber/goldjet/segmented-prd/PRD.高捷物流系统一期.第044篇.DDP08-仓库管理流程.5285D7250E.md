### 1.1 航晟物流：仓库管理的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 发送仓库订单 | 空运系统 | 空运系统发送需要仓库服务的订单。 | 3 | 是 |
| 2 | 维护仓库报价 | 航晟仓库 | 航晟仓库按客户和服务类别维护报价。 |  |  |
| 3 | 查看仓库订单列表 | 航晟仓库 | 仓库订单列表统一展示和管理不同客户的订单。 | 4 |  |
| 4 | 创建入仓单 | 航晟仓库 | 仓库系统创建入仓单并发送给 WMS。 | 5 | 是 |
| 5 | 判断是否修改订单 | 航晟仓库 | 仓库客服根据实际业务决定是否修改仓库订单。 | 6或10 |  |
| 6 | 编辑或删除订单 | 航晟仓库 | 仓库客服修改或删除订单记录。 | 8 |  |
| 7 | 接收入仓单 | WMS | WMS 接收入仓单。 | 8 |  |
| 8 | 接收更新后的订单数据 | WMS | 提单号等订单信息变更后，WMS 接收更新后的数据。 | 9 |  |
| 9 | 反馈实际入仓毛件体 | WMS | WMS 向仓库系统反馈实际入仓毛件体。 | 10 |  |
| 10 | 查看订单详情 | 航晟仓库 | 订单详情展示订单信息、实际毛件体和预计应收、应付信息。 | 11或13 |  |
| 11 | 反馈实际毛件体 | 航晟物流 | 航晟物流将实际毛件体反馈给空运系统。 | 12 |  |
| 12 | 更新出仓状态 | 空运系统 | 空运系统收到仓库反馈后更新出仓状态。 |  |  |
| 13 | 创建出仓单 | 航晟仓库 | 仓库系统创建出仓单并发送给 WMS。 | 16 |  |
| 14 | 接收出仓单 | WMS | WMS 接收出仓单。 | 15 |  |
| 15 | 回传出库数据 | WMS | WMS 向仓库系统回传出库结果。 | 16 |  |
| 16 | 更新订单状态 | 航晟仓库 | 仓库系统收到 WMS 反馈后更新订单状态。 | 17 |  |
| 17 | 修改应收、应付项目 | 航晟仓库 | 航晟仓库可以手工修改应收、应付成本项目和金额。 | 18 |  |
| 18 | 导出应收、应付账单 | 航晟仓库 | 支持批量导出应收、应付账单。 |  |  |
