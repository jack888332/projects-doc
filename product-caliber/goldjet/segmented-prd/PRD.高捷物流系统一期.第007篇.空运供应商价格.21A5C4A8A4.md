### 1.1 供应商价格维护功能与规则

<a id="doc-21A5C4A8A4-section-d2de89f28aab"></a>
#### 1.1.1 供应商价格业务范围

本篇定义供应商价格的查询、新增、编辑、启用、失效及计费规则，并定义客户应收费用的计算口径。

<a id="doc-21A5C4A8A4-section-9210aa5d4506"></a>
#### 1.1.2 供应商价格查询与操作

**查询条件**

- 成本类型：下拉框。数值取自费用项。支持模糊查询。

- 状态：下拉框。仅有两种状态：“已生效”、“失效”。

- 计费单位：下拉框。“分单数（个）”、“主单数（个）”、“提单计费重（kg）”、“提单毛重（kg）”、“提单毛重/提单件数（kg/件）”、“提单件数”。

- 服务类型：下拉框。仅有八种服务：订舱、提货、仓储、中转、预配发送、报关、货站安检、清关派送。

- 供应商：下拉框。数值取自供应商档案。支持模糊查询。

**操作规则**

- 查询：在不选择任何查询字段下，点击“查询”按钮，默认所有查询条件。选择对应的查询条件，则显示符合结果的数据。查询出的数据按照“更新时间”倒序排列。

- 重置：重置查询条件。

- 新增：只有客服主管能看到该按钮。点击后，在价格维护列表上方新增一行输入项。

- 编辑：只有客服主管能看到该按钮。点击后，被编辑的价格数据显示在价格维护列表上方。

- 启用：只有客服主管能看到该按钮；点击后弹出“供应商价格规则启用”弹窗。

- 失效：只有客服主管能看到该按钮；点击后弹出“供应商价格规则失效”弹窗。

- 查看：当计费方式为非“常规”时，计费单价列不显示数据，显示“查看”按钮。点击“查看”按钮，出现计费方式详细弹窗。

#### 1.1.3 新增供应商价格规则

在“供应商价格维护列表页面”点击“新增”按钮，在供应商价格维护列表之上新增一行可编辑的价格规则。新增时，填写供应商、服务类型、成本类型、计费单位、计费方式、计费单价、税率、币种、生效日期、截止日期、合同编号。

**操作规则**

- 查询：在不选择任何查询字段下，点击“查询”按钮，默认所有查询条件。选择对应的查询条件，则显示符合结果的数据，查询出的数据按照“更新时间”倒序排列。查询时保留新增列表相关内容。

- 重置：重置查询条件。

- 保存：保存成功时提示“新增供应商价格规则成功”，并刷新页面。

- 取消：取消新增报价。

- 编辑：若计费方式选择为航晟运输报价、梯度报价、首加续报价，计费单价列显示“修改”按钮；点击“修改”，出现相对应的“新增计费方式”弹窗。

- 修改：点击“修改”按钮，弹出相对应的计费方式价格维护新增弹窗。

- 失效：在新增时，“失效”按钮置灰。

- 启用：在新增时，“启用”按钮置灰。

**保存校验规则**

同一个供应商、同一个服务类型、同一个成本类型、同一时间只支持维护一条价格维护数据。当新增的价格维护数据与之前的数据发生有效期重叠时，不允许新增。

<a id="doc-21A5C4A8A4-section-16b1f15d47b7"></a>
#### 1.1.4 编辑供应商价格规则

在“供应商价格维护列表页面”选择要编辑的一条价格维护数据，点击“编辑”按钮，在供应商价格维护列表之上编辑选中的价格维护数据。可编辑供应商、服务类型、成本类型、计费单位、计费方式、计费单价、税率、币种、生效日期、截止日期、合同编号。

**操作规则**

- 保存：保存成功时提示“编辑供应商价格规则成功”，并刷新页面。

- 取消：取消编辑价格。

- 新增：在编辑页面点击“新增”弹出提示弹窗：“有修改的内容尚未保存，是否新增”。

- 修改：若计费方式为航晟运输报价、梯度报价、首加续报价，计费单价列显示“修改”按钮；点击“修改”，出现该条数据相对应的“编辑计费方式”弹窗。若直接修改计费方式选项，则需红字提示“与之前的计费方式不一致，请确认后继续操作”，此时点击“修改”按钮，出现的是新计费方式对应的计费详细弹窗。

- 失效：在编辑时，“失效”按钮置灰。

- 启用：在编辑时，“启用”按钮置灰。

**保存校验规则**

同一个供应商、同一个服务类型、同一个成本类型、同一时间、生效状态下只支持维护一条价格维护数据。当编辑后的价格维护数据与之前的数据发生有效期重叠时，不允许编辑，并做出相应的提示。

当截止日期早于当前日期时，不允许保存。

<a id="doc-21A5C4A8A4-section-05bc00aca127"></a>
#### 1.1.5 启用供应商价格规则

供应商价格维护列表界面，勾选一条价格维护数据，点击“启用”按钮，弹出“供应商价格规则启用”弹框。只有“失效”状态的供应商价格规则才能使用启用功能。

**操作规则**

- 启用：完成指定价格数据的状态转换，返回“供应商价格维护列表”界面并刷新。

- 状态流转：启用后，价格规则状态由“失效”变为“已生效”。

- 取消：取消启用，返回“供应商价格维护列表”界面。

**启用校验规则**

同一个供应商、同一个服务类型、同一个成本类型、同一时间、生效状态下只支持维护一条价格维护数据。当生效后的价格维护数据与之前的数据发生有效期重叠时，不允许启用，并做出相应的提示。

<a id="doc-21A5C4A8A4-section-3b13a22cc310"></a>
#### 1.1.6 失效供应商价格规则

供应商价格规则界面，点击“失效”按钮，弹出“供应商价格规则失效”弹框。只有“生效”状态的价格规则数据才进行失效处理。

**操作规则**

- 失效：完成对指定价格规则的失效处理，返回“供应商价格规则列表”界面并刷新。

- 状态流转：失效后，价格规则状态由“已生效”变为“失效”；超过截止时间时，价格规则状态也变为“失效”。

- 取消：取消失效，返回“供应商价格规则列表”界面。

#### 1.1.10 供应商其他价格维护规则

- 订舱费计算规则：空运成本取订舱管理中主订单订舱完成后的航程信息；提单计费重取提单管理的提单编辑页面。订舱费=空运成本*提单计费重。

- 提单杂费计算规则：提单杂费为数据字典所列各项提单杂费之和。

字段定义见 [数据字典 · 提单杂费代码映射](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-009-005)。

### 1.2 客户价格维护管理

<a id="doc-21A5C4A8A4-section-d38d885b9b09"></a>
#### 1.2.1 应收空运费计算规则

先主后分场景下，应收客户空运费计算规则为运费卖价*提单计费重。其中运费卖价取自主订单管理的货物信息-运费卖价。

先分后主场景下，应收客户空运费计算规则为子订单的运费卖价*子单提单计费重之和。其中运费卖价取自子订单管理—订单录入-子订单创建的运费卖价。

<a id="doc-21A5C4A8A4-section-3d0d8373c547"></a>
#### 1.2.2 其他应收计算规则

取应付作为应收，允许客服对应收进行修改。
