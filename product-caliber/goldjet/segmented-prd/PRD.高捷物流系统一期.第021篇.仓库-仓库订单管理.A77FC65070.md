#### 1.2.6 仓库订单列表规则

| 场景名称 | 仓库订单列表 |
| --- | --- |
| 范围/概述 | 查看订单列表，了解订单概况 |
| 主要参与者 | 仓库人员 |
| 前置条件 | 成功接收上游传来的仓库订单创建申请 |
| 业务结果 | 仓库数据与状态显示正确 |
| 主业务流程 | 1. 页面订单数据源：<br>- 高捷物流-空运事业部的仓库服务自动生成的仓库订单；<br>- 航晟物流-客服部的仓库服务自动生成的仓库订单；<br>- 高捷物流-空运事业部手动创建的仓储订单；<br>- 航晟物流-客服部手动创建的仓储订单；<br>- 仓库自己手动创建的仓储订单；<br>1. 页面排序规则：<br>- 以订单创建时间倒序排序，每页展示50条记录；<br>1. 选中订单：支持选择一条或多条订单，并展示所选订单的汇总信息。<br>- 已选择X项：所选订单数量；<br>- 总重量X kg：所选订单委托重量之和；<br>- 总数量X件：所选订单委托数量之和；<br>- 总体积X m³：所选订单委托体积之和；<br>- 清空：取消全部选择；<br>- 下载标签：将所选订单的航空标签打包为一个压缩文件下载。 |

订单状态与操作规则：

- 待入库：当前没有发生过任何入库。
- 已入库：只有发生了货物入库，状态便是“已入库”。
- 待出库：接收到上游的出库指令，但还没有完成对应的出库（发给WMS出库指令，WMS还没反馈出库完成）。
- 部分出库：已实际出库数量（件数）<=总入库数量。
- 已出库：已实际出库数量（件数）=总入库数量。
- 已取消：上游系统发送取消订单指令，并成功取消。
- 订单行操作：“编辑”用于修改；“详情”用于查看订单详情；“标签”用于下载该订单的“打印”标签。
