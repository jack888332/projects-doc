## 1. 消息推送


**业务入口：** 消息推送页面。

### 1.1 消息推送业务范围

<a id="doc-5F950AB3B1-section-64f8c72867c1"></a>
#### 1.1.1 消息渠道与适用范围

消息推送按业务触发条件，通过短信、企业微信或邮件向指定对象发送通知。

<a id="doc-5F950AB3B1-section-26ed19e0c911"></a>
### 1.2 航晟物流消息推送规则

<a id="doc-5F950AB3B1-section-0aac2850dc82"></a>
#### 1.2.1 订单调度邮件通知

- 系统根据用车调度结果，自动发送邮件到预留的客户邮箱地址。

<a id="doc-5F950AB3B1-section-11ddcb71608e"></a>
#### 1.2.2 调度邮件通知规则

| 场景名称 | 调度信息系统邮件自动发送 |
| --- | --- |
| 范围/概述 | 对于调度和修改调度的信息，系统提供发送邮件通知给客户 |
| 主要参与者 | 系统自动触发 |
| 前置条件 | 录入调度信息（单笔调度和批量调度）与修改调度，才会自动触发邮件通知。 |
| 业务结果 | 符合自动发送邮件条件时，系统将邮件发送至指定邮箱地址。 |
| 主业务流程 | 1. 邮件按订单发送；批量调度多笔订单时，每笔订单分别发送一封邮件。<br>1. 单笔调度提交、批量调度提交或单笔调度修改保存后触发邮件。<br>1. 收件人为订单中选定的委托方联系人邮箱；抄送人为主数据中配置的航晟物流客服部邮箱。<br>1. 调度邮件标题为“《单号：<单号>》的调度安排”；修改调度邮件标题为“《单号：<单号>》的调度调整”。<br>1. 正文字段无值时不显示对应行。调度邮件正文包含车辆数，以及每辆车的车牌号、司机姓名、联系电话、司机身份证、车型、公司地址、海关编号、车自重、柜号、架重、柜重和客户密码；多辆车之间空一行。正文附用车申请的件数、重量、体积、尺寸、提货点和卸货点。<br>1. 修改调度邮件先展示原车牌号与变更后车牌号，再按调度邮件格式展示各车辆和原用车申请信息；未变更车辆仍按相同格式展示。 |
| 业务分支 | 取消调度的场景，则不用发送系统邮件。 |

<a id="doc-5F950AB3B1-section-a6e33a4650f8"></a>
#### 1.2.3 订单企业微信通知

- 针对相关场景节点，自动推送微信通知，以作实时提醒。

<a id="doc-5F950AB3B1-section-5abcb3a0e4eb"></a>
#### 1.2.4 订单企业微信通知规则

| 场景名称 | 微信消息自动推送 |
| --- | --- |
| 范围/概述 | 系统自动触发发送微信消息内容到指定的企业微信账号 |
| 主要参与者 | 航晟物流 |
| 前置条件 | 特定的业务场景下触发 |
| 业务结果 | 接收的对象精准无遗漏，消息内容正确 |
| 主业务流程 | 1. 未调度订单提醒：每天18:00检查状态为“未调度”且提货日期不晚于次日的运输订单。存在符合条件的订单时，向配置的航晟卡车部主管和客服人员发送“今天还有<未调度订单数量>个订单未处理，请尽快处理！”<br>1. 司机异常提醒：司机通过小程序上报运单异常后，立即向航晟卡车部客服人员发送“运单号<运单号>：司机（联系方式：<司机联系方式>）上报了异常（<异常类型>），请关注处理！”<br>1. 调度取消提醒：已调度订单被取消后，向航晟卡车部客服人员发送“委托方：<委托方>，订单号：<订单号>，已取消订单，请关注处理！”订单号为空时依次改用子单号、批次号。 |

<a id="doc-5F950AB3B1-section-72426f54db3e"></a>
#### 1.2.5 车辆到期企业微信通知

- 针对相关场景节点，自动推送微信通知，以作实时提醒。

<a id="doc-5F950AB3B1-section-3c5f41544979"></a>
#### 1.2.6 车辆到期通知规则

| 场景名称 | 微信消息自动推送 |
| --- | --- |
| 范围/概述 | 系统自动触发发送微信消息内容到指定的企业微信账号 |
| 主要参与者 | 航晟物流 |
| 前置条件 | 特定的业务场景下触发 |
| 业务结果 | 接收的对象精准无遗漏，消息内容正确 |
| 主业务流程 | 1. 年审到期提醒：当年审日期与当前日期的差值不超过30天时，当日9:00向配置的航晟卡车部主管发送“车牌号：<车牌号>，距离本次年审（<年审日期>）已不足30天，请留意处理！”<br>1. 保险到期提醒：当保险期止日与当前日期的差值不超过30天时，当日9:00向航晟卡车部客服人员发送“车牌号：<车牌号>，距离本次保险到期（<保险到期日>）已不足30天，请留意处理！” |

<a id="doc-5F950AB3B1-section-50517cbc7d00"></a>
#### 1.2.7 登录短信验证码

- 高捷物流小程序支持获取短信验证码。

<a id="doc-5F950AB3B1-section-8aa7a963b21f"></a>
#### 1.2.8 登录验证码规则

| 场景名称 | 用户登录页面 |
| --- | --- |
| 范围/概述 | 可通过短信验证码校验或者微信快捷登录方式完成登录。 |
| 主要参与者 | 司机 |
| 前置条件 | 在订单调度时，录入了调度的司机联系方式。 |
| 业务结果 | 可成功登录，并进入小程序。 |
| 主业务流程 | 1. 输入手机号时校验其为11位数字。<br>1. 点击“获取验证码”后先完成图形校验；校验通过后发送验证码并开始60秒倒计时，倒计时结束后可再次获取。短信内容为“【高捷物流】您本次的验证码为<验证码>，请不要告诉其他人。”<br>1. “保持登录状态”默认勾选，用户可取消；勾选后系统保持登录，未勾选时下次登录需重新验证。<br>1. 点击“登录”后，验证码通过则进入首页；验证码失败时提示“验证码错误，请重新输入！”<br>1. 用户也可通过微信授权登录，系统按微信绑定手机号匹配账号。 |

<a id="doc-5F950AB3B1-section-355bae4e92cc"></a>
#### 1.2.9 空运赶单企业微信预警

- 系统在空运赶单节点自动推送企业微信预警。

<a id="doc-5F950AB3B1-section-2008fa54badc"></a>
#### 1.2.10 空运赶单预警规则

| 场景名称 | 空运赶单预警微信通知 |
| --- | --- |
| 范围/概述 |  |
| 主要参与者 | 地面服务人员 |
| 前置条件 | 基于空运的主单/分单进行预警时间段的提醒。 |
| 主业务流程 | 1. 仓库赶单预警：航班起飞时间距当前时间12小时30分钟、对应主单或分单选择“我司仓库服务”且仓库订单状态为“待入仓”时，向航晟物流仓库客服人员发送“入仓号：<入仓号>的航班起飞时间为<航班起飞时间>，剩余时间已接近12小时，请跟进货物到库情况。”<br>1. 中转派车预警：航班起飞时间距当前时间10小时30分钟且对应中转订单的仓库订单状态为“打包中”时，向航晟物流卡车客服人员发送“入仓号：<入仓号>的航班起飞时间为<航班起飞时间>，剩余时间已接近10小时，请跟进货物中转派车情况。” |

<a id="doc-5F950AB3B1-section-b42f0635c9-message"></a>
#### 1.2.11 货站打板企业微信通知规则

| 场景名称 | 货站打板企业微信通知 |
| --- | --- |
| 范围/概述 | 系统在板纸修改和货站赶单预警场景触发企业微信通知。 |
| 主要参与者 | 货站打板人员、货站打板主管、空运客服、航线部 |
| 前置条件 | 板纸修改提交成功，或当前时间距离航班起飞时间8小时30分钟。 |
| 业务结果 | 系统向对应业务角色发送通知。 |
| 主业务流程 | 1. 板纸修改通知：货站打板人员通过“板纸上传”功能修改已上传板纸并提交后，系统向货站打板主管、空运客服和航线部人员发送企业微信通知。消息内容为“航班号：<航班号>，板纸已修改，请留意变更！”<br>1. 货站赶单预警：当前时间距离航班起飞时间8小时30分钟时，系统向货站打板人员和货站打板主管发送企业微信通知。消息内容为“提单号：<提单号>，距离航班起飞已不足8.5小时，请及时跟进货物进站！” |

<a id="doc-5F950AB3B1-section-19cc14201b04"></a>
### 1.3 空运业务消息推送规则

<a id="doc-5F950AB3B1-section-be4a7d363155"></a>
#### 1.3.1 空运入仓图邮件发送

- 系统根据客服手动操作结果，发送入仓图到预留的客户邮箱地址。

<a id="doc-5F950AB3B1-section-89184bd561de"></a>
#### 1.3.2 入仓图邮件规则

| 场景名称 | 系统邮件手动发送 |
| --- | --- |
| 范围/概述 | 对于入仓图，客服手动点击发送后，发送邮件给客户 |
| 主要参与者 | 空运客服 |
| 前置条件 | 当空运客服手动点击发送时 |
| 业务结果 | 客户有指定的邮箱地址。 |
| 主业务流程 | 1. 订单状态为“待订舱”“待补录”或“待出提单”时显示“发送”按钮；同一订单仅可发送一次，发送后按钮不再显示。<br>1. 客服点击“发送”后触发邮件。收件人为客服在订单委托方联系人邮箱中勾选的联系人，抄送人为订单创建客服及空运客服主管。<br>1. 邮件标题为“入仓图通知：《订单号：<订单号>（毛件体：<毛件体>；中文品名：<中文品名>；出港日期：<出港日期>）》的入仓地图”。<br>1. 正文字段无值时不显示对应行；正文说明订单货物的入仓图已下发，并提示附件SO可供查收，客服联系方式取配置的<客服联系方式>。<br>1. 附件中的订单号、目的港、件数、商品名、体积、重量和操作人取订单数据，操作人为当前客服姓名。 |

<a id="doc-5F950AB3B1-section-e1b9654274f9"></a>
#### 1.3.3 空运服务节点邮件通知

- 系统根据货物轨迹、报关状态、部分订单状态，自动发送在途跟踪邮件到预留的客户邮箱地址。

- 修改航班、毛件体时自动发送通知。

<a id="doc-5F950AB3B1-section-e48548e84cac"></a>
#### 1.3.4 空运服务节点邮件规则

| 场景名称 | 系统自动发送在途跟踪邮件 |
| --- | --- |
| 范围/概述 | 对于顾客已经订购的服务，系统提供发送轨迹节点邮件通知给客户 |
| 主要参与者 | 系统自动触发 |
| 前置条件 | 客户选择某项服务，该服务的服务节点才会自动触发邮件通知。 |
| 业务结果 | 符合自动发送邮件条件时，系统将邮件发送至指定邮箱地址。 |
| 主业务流程 | 1. 邮件按服务节点状态发送，且仅在客户订购对应服务时触发。收件人为订单中的委托方联系人邮箱，抄送人为订单创建客服和空运客服主管。邮件标题为“《订单号：<订单号>（毛件体：<毛件体>；中文品名：<中文品名>；出港日期：<出港日期>）》的状态轨迹”。正文字段无值时不显示对应行，通用客服联系方式取<客服联系方式>。<br>1. 已派车：通知车辆正前往<目的地址>，并逐车展示<司机姓名>、<司机身份证号>、<车牌号>和<车型>。<br>1. 已提货：通知货物已提走并将送达<送达地址>。<br>1. 已入仓库：接收WMS入仓数据后，通知货物已入<仓库地址>，并展示<入仓毛件体>。<br>1. 已出仓库：通知货物已出仓库，目的地取订单对应航班的<货站名称>。<br>1. 到货站：通知货物已到<货站名称>。<br>1. 已过安检：通知货物已通过安检。<br>1. 已出运：通知货物已出运，并展示<航班号>。<br>1. 已中转：通知航班已中转。<br>1. 已到达：通知货物已到达目的港。<br>1. 目的地提货：通知货物已在目的地提货。<br>1. 已清关送达：通知货物已完成清关送达。<br>1. 报关放行：通知货物已放行并附报关单；主单下全部分单放行后，一次发送全部报关单。<br>1. 已订舱：订单状态变为“待补录”时，展示<主提单号>、<航班号>、<货站名称>、<截单时间>和<装板公司>。<br>1. 修改航班信息：航线部修改航班信息后，展示<主提单号>，以及航班、截单时间和装板公司的变更前后值。<br>1. 修改运费卖价：客服修改卖价后，展示<毛件体>、<主提单号>、<航班号>、<货站名称>，以及运费卖价、后端卡车卖价和分泡比例的变更前后值；毛件体按提单、入仓、预计的顺序取值。 |
