## 2. 应付对账单管理


<a id="doc-30A62F6230-section-313e3234bff9"></a>
### 2.1 应付对账单页面

应付对账单页面，可查看、搜索、删除、确认所有的应付对账单信息以及发送账单信息至供应商邮箱。

<a id="doc-30A62F6230-section-1f2438f929fd"></a>
### 2.2 应付对账单列表页面

**操作与反馈**

- 待对账列表：跳转至“待对账列表”界面。

- 对账单明细列表：跳转至“对账单明细列表”界面。

- 查询：按填写的条件查询；未设置条件时查询全部记录。查询结果按照“创建日期”倒序排列。

- 重置：重置所有查询条件。

- 查看：跳转至“应付对账单明细”查看界面。

- 删除：弹出“对账单删除”弹框。

- 确认：弹出“对账单确认”弹框。

- 发送邮件：弹出“发送邮件确认”弹框。

**界面原型概述 · 应付对账单查询栏**

- **区域字段或业务元素**：对账单号、结算单位、应收应付周期、创建人、创建日期、状态。
- **区域级通用规则**：查询条件均选填、无预设值。

| 字段或控件特例 | 界面特例或可见反馈 |
| --- | --- |
| 对账单号 | 填写对账单号，支持模糊查询。 |
| 结算单位 | 填写结算单位，支持模糊查询。 |
| 应收应付周期 | 填写应收应付周期。 |
| 创建人 | 填写创建人，支持模糊查询。 |
| 创建日期 | 日期范围框，选择日期范围；不选择默认全部日期。 |
| 状态 | 状态有：新建、已确认。 |

**界面原型概述 · 应付对账单列表栏**

- **区域字段或业务元素**：对账单号、状态、结算单位、应收应付周期、对账单属性、创建人、创建日期。
- **区域级通用规则**：除所列特例外，字段均只读；按查询条件展示匹配记录；未设置查询条件时展示全部记录。

| 字段或控件特例 | 界面特例或可见反馈 |
| --- | --- |
| 对账单号 | 系统自动生成。 |
| 状态 | 仅展示“新建”、“已确认”两种状态的对账单；“新建”状态的对账单，可以进行查看、删除、确认、发送邮件操作；“已确认”状态的对账单可进行查看操作。 |
| 对账单属性 | 默认所有应付状态的对账单。 |

### 2.4 应付对账单删除操作

在应付对账单列表页面点击“删除”按钮，系统打开“删除确认”对话框。

### 2.11 应付对账单新增

**业务范围**：选择结算单位，勾选结算明细数据，录入备注、上传附件，完成应付对账单新增

**参与角色**：业务/财务

**前置条件**：进入结算对账管理->应付对账管理->待对账列表页面，勾选需要生成对账单的订单信息（订单信息必须要同一个结算单位），点击“新增”按钮，进入此页面

**业务结果**：校验通过后生成应付对账单；保存时状态为“新建”，保存并确认时状态为“已确认”。校验失败时不生成对账单并提示原因。

**处理规则**

勾选结算明细数据，进入“新建应付对账单”页面，录入备注和上传附件。

**备注**

- 输入200个字符以内的内容。

- 未保存前，可重新输入备注。

**附件**

- 上传的附件格式只能是文档格式、图片格式，大小限制在20m以内。

- 未保存前，可重新上传。

明细信息每页显示50条，支持翻页。

点击“保存”进行保存确认。

- 确认：自动生成对账单号，规则BL+6位年月日（YYMMDD）+5位流水，如BL20112600002，把数据状态改成“新建”状态，跳转到“应付待对账单列表”界面。

- 取消：不确认保存该对账单。

点击“保存并确认”进行提交保存。

- 确认：自动生成对账单号，规则BL+6位年月日（YYMMDD）+5位流水，如BL20112600002，把数据状态改成“已确认”状态，跳转到“应付待对账单列表”界面。

- 取消：不确认保存该对账单。

### 3.11 应收对账单新增

**业务范围**：选择结算单位，勾选结算明细数据，录入备注、上传附件，完成应收对账单新增

**参与角色**：业务/财务

**前置条件**：进入结算对账管理->应收对账管理->待对账列表页面，勾选需要生成对账单的订单信息（订单信息必须要同一个结算单位），点击“新增”按钮，进入此页面

**业务结果**：校验通过后生成应收对账单；保存时状态为“新建”，保存并确认时状态为“已确认”。校验失败时不生成对账单并提示原因。

**处理规则**

勾选结算明细数据，进入“新建应收对账单”页面，录入备注和上传附件。

**备注**

- 输入200个字符以内的内容。

- 未保存前，可重新输入备注。

**附件**

- 上传的附件格式只能是文档格式、图片格式，大小限制在20M以内。

- 未保存前，可重新上传。

明细信息每页显示50条，支持翻页。

点击“保存”进行保存确认。

- 确认：自动生成对账单号，规则BL+6位年月日（YYMMDD）+5位流水，如BL20112600002，把数据状态改成“新建”状态，跳转到“应收待对账单列表”界面。

- 取消：不确认保存该对账单。

点击“保存并确认”进行提交保存。

- 确认：自动生成对账单号，规则BL+6位年月日（YYMMDD）+5位流水，如BL20112600002，把数据状态改成“已确认”状态，跳转到“应收待对账单列表”界面。

- 取消：不确认保存该对账单。
