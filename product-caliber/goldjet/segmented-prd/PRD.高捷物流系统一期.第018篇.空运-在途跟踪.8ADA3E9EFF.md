#### 1.3.2 业务规则说明

| 场景名称 | 空运-在途跟踪 |
| --- | --- |
| 范围/概述 | 有主订单号/已配置提单号的订单 |
| 主要参与者 | 空运客服 |
| 前置条件 | 进入系统，点击《在途跟踪》按钮，进入此页面 |
| 业务结果 | 页面操作功能可正常使用，可成功提交。 |
| 主业务流程 | 进入《在途跟踪页面》页面，可输入主订单号或者提单号进行搜索。系统根据主订单号或者提单号可搜索出对应订单的在途跟踪轨迹。<br>1.<br>- 查询按钮：点击查询<br>重置按钮：点击后订单号和提单号输入框信息清空<br>2.<br>以上字段取自空运系统，有值显示，无值留空<br>航班号由头程航班+出港日期拼接而成，举例：CZ327/02.DEC<br>前半部分（CZ327）：取值订舱管理的头程航班<br>后半部分（/02.DEC）：/+出港日期的日期+.+出港日期的月份英文<br>3.<br>1）以运单号的tab切换展示对应的轨迹信息，当前运单号选中状态<br>运单未选中状态<br>2）倒序，默认显示最新两条轨迹信息，服务状态为“异常结束”则轨迹信息标红<br>3）多于两条轨迹信息则缩略显示，点击则全部展开轨迹信息<br>再次点击，则缩略为最新两条轨迹信息<br>4.<br>航班号由头程航班+出港日期拼接而成，举例：CZ327/02.DEC<br>具体逻辑请参照上面<br>5.<br>6.<br>7.<br>8.<br>9.<br>10.<br>11. |
