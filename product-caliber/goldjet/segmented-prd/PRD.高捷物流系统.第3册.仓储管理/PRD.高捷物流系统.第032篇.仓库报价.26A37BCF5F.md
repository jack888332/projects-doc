## 1. 仓库报价

**业务入口：** 仓库报价

**概念模型：** [数据字典 · 合作方与报价实体](../PRD.高捷物流系统.第6册.运营支撑/PRD.高捷物流系统.第061篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-domain-partners-quotes)

### 1.1 仓库报价业务范围、角色与流程

<a id="doc-26A37BCF5F-section-9f9cfe930870"></a>
#### 1.1.1 仓库报价覆盖范围

仓库报价按客户和报价科目维护仓库服务收费信息，支持报价新增、修改、查询、启用和失效。报价通过生效日期和截止日期控制适用期间。

<a id="doc-26A37BCF5F-section-5170c8593ebb"></a>
#### 1.2.2 仓库报价新增页面

**操作与反馈**
- 提交：提交时对必填信息、报价信息进行校验，若必填项为空时，则系统提交时会标红提示该错误，并不允许提交；如果报价相同且有效日期重叠，那么提交时失败，并提示“已存在报价，请勿重复添加”。根据字段：客户、报价科目、生效日期、截止日期判断。如果客户、报价科目相同且生效日期重叠，则判断为相同报价。

- 取消：取消新增仓库报价，并返回仓库报价列表。

- 查询：未设置查询条件时查询全部记录；设置条件后展示匹配记录。查询出的数据，按照客户首个字母拼音顺序排列。

- 重置：重置查询条件。

- 修改：点击跳转前，确认是否保存当前报价，跳转至“修改仓库报价记录”页面。

- 失效/启用：“生效”的报价在未到截止日期可以人为点击“失效”停用该报价。点击“启用”可以重新使“失效”并且还在“截止日期”内的报价生效。

- 新增：重置当前的新增中的报价。

**界面原型概述 · 仓库报价新增**

- **区域字段或业务元素**：客户、税率（%）、币种、报价科目、报价金额、单位、计费方式、生效日期、截止日期、备注。
- **区域级通用规则**：除所列特例外，字段均必填、可编辑。

| 字段或控件特例 | 特例约束或业务结果 |
| --- | --- |
| 客户 | 所有客户，由系统合作方档案管理类型为“客户”带出。 |
| 税率（%） | 提交时校验税率；取值范围为 0～100，最多保留两位小数。 |
| 币种 | 币种代码。 |
| 报价科目 | 卸载操作费（元/KG）；卸载最低费（元）；仓储费（KG/天）；免租期（天）；打托费（元）；拆托费（元）；加重费（元）；分拣费（元）；改标签（元）。 |
| 报价金额 | 保留小数点后2位。 |
| 单位 | 选项：千克、个、托、次。 |
| 计费方式 | 选项：常规、其他。 |
| 生效日期 | 格式“YYYY-MM-DD”，默认当天。 |
| 截止日期 | 格式“YYYY-MM-DD”，结合生效日期判断报价状态“生效”“失效”“待生效”。 |
| 备注 | 选填。 |

1. 仓库报价新增规则

**场景：** 仓库客户报价管理-仓库客户报价新增

**范围：** 填写客户信息、报价信息，提交完成报价新增。

**参与角色：** 航晟客服、主管

**触发与入口：** 进入仓库客户报价管理，点击“新增报价”按钮，进入此页面

**业务结果：** 有效报价保存后进入仓库客户报价列表；必填信息缺失或报价重复时不保存并提示原因。

**处理规则**

进入“新建报价”页面，填写：客户信息、报价信息。

**客户信息**

- 客户：所有客户，由系统合作方档案管理类型为“客户”带出。

- 税率（%）：填写税率，最大值不能大于100，提交时校验，保留小数点2位。

- 币种：选择结算的币种代码，和结算系统的币制代码一致。

- 未保存前，可重新修改客户信息。

**报价信息**

- 报价科目：选择一个报价科目。

- 报价金额：录入数值，保留小数点后2位。

- 未保存前，可重新修改报价信息。

- 生效日期：生效日期默认为提交报价当天。录入生效日期，格式“YYYY-MM-DD”。

- 截止日期：录入截止日期，格式“YYYY-MM-DD”。

- 未保存前，可重新修改报价信息。

点击“确认”进行提交保存。

- 提交成功：显示“保存成功”提示，跳转到“仓库客户报价管理列表”界面。

- 无法提交：若必填项未输入，则该输入项红色高亮提示；

#### 1.2.3 仓库报价修改页面

**操作与反馈**
- 提交：提交时对必填信息、报价信息进行校验，若必填项为空时，则系统提交时会标红提示该错误，并不允许提交；如果报价相同且有效日期重叠，那么提交时失败，并提示“已存在报价，请勿重复添加”。根据字段：客户、报价科目、生效日期、截止日期判断。如果客户、报价科目相同且生效日期重叠，则判断为相同报价。

- 取消：取消修改仓库报价，并返回仓库报价列表。

1. 修改说明

- 客户信息不可编辑，页面上的对应数据置灰。

**界面原型概述 · 仓库报价修改**

- **区域字段或业务元素**：客户、税率（%）、币种、报价科目、报价金额、单位、计费方式、生效日期、截止日期、备注。

| 字段或控件特例 | 特例约束或业务结果 |
| --- | --- |
| 客户、税率（%）、币种 | 不可修改；只读。 |
| 报价科目 | 卸载操作费（元/KG）；卸载最低费（元）；仓储费（公斤/天）；免租期（天）；打托费（元）；拆托费（元）；加重费（元）；分拣费（元）；改标签（元）；必填；可编辑。 |
| 报价金额 | 保留小数点后2位；必填；可编辑。 |
| 单位 | 选项：千克、个、托、次；必填；可编辑。 |
| 计费方式 | 选项：常规、其他；必填；可编辑。 |
| 生效日期、截止日期 | 格式“YYYY-MM-DD”；必填；可编辑。 |
| 备注 | 选填；可编辑。 |

1. 仓库报价修改规则

**场景：** 仓库客户报价管理-仓库客户报价修改

**范围：** 修改报价信息，点击提交完成修改。

**参与角色：** 航晟客服、主管

**触发与入口：** 进入仓库客户报价管理，点击“修改”按钮，进入此页面

**业务结果：** 有效修改保存后更新仓库客户报价列表；必填信息缺失或报价重复时不保存并提示原因。

**处理规则**

进入“修改报价”页面，客户信息不可修改，报价信息可编辑。

1. 报价科目：选择一个报价科目。

1. 报价金额：录入数值，保留小数点后2位；保存前可继续修改。

1. 生效日期：默认为提交报价当天，格式为“YYYY-MM-DD”。

1. 截止日期：录入报价截止日期，格式为“YYYY-MM-DD”；保存前可继续修改。

1. 点击“确认”提交保存。保存成功后提示“保存成功”，并跳转到仓库客户报价管理列表；必填项未输入时，对应输入项显示红色高亮提示。

#### 1.2.4 仓库报价列表页面

**操作与反馈**

- 重置：重置查询条件。

- 新建报价：跳转至“新增仓库报价记录”页面。

- 修改：跳转至“修改仓库报价记录”页面。

- 删除：删除当前选择的仓库报价记录，点击删除有删除确认提示。
