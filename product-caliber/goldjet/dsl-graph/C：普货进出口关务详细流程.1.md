## 2. 退运及出口报关流程（标题为推断）

```plantuml
start

else (未申报)
  :申请直接退运;
  -> 线下提交资料办理退运手续，;
  :确认已办理退运手续;
  -> 货站安排运货到指定仓库贴标签，\n称重，录入预配信息;
  :提交出口报关单;
  :提交进口报关单;
  :查看报关状态;
  if (报关状态) then (查验)
    :安排查验;
    if (查验异常？) then (是)
      :查验异常处理;
      -> 查验通过;
    else (否)
    endif
    :放行交单;
    :货物离境;
  else (放行)
  endif
endif
stop
@enduml
```

```plantuml

title 普货进口卡航（国外空运—广州机场—卡车航班转运国内其他口岸）流程

:接单;

  :联系客户，确认处理方案;

:提货装车;
:封车;
:确认发车;
:车辆离场;
stop
@enduml
```

## 5. 到货换单理货流程（标题为推断）

```plantuml
@startuml
title 到货换单理货流程
start
:新建订单;
:接单;
:查到货信息;
if (到货异常) then (是)
  :通知客户处理;
  -> 处理完成;
else (否，线下换单，盖章，结算)
endif
:确认换单完成;
:做分运清单;
:到货站交单;
if (货物是否破损) then (是)
  :出破损证明;
  :通知客户;
else (否)
endif
:到货站找货;
:拉货回我司监管仓;
:理货;
if (理货异常) then (是)
  :通知客服;
  :通知客户，确认异常情况;
else (否，加盖验讫章)
endif
:上传分单理货数据;
:转仓完成;
stop
@enduml
```

## 6. 普货进口主流程（标题为推断）

```plantuml
@startuml
title 普货进口主流程
start
:新建订单;
:接单;
:审核资料;
while (审核通过？) is (否)
  :审核资料;
endwhile (是)
:制单录入;
:初审复审;
-> 有舱单回执;
:提交申报;
if (申报异常？) then (是)
  :申报异常处理;
  -> 处理完成;
else (否，且货物已运抵)
endif
:确认换单完成;
-> 线下录运抵后;
:查看报关状态;
-> 查验;
:安排查验;
if (查验异常？) then (是)
  :查验异常处理;
else (否)
endif
:放行;
if (提货方式) then (客户要求提货)
  :约车;
  :装车出仓;
  :送货;
  :确认客户已签收;
else (客户自提)
  :记录客户提货信息;
endif
stop
@enduml
```

- 区域 3 中“联系货站处理”原图无后续连线，此处按流向汇入“确认换单完成”。
- 区域 5 中“到货异常”另有一条未标注的到“确认换单完成”的连线，未纳入。
- 区域 6 中“查看报关状态”原图仅标注“查验”一条出口（“查看报关状态→[放行]→结束”的连线经坐标核实属于区域 2），“审核通过？→否→审核资料”的回退用 while 循环表达。
