# 待开发需求：返款账单结算币种与包裹级回款、返款事实的汇率适配

| 变更范围 | 返款账单金额计算、包裹级回款事实保留、返款账单详情及回款管理展示。 |

## 2. 本次变更

### 2.1 统一回款与返款的币种、汇率边界（修改）

变更前，订单费用报表提供包裹级`实收回款`、`回款汇率`、`实付返款`和`返款汇率`，返款账单配置又可单独设置货款原始币种与货款结算币种。由于来源报表没有实付返款币种字段，包裹来源值无法唯一确定账单结算结果。本次将来源事实与账单计算拆为两条独立链路：

| 链路 | 金额和币种 | 汇率来源 | 处理规则 |
| --- | --- | --- | --- |
| 包裹回款链路 | `实收回款`为尾程包裹级导入事实；没有回款汇率时按目的国币种保留，有回款汇率时按导入结果保留财务本位币 | 导入的`回款汇率`，货币对为目的国币种 → 财务本位币 | 仅用于记录尾程包裹实际回款及回款核对，不作为返款账单的结算汇率。 |
| 返款账单链路 | `应付返款（即代收货款）`为业务订单级OIS机算值，使用货款原始币种；`实付返款（准）`先使用货款原始币种，最终`实付返款`使用货款结算币种 | 按客户级汇率规则取得并锁定`返款汇率`，货币对为货款原始币种 → 货款结算币种 | 以返款账单配置和账单锁定汇率为准，不使用历史包裹导入的返款汇率或实付返款计算返款金额。 |
| 历史包裹返款来源链路 | 历史`实付返款`和`返款汇率`为尾程包裹级导入事实，缺少实付返款币种字段 | 历史导入的`返款汇率`为目的国币种 → 财务本位币 | 只保留存量原记录，不在返款账单详情和对账报表中继续展示，不参与结算币种、返款汇率、金额计算或核销。 |

#### 2.1.1 返款账单的计算顺序

1. 在货款原始币种中确认`应付返款（即代收货款）`本金：`应付返款 = 到付金额 - 到付附加费总额`。
2. 将返款账单指定扣减费项换算为货款原始币种后汇总，计算`实付返款（准） = 应付返款 - 返款账单指定扣减费项`。
3. 按配置确定`货款原始币种 → 货款结算币种`的`返款汇率`并锁定；同一币种之间固定为`1`。
4. 计算`实付返款 = 实付返款（准） × 返款汇率`，币种为货款结算币种。
5. 客户收款账户币种必须与货款结算币种一致；缺少对应账户或必要汇率时，受影响业务订单不得生成返款结果。

#### 2.1.2 包裹级事实与订单级金额的关系

- `应付返款`及其符合配置的`代收货款手续费`按业务订单归集；它们的机算结果由OIS输出，BMS读取并参与返款账单计算。
- `实收回款`、包裹级`回款汇率`和历史包裹级`实付返款`、`返款汇率`均保留在尾程包裹明细中，不复制到同一订单的其他包裹，也不拆分订单级返款金额。
- 一票多件时，`回款返款`只要任一尾程包裹录入有效`实收回款`，业务订单即可进入返款账单归集范围；其他包裹继续独立记录回款状态。

#### 2.1.3 回款与返款汇率不得混用

包裹导入的`回款汇率`是回款来源事实，货币对为目的国币种 → 财务本位币；返款账单的`返款汇率`按客户配置取得，货币对为货款原始币种 → 货款结算币种。两者货币对和用途不同，不得互相替代。

### 2.2 汇兑损益如何形成（修改）

汇兑损益用于比较同一笔换算前返款金额分别按回款汇率和返款汇率折算后的差额，只在返款账单中计算和展示。

1. `汇兑损益金额 = 实付返款（准） ×（标准化回款汇率 - 标准化返款汇率）`。
2. 两个汇率相减前必须同货币对、同汇兑方向；以回款汇率货币对为准，不一致时用账单锁定汇率换算。
3. 汇兑损益金额只在返款账单详情和面向财务的内部导出中展示，回款管理不展示，客户页面、客户邮件和面向客户的对账报表均不得展示。
4. 汇兑损益不参与实付返款、已返金额、待返金额或核销金额，也不回写订单费用报表的实收回款和回款汇率。

例如：到付金额为`70 TWD`，到付附加费为`10 TWD`，指定扣减费项为`20 TWD`，则`实付返款（准） = 40 TWD`。回款汇率为`0.2`、返款汇率为`0.15`且货币对均为`TWD → CNY`时，`汇兑损益金额 = 40 ×（0.2 - 0.15）= 2 CNY`。

## 3. 变更后的边界与结果

| 内容 | 本次规则 |
| --- | --- |
| 生效范围和时点 | 适用于按当前返款账单配置新生成的账单，以及规则允许重算的未发出账单；账单生成时锁定本次使用的结算币种和汇率。 |
| 存量数据与已生效结果 | 历史包裹级实付返款和返款汇率只保留原记录，不展示、不参与计算；已发出、已结清或其他不允许重算的账单不因导入汇率、包裹回款或配置变化自动改写。 |
| 来源缺失 | 缺少回款汇率或必要换算汇率时，汇兑损益金额显示为`--`并说明缺失项；缺少返款汇率或同币种客户收款账户时，受影响业务订单不得生成返款结果。 |
| 账单结果 | 返款账单按货款结算币种分桶展示`实付返款（准）`、指定扣减费项、`返款汇率`和`实付返款`；汇兑损益仅财务可见。 |
| 回款管理 | 展示包裹级回款事实并关联返款账单结果；不重新计算返款金额、返款汇率或汇兑损益。 |
