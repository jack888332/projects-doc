#### 1.1.3 客服工作台展示与快捷入口

| 场景名称 | 空运客服、空运客服主管工作台 |
| --- | --- |
| 范围/概述 | 集中展示空运客服和空运客服主管的待办、快捷入口与消息。 |
| 主要参与者 | 空运客服、空运客服主管 |
| 前置条件 | 用户已登录并具备空运客服或空运客服主管角色 |
| 业务结果 | 工作台展示当前角色可处理的任务、快捷入口和消息通知 |
| 主业务流程 | 1. “总待办”显示所有未处理任务的数量。<br>1. 待办任务进度条=未处理任务数/（已处理任务数+未处理任务数）。<br>1. “我的待办”最近更新时间显示待办任务进度条最后一次变化的时间。<br>1. 快捷入口包括主订单、子订单、提单制作、自建仓库订单、结算订单成本和核算订单成本。<br>1. 待办任务概览按创建时间升序展示所有未处理任务，每页最多20条。<br>1. 消息通知展示企业微信通知的消息类型和内容，每页最多10条。 |
