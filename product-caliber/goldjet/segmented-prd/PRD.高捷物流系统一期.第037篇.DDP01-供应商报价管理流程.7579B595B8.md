### 1.1 航晟物流：供应商报价管理的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 线下提供报价单 | 供应商 | 供应商按自己的报价单格式在线下提供报价。 |  |  |
| 2 | 判断是否可以上传导入 | 航晟物流客服 | 报价单符合统一格式时支持上传导入；不符合统一格式时改为手工新建报价记录。 | 2 |  |
| 3 | 上传报价单 Excel | 航晟物流客服 | 客服选择上传方式时，上传符合统一格式的报价单 Excel 文件。 | 5 |  |
| 4 | 新建报价记录 | 航晟物流客服 | 客服按供应商报价单录入报价。录入时可以复制已有报价记录，再修改需要变化的内容。 | 5 | 是 |
| 5 | 查看报价列表 | 航晟物流客服 | 列表展示已录入的供应商报价，并提供筛选和搜索。 | 6 |  |
| 6 | 判断是否修改 | 航晟物流客服 | 报价录入错误或需要更新时，客服进入报价编辑。 |  |  |
| 7 | 编辑或删除报价记录 | 航晟物流客服 | 客服可以编辑或删除单条报价，也可以批量删除多条报价。 |  |  |
