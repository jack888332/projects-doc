# 变更需求：将账单配置的结算币种规则改为表格维护

> Commit：空

## 1. 变更原因与范围

当前应收账单配置将默认结算币种和指定结算币种分开维护，返款账单配置也分开维护货款原始币种、货款结算币种和客户收款账户。财务配置多条规则时，难以一次看清明确规则、兜底规则及其默认值。

本次将两类结算币种规则分别集中到一张表中：

- 应收账单按费项维护结算币种。
- 返款账单按货款原始币种维护结算币种和客户收款账户。
- 其他账单配置、已生成账单及既有金额换算规则不变。

## 2. 变更总览

| 变更点 | 修改前 | 修改后 |
| --- | --- | --- |
| 应收账单配置（CP-01） | 默认结算币种、指定结算币种分开维护 | 在“费项结算币种”表中统一维护明确费项规则和兜底规则 |
| 返款账单配置（CP-02） | 原始币种、结算币种和客户收款账户分开维护 | 在“货款结算币种”表中按原始币种维护结算币种和客户收款账户 |

## 3. 两张表共用哪些规则？

### 始终保留末行兜底规则（R-01）

1. 每张表必须且只能保留一条兜底规则，且兜底规则始终位于末行。
2. 没有明确规则时，兜底规则的匹配范围显示为“全部”；存在明确规则时显示为“其他”。
3. 兜底规则的匹配范围为只读字段，财务不能修改或删除兜底规则。
4. 财务可以新增或删除明确规则，不能删除兜底规则。

### 保存时校验最终规则（R-02）

1. 保存配置时，系统校验必填字段、重复规则、兜底规则数量及位置。
2. 任一规则不符合要求时，系统不保存本次修改并提示原因。

## 4. 应收账单怎样维护费项结算币种？（CP-01）

业务落点：BMS 应收账单配置编辑页的默认方案或分支方案。`见图1`

### 合并为“费项结算币种”表（R-03）

1. 移除“费项默认结算币种”设置。
2. 将“费项指定结算币种”更名为“费项结算币种”，并移除“指定币种”列。
3. 表格展示“费项”“结算币种”和“操作”三列。

### 明确费项不得重复（R-04）

1. 明确规则必须选择具体费项和明确币种；费项不提供“全部”“其他”，结算币种不提供“随原始币种”。
2. 选择费项后，结算币种默认取该费项的原始币种，财务可以改为其他明确币种。
3. 同一配置方案内，同一费项只能出现一次；存在重复费项时，系统不保存配置并指出重复行。
4. 兜底规则的结算币种默认为“随原始币种”，财务也可以改为一个明确币种。

### 引用模板只复制规则（R-05）

1. 移除原“引用费项币种模板”下拉框，在表格工具栏增加“引用模板”按钮。
2. 财务选择模板后，系统展示待填充规则；当前方案已有规则时，同时展示覆盖差异，由财务确认保留原值或使用模板值。
3. 确认后，系统将模板当时的规则复制到表格，并按 R-01、R-02 和 R-04 校验最终结果。
4. 系统只保存最终规则，不保存模板关联。模板后续变化不影响已套用的账单配置。

## 5. 返款账单怎样维护货款结算信息？（CP-02）

业务落点：BMS 返款账单配置编辑页。`见图2`
### 按货款原始币种维护结算信息（R-06）

1. “货款结算币种”表展示“货款原始币种”“货款结算币种”“客户收款账户”和“操作”四列。
2. 明确规则必须选择具体的货款原始币种，候选项不提供“全部”“其他”；同一原始币种只能出现一次。
3. 选择货款原始币种前，该行货款结算币种为空且不可选择；选择后，货款结算币种默认取相同币种，财务可以改为其他明确币种。
4. 明确规则和兜底规则都必须选择明确的货款结算币种，不提供“随原始币种”；兜底规则的货款结算币种默认为为“台币”。
5. 存在重复原始币种或缺少货款结算币种时，系统不保存配置并指出对应行。

### 每条规则可以维护客户收款账户（R-07）

1. 明确规则和兜底规则均可配置客户收款账户，也可以不配置；未配置账户不影响保存。
2. “账户名称”和“收款账号”均非必填，可以只填写一项，也可以全部留空。
3. 每条规则独立保存账户信息，不得读取或保存其他规则的账户。

## 6. 生效、存量与下游处理

1. 客户级账单配置继续按版本管理；新版本默认只影响变更后创建的任务和账单，不自动改写已有账单。
2. 首次生成账单时，任务读取并锁定所选配置版本中已经保存的结算币种规则。
3. 应收账单任务和结果只保存最终费项结算币种快照，不保存模板编号、模板版本或模板快照；模板后续变化不影响已有账单。
4. 历史账单需要调整结算币种时，按关联 PRD 的账单生成、重算或调账规则处理，不得通过修改模板或当前配置直接回写。
5. 本次不处理上线前已有配置和历史账单：不迁移、不转换、不回填，也不改写原有数据和结果。
6. 本需求生效后新增或修改配置时，新生成的配置版本按本需求规定的表格规则保存。
