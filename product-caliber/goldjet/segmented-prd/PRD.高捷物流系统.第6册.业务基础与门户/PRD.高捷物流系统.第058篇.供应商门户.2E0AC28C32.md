## 1. 业务范围与协作

供应商门户作为一个给外部供应商在服务过程中进行记录和状态反馈的平台。其中数据主要来源于业务运营平台，供应商门户可看作是业务运营平台中各服务模块的另一个载体，也是承接业务运营平台生成的服务订单；同时，大部分操作也是跟业务运营平台的服务模块一致的，操作后主要把服务订单状态和主要的数据回传到业务运营平台的订单详情-节点轨迹页面中。

## 2. 服务协作共用规则

<a id="doc-2E0AC28C32-service-sync-results"></a>
### 2.1 状态同步与完成信息回传

**业务范围**：供应商门户(干线服务、运输服务、关务服务、仓储服务）、业务运营平台-订单管理

**参与角色**：客服、供应商

**前置条件**：服务订单状态改变，服务信息不为空

**业务结果**：服务订单状态同步，服务信息回传到订单详情-节点轨迹

**处理规则**：服务订单状态发生变化，如，由“待接单”变为“进行中”，“进行中”变为“已完成”等，只要发生了服务状态的变化，都要同步到业务运营平台，在订单详情-服务信息也能看到服务状态，同时，在节点轨迹，也能看到对应的服务状态。
服务订单状态=已完成时，回传服务信息并显示到节点轨迹中，：
干线服务展示订舱界面的航线信息和附件资料，附件按上游资料类型区分装箱单、发票、合同、报关资料及其他，不限制为装箱单与发票两类。

运输服务：显示调度界面的运输信息

关务服务：显示服务项，操作人，完成时间

仓储服务：显示操作详情，操作人，操作时间

<a id="doc-2E0AC28C32-service-list-query"></a>
### 2.2 服务列表查询与重置

适用于空运、海运、陆运中港车、运输及各关务服务列表。各列表的业务类型与供应商数据范围仍由对应场景限定。

查询：在不选择任何查询字段下，点击“查询”按钮，默认查询全部数据。选择对应的查询条件，则显示符合结果的数据。查询出的数据，按照系统记录的“下单时间”倒序排列。

重置：重置所有查询条件。

### 2.3 关务服务列表统计与批量操作

适用于普货进出口、BC 出口、BC 进口、CC 进口和 BBC 进口关务服务。编辑服务信息的资格按各场景定义。

总计数量tab：点击后在下方表格显示全部的服务订单；里面的数字=全部服务订单之和。

待接单tab：点击后在下方表格显示服务状态=待接单的服务订单，里面的数字=全部待接单的服务订单之和。

已完成tab：点击后在下方表格显示服务状态=已完成的服务订单，里面的数字=全部已完成的服务订单之和。

已终止tab：点击后在下方表格显示服务状态=已终止的服务订单，里面的数字=全部已终止的服务订单之和。

已取消tab：点击后在下方表格显示服务状态=已取消的服务订单，里面的数字=全部已取消的服务订单之和。

终止服务：勾选要终止的服务单据，可批量选择，点击终止服务，弹出提示：

仅服务单状态=进行中的服务可执行终止服务，点击确定，如果勾选了其他状态的服务订单，则直接过滤掉，弹出提示：操作成功。

取消服务：勾选要取消的服务单据，可批量选择，点击取消服务，弹出提示：

仅服务状态=待接单/进行中的服务可执行取消服务，点击确定，如果勾选了其他状态的服务订单，则直接过滤掉，弹出提示：操作成功。

状态管理：勾选服务订单，可批量选择，点击状态管理后，弹出弹窗:

记录当前服务单据的完成时间节点。处理人为当前账号名，操作时间默认为当前时间，支持编辑。

仅进行中的服务订单可执行状态管理，点击确定，如果勾选了其他状态的服务订单，则直接过滤掉，弹出提示：操作成功。

## 3. 业务运营平台-供应商管理

**业务范围**：为外部供应商创建账号

**参与角色**：电商客服、供应商

**业务结果**：供应商主账号创建成功、供应商子账号创建成功。

**处理规则**：客服在业务运营平台创建供应商主账号。
在权限配置上配置该管理员账号的权限。
供应商在供应商门户上登录管理员账号。
供应商在供应商门户上创建子账号。
供应商为子账号配置数据权限和资源权限。
其他员工用子账号登录供应商门户系统。

**分支与异常**：3a、供应商登录管理员账号失败
3a-01、联系客服重新获取账号密码
3b、供应商登录后看不到相应的菜单和数据
3b-01、联系客服重新配置权限
6a：供应商员工登录子账号失败
6a-01、联系供应商管理员重新获取账号密码
6b、供应商员工登录后看不到相应的菜单和数据
6b-01、联系供应商管理员重新配置权限

### 3.1 账号管理

账号列表页面管理所有供应商的管理员账号信息。一个供应商仅存在一个管理员账号。管理员账号由客服在后台创建。

查询：在不选择任何查询字段下，点击“查询”按钮，默认查询全部数据。选择对应的查询条件，则显示符合结果的数据。查询出的数据，按照系统记录的“创建时间”倒序排列。

重置：重置所有查询条件。

新建账号：点进后进入账号创建页面

编辑：进入该账号的账号编辑页面，展示当前供应商管理员账号下的所有子账号。

**界面原型概述 · 账号管理**

- **区域字段或业务元素**：账号名称、账号密码、账号类型、状态、权限配置。
- **区域级通用规则**：展示当前记录，字段只读；操作入口按本场景的业务资格开放。

| 字段或控件特例 | 界面特例或可见反馈 |

| 账号名称 | 取供应商创建账号资料时的登录名称；展示全部 |

| 账号类型 | 由客服创建的管理员账号为主账号；由供应商创建的账号为子账号；展示全部 |
| 状态 | 账号的当前状态；《状态》为已启用，默认《操作》为禁用；当点击《操作》禁用时，更改《状态》为已禁用，《操作》为启用。 |

查看：进入该账号的查看页面

禁用：当禁用该账号时，该主账号下的所有子账号（包括主账号）被禁用

启用：当启用该账号时，该主账号下的所有子账号（包括主账号）被启用

## 4. 登录

### 4.1 原型界面

供应商门户账号不能自行注册，主账号由平台管理员在运维后台开通并设置权限。每个供应商限定1个主账号；主账号登录门户后，可创建子账号并设置子账号权限，最多可开设30个子账号。

## 5. 基础信息-供应商档案

**业务范围**：供应商或客服创建供应商档案

**参与角色**：电商客服、供应商管理员

**前置条件**：创建供应商账号成功

**业务结果**：供应商档案经由客服审核成功。

**处理规则**：供应商在供应商门户上创建供应商档案。
客服在业务运营平台进行供应商档案的审核。
审核成功后，为该供应商进行账期等业务资料的编辑。
客服主管进行供应商档案审核。

**分支与异常**：1a、供应商不创建供应商档案
1a-01、联系客服，由客服在业务运营平台创建包括业务资料在内的供应商档案。
1a-02、客服主管进行审核。
4a、供应商档案审核失败
4a-01、联系客户，由供应商或客服重新编辑供应商档案。
4a-02、客服主管进行审核。

## 16. 仓储服务

1、供应商门户的仓储服务与业务运营平台的仓储服务功能一致，只是把业务运营平台的仓储服务的界面搬过来供应商门户而已，操作和交互也是一致的。

2、服务单列表数据来源有所不同

当订单服务信息中，所选仓储服务的服务类型=我司服务的，生成的服务单是显示到业务运营平台-仓储服务模块的；

当所选仓储服务的服务类型=委外服务时，生成服务单才是显示到供应商门户-仓储服务模块中。

功能范围

| 功能菜单 | 说明 |
| --- | --- |
| 服务单列表 | 包含备货入库、集货入库、备货出库、集货出库，以及服务单详情 |
| 集货理货 | 包含小包裹理货、大宗商品理货 |
| 托盘管理 | 展示集货理货时保存的托盘信息 |
| 集货出库交接 | 线下扫描托盘号或线上输入托盘号，进行出库确认 |

注：无需做“暂存区管理”功能。

仓储理货、托盘和出库交接的完整业务规则由仓储管理篇定义；本场景只增加委外供应商的数据隔离与操作入口。
