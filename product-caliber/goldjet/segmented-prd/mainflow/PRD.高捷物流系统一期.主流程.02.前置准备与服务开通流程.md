# 前置准备与服务开通流程

<a id="mainflow-02"></a>

本文定义业务开展前的准备工作（建档签约、报价、商品备案、系统配置），以及订单级服务开通与取消流程。前置准备对应各业务模式主流程中的“建档签约→商品备案→业务准备→系统对接”环节。


## 1. 前置准备工作详细流程

“准备资料”后分两条无条件并行链：平台签约与系统配置链（平台签约完成→…→准备耗材）、客户合同与商品备案链（维护客户档案→…→获取商品备案信息）；商品备案经预审、审核未通过时通知客户并循环接受意见直至通过。

```plantuml
@startuml
skinparam activityDiamondBackgroundColor #FFF4CC
title 前置准备工作详细流程
start
:准备资料;
fork
  :平台签约完成;
  :10、收到平台对接信息;
  :11、维护客户店铺资料;
  :13、查看客户税金和运费;
  :14、设置客户信用等级;
  :15、创建仓库;
  :16、创建自动寻源规则;
  :14、通知仓库准备耗材/\n库内操作规范;
  :准备耗材;
fork again
  :1、维护客户档案;
  :2、维护店铺信息;
  :签订合同;
  :3、获取合同信息;
  fork
    :4A、设置报价规则;
  fork again
    :4B、发送客户指引;
    fork
      :5A、税金和运费充值;
    fork again
      :5B、填写商品备案信息;
      :6、预审;
    end fork
  end fork
  while (是否审核通过) is (否)
    :7、通知客户;
    :8B、收到意见;
    :8A、接受意见;
  endwhile (是)
  :9、获取商品备案信息;
end fork
stop
@enduml
```
## 2. 服务添加或取消子流程

按“合同条款是否已包含该服务”与“客户是否需要该服务”两个判断决定：已包含且需要则添加本次运输费用项、已包含但不需要则移除本次运输费用项、未包含但需要则先添加合同补充条款。

```plantuml
@startuml
skinparam activityDiamondBackgroundColor #FFF4CC
title 服务添加或取消子流程
start
if (合同条款包含该服务？) then (是)
  if (客户需要该服务？) then (是)
    :添加本次运输费用项;
  else (否)
    :移除本次运输费用项;
  endif
else (否)
  if (客户需要该服务？) then (是)
    :添加合同补充条款;
  else (否)
  endif
endif
stop
@enduml
```
