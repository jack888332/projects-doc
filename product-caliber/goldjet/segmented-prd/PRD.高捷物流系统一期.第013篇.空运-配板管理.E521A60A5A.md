### 1.1 页面交互规则

<a id="doc-E521A60A5A-section-b4efd1366e16"></a>
#### 1.1.1 通用页面行为

- 订单列表页面，默认分页结构，每页默认10条记录显示。

- 创建订单，默认按钮为“提交”、“取消”2个按钮。修改订单，默认按钮未“保存”、“取消”。

- 提交成功，页面一闪而过提示语“已提交成功！”

- 若页面有输入项不符合输入规范和不满足必填项输入，则该输入项Highlight提示，“提交”和“保存”按钮置灰，不可点击。

### 1.3 空运配板功能与规则

<a id="doc-E521A60A5A-section-c0227b1edded"></a>
#### 1.3.1 配板管理页面

- 航线部基于已经订舱的订单，确定同一航班号的订单如何配板才能实现当日航班利益最大化。

<a id="doc-E521A60A5A-section-26b24e8d3608"></a>
#### 1.3.2 筛选项定义

字段定义见 [数据字典 · 订舱与配板共用筛选项](PRD.高捷物流系统一期.第050篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-012-002)。

<a id="doc-E521A60A5A-section-2a7591d54113"></a>
#### 1.3.3 业务规则说明

|  | 主订单管理-配板界面 |
| --- | --- |
| 范围/概述 |  |
| 主要参与者 | 航线部 |
| 前置条件 | 订单已经完成订舱服务，并且已绑定提单号、航班号和出港日期 |
| 业务结果 | 页面操作功能可正常使用，查询和筛选项正常使用 |
| 主业务流程 | 1. 进入《配板管理》页面，根据筛选项在待配板列表和配板列表查询出想要配板的订单和对应的航班。点击待配板列表的“配板”，配板成功。已勾选的订单被配在勾选的航班上。<br>1. 取值逻辑：<br>- 舱位总体积：取自舱位实时查询的舱位总体积。<br>- 板数：取自舱位产品维护。算出高捷在这个航班上所能使用的当前板数。<br>- 货物总体积：配上去的体积之和。会根据配板、卸下、分批实时变动。<br>- 货物总毛重：配上去的毛重之和。会根据配板、卸下、分批实时变动。<br>- 货物毛件体：分为预计、入仓、提单。按毛/件/体进行排列。<br>- 货物尺寸：取自客服填写的货物尺寸。仅托盘货会有货物尺寸数据。其他货没有。<br>- 备注：航线运营会填写备注信息。运营人员会根据配板情况实时修改。<br>- 特殊物品：如果前面订单有选特殊物品，则这里展示<br>- 预计利润：预计利润=卖价*收客户重量-成本*付航司重量-当前航班剩余基重*合同罚金<br>卖价：客服新增订单填写的运费卖价<br>收客户重量=（提单体积重-提单毛重）*分泡率+提单毛重<br>成本：航线订单确认填写的成本<br>付航司重量：计费重<br>当前航班合同基重：板1数量*基准载重+板2数量*基准载重。。。<br>当前航班剩余基重：当前航班合同基重-（板1毛重+板2毛重）<br>并非所有航班都要计算预计利润。 |
| 业务分支 | 功能：<br>1. 卸下：将已经配好板的订单卸下。货物总体积和货物总毛重实时更新。<br>1. 分批：航线发现已配好的订单货物受限于可使用的板体积（货物总体积远大于舱位总体积），只能配上一部分。就可点击“分批”，将货物的毛件体拆分出一个新的订单。<br>默认和原订单同一个航班号和出港日期，支持修改。<br>点击确认后，在配板列表生成新的数据。提单号不变。<br>此时功能按钮为：撤回。点击撤回后，合并成原订单的毛件体。 |
