### 1.2 空运清关派送功能与规则

<a id="doc-6708987F95-section-547c49a6013c"></a>
#### 1.2.1 清关派送列表管理

- 海外部客服完成清关派送服务操作。

<a id="doc-6708987F95-section-bfeec0895699"></a>
#### 1.2.2 清关派送查询与列表字段

**筛选项**

**界面原型概述 · 清关派送筛选栏**

- **区域字段或业务元素**：订单号/提单号、始发港、目的港、客户、建单日期、出港日期、订单状态、服务状态。

| 字段或控件特例 | 特例约束或业务结果 |
| --- | --- |
| 订单号/提单号、客户 | 支持模糊查询。 |
| 始发港、目的港 | 默认值：全部。 |
| 建单日期、出港日期 | 按日期筛选；如果不筛选，默认为全部。 |
| 订单状态 | 候选项为：；全部；待订舱；待补录；待出提单；已出提单；已交单；待审核；已作废；异常作废。 |
| 服务状态 | 待服务；服务中；服务已完成；异常结束；服务已取消。 |

**订单列表字段**

**界面原型概述 · 清关派送订单列表栏**

- **区域字段或业务元素**：提单号、入中转仓货物数据-件数（件）、入中转仓货物数据-重量（kg）、入中转仓货物数据-体积（m³）、提单货物数据-件数（件）、提单货物数据-重量（kg）、提单货物数据-体积（m³）、货物状态、始发港、目的港、头程航班号、二程目的地、三程目的地、出港日期、品名、客服、客户、备注、建单日期、订单状态、服务状态。
- **区域级通用规则**：字段均只读。

| 字段或控件特例 | 特例约束或业务结果 |
| --- | --- |
| 入中转仓货物数据-件数（件）、提单货物数据-件数（件） | 单位：件。 |
| 入中转仓货物数据-重量（kg）、提单货物数据-重量（kg） | 单位：kg。 |
| 入中转仓货物数据-体积（m³）、提单货物数据-体积（m³） | 单位：m³。 |
| 备注 | 来源：补料-清关派送备注。 |

<a id="doc-6708987F95-section-e97956a32a71"></a>
#### 1.2.3 材料、接单与状态管理规则

空运客服发出清关派送服务指令后，海外部客服在清关派送列表查询订单、处理材料、接单，并记录目的地提货或清关送达结果。订单按创建时间倒序排列；接单时记录接单用户名和操作时间。

**界面原型概述 · 清关派送材料**

- **区域字段或业务元素**：附件上传、附件删除、材料下载。

| 字段或控件特例 | 适用条件 | 特例约束或业务结果 |
| --- | --- | --- |
| 附件上传、附件删除 | 上传清关派送材料时 | 附件必填，支持`.rar`、`.zip`、`.docx`、`.doc`、`.xls`、`.xlsx`、`.pdf`、`.jpg`，单个不超过20 MB；保存前可删除并重新上传。 |
| 材料下载 | 海外部客服点击“下载”时 | 展示全部已上传材料，支持单个或批量下载。空运客服发送服务指令时上传材料；其他文件取这些已上传材料。 |
| 提单、分单、舱单 | 下载对应单据时 | 系统按航司从模板管理生成PDF文件。 |

**界面原型概述 · 提货与送达结果录入**

- **区域字段或业务元素**：目的地提货、清关送达、操作时间、数量、确认保存。
- **区域级通用规则**：勾选目的地提货或清关送达后展示操作时间和数量；操作时间默认当前时间，两类结果均支持多次提交。

**保存后的业务结果**

| 操作 | 服务状态结果 | 订单状态结果 | 剩余数量 |
| --- | --- | --- | --- |
| 目的地提货 | 由“服务中”变为“服务已完成”。 | 变为“目的地提货”。 | 剩余毛件体=提单剩余数量−当前录入数量。 |
| 清关送达 | 变为“服务已完成”。 | 变为“清关送达”。 | 剩余毛件体=提单剩余数量−当前录入数量。 |
