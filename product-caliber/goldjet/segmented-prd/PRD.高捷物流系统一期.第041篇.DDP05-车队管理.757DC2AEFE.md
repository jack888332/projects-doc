### 1.1 航晟物流：车队管理的流程与关键控制点

<a id="doc-757DC2AEFE-section-803c34fafff7"></a>
#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 新增司机 | 司机管理 | 录入司机基础资料。 | 2 | 是 |
| 2 | 关联车辆 | 司机管理 | 将司机与车辆关联，反映司机驾驶车辆的关系。 | 3 |  |
| 3 | 查看司机列表 | 司机管理 | 司机列表支持查看和筛选司机记录。 | 4 |  |
| 4 | 判断是否修改司机信息 | 司机管理 | 司机信息需要更新时进入修改。 | 5 |  |
| 5 | 修改司机资料 | 司机管理 | 修改司机记录后，系统记录修改时间和操作人。 | 6 |  |
| 6 | 查看司机详情<br>（进行中任务和历史任务） | 司机管理 | 司机详情展示基础资料、当前进行中的任务和历史任务。 |  |  |
| 7 | 新增车辆 | 车辆管理 | 录入车辆资料。 | 8 | 是 |
| 8 | 查看车辆列表 | 车辆管理 | 车辆列表支持查看和筛选车辆记录。 | 9 |  |
| 9 | 判断是否修改车辆信息 | 车辆管理 | 车辆信息需要更新时进入修改。 | 10 |  |
| 10 | 修改车辆资料 | 车辆管理 | 修改车辆资料及其关联司机信息。 | 11 |  |
| 11 | 查看车辆详情<br>（进行中任务和历史任务） | 车辆管理 | 车辆详情展示基础资料、当前进行中的任务和历史任务。 |  |  |
| 12 | 录入事故或违章 | 事故违章管理 | 选择记录类型，录入事故或违章信息。 | 13 |  |
| 13 | 关联司机 | 事故违章管理 | 将事故或违章记录与司机关联。 | 14 |  |
| 14 | 查看事故违章列表 | 事故违章管理 | 事故违章列表支持查看和筛选记录。 | 15 |  |
| 15 | 判断是否修改事故违章信息 | 事故违章管理 | 记录需要更新时进入修改；无需修改时结束。 | 16或结束 |  |
| 16 | 修改事故违章 | 事故违章管理 | 编辑事故或违章信息并保存。 |  |  |
| 17 | 录入维修记录 | 维修管理 | 录入维修明细。 | 18 |  |
| 18 | 关联车辆 | 维修管理 | 将维修记录与发生维修的车辆关联。 | 19 |  |
| 19 | 查看维修列表 | 维修管理 | 维修列表展示维修记录。 | 20 |  |
| 20 | 判断是否修改维修信息 | 维修管理 | 维修记录需要更新时进入修改；无需修改时结束。 | 21或结束 |  |
| 21 | 修改维修记录 | 维修管理 | 编辑维修记录并保存。 | 结束 |  |
| 22 | 录入油耗或油卡记录 | 油耗管理 | 录入加油、油卡消费和耗损信息。 | 23 |  |
| 23 | 计算百公里油耗 | 油耗管理 | 系统根据已录入数据自动计算百公里油耗。 | 24 |  |
| 24 | 关联车辆 | 油耗管理 | 将油耗记录与对应车辆关联。 | 25 |  |
| 25 | 查看油耗列表 | 油耗管理 | 油耗列表展示油耗记录。 | 26 |  |
| 26 | 判断是否修改油耗信息 | 油耗管理 | 已提交的油耗记录需要更新时进入修改；无需修改时结束。 | 27或结束 |  |
| 27 | 修改油耗记录 | 油耗管理 | 编辑油耗记录并保存。 | 结束 |  |
