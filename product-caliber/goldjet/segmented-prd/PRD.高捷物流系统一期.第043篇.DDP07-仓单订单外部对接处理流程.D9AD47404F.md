### 1.1 航晟物流：仓单订单外部对接处理的流程与关键控制点

#### 1.1.1 流程描述

| 步骤 | 步骤描述 | 角色 | 流程描述 | 下一步骤 | 关键控制点 |
| --- | --- | --- | --- | --- | --- |
| 1 | 判断入仓重量误差是否小于 3% | 仓库系统 | 计算 \|(入仓重量 - 报关重量) / 报关重量\|。结果小于 3% 且满足密度等操作条件时，系统自动发送预配舱单。 | 2 | 是 |
| 2 | 接收预配舱单 | 海关系统 | 海关系统接收并处理预配舱单。 | 4 |  |
| 3 | 人工确认重量并发送预配舱单 | 仓库系统 | 重量误差大于 3% 或未满足其他操作条件时，由空运或航晟物流客户部确认重量；确认后，业务系统发送预配舱单。 | 4 |  |
| 4 | 接收预配舱单反馈 | 仓库系统 | 仓库系统接收预配舱单反馈结果。 | 5 |  |
| 5 | 线下申请报关 | 海关系统 | 线下操作，申请报关。 | 6 |  |
| 6 | 获取报关状态 | 海关系统 | 报关后，系统自动获取海关反馈的报关状态。 | 7 |  |
| 7 | 发送出仓单 | 仓库系统 | 海关反馈“放行”后，仓库系统自动向 WMS 发送该订单的出仓单。 | 8 |  |
| 8 | 接收并处理出仓单 | WMS | WMS 接收出仓单并处理货物出仓。 | 9 |  |
| 9 | 反馈出仓结果 | WMS | WMS 向仓库系统反馈出仓结果。 | 10 |  |
| 10 | 中转派车 | 仓库系统 | 仓库系统为出仓货物安排中转派车，具体流程见[中转仓用车流程](PRD.高捷物流系统一期.第046篇.DDP10-中转仓用车流程.230BF48EFA.md#doc-230BF48EFA-section-e4cd43033ac4)。 | 11 |  |
| 11 | 发送入区登记 | 仓库系统 | 仓库系统通过人工操作或自动处理发送入区登记。 | 12 |  |
| 12 | 接收入区登记 | 货站 | 货站接收并处理入区登记。 | 13 |  |
| 13 | 反馈入区登记回执 | 货站 | 货站反馈入区登记处理结果。 | 14 |  |
| 14 | 接收入区登记回执 | 仓库系统 | 仓库系统接收入区登记回执。 |  |  |

| 所属步骤 | 关键控制点描述 |
| --- | --- |
