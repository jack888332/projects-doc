#### 1.1.1 通用页面行为

### 1.3 合作方报价维护功能与规则

#### 1.3.1 供应商报价管理

<a id="doc-92B1FD526A-section-4485691bd328"></a>
#### 1.3.2 供应商报价新增

1. 按钮说明

- 提交：提交时对必填信息、报价信息进行校验，若必填项为空时，则系统提交时会标红提示该错误，并不允许提交；如果报价相同且有效日期重叠，那么提交时失败，并提示“已存在报价，请勿重复添加”。根据字段：供应商车行、提货点、卸货点、车行、监管类型、特种车、尾板车、有效期判断。如果供应商、路线信息、车辆信息相同且生效日期重叠，则判断为相同报价。

- 取消：取消当前新增供应商报价，返回供应商报价列表页面。

- 复制：复制当前序号的报价内容，右击可以粘贴到另一行。

- 删除：删除当前序号的报价。

- 新增行：新增页面默认10条报价行，如果报价行不够，点击该按钮添加一行。

1. 字段说明

字段定义见 [数据字典 · 供应商运输报价新增字段](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-007-001)。

**返空费计算规则：**
- `返空费 （%）`：系统根据运单状态为“已取消”的对运单计算返空费。返空费=运输费*返空费比例。百分比数值，数值取值范围0-100，保留小数点后2位

#### 1.3.4 供应商报价查询与状态

（1）按钮说明

- 查询：在不选择任何查询字段下，点击“查询”按钮，默认所有查询条件。选择对应的查询条件，则显示符合结果的数据。查询出的数据，按照供应商首个字符拼音顺序排列。

- 重置：重置查询条件。

- 新增报价：跳转至“新增报价”页面。

- 上传报价：弹出“导入excel报价”弹窗。

- 修改：跳转至“修改报价”页面。

- 删除：删除当前的报价，点击时有确认删除提示。

- 批量删除：删除已经勾选了的报价。

（2）筛选自定义

字段定义见 [数据字典 · 供应商运输报价筛选项](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-007-003)。

1. 列表字段

字段定义见 [数据字典 · 供应商运输报价列表字段](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-007-004)。

1. 列表说明

- 排序规则：查询结果先按供应商车行首个字符的拼音字母顺序排列；同一供应商下，“有效”报价优先于“失效”报价。

- 供应商车行：显示全称。

- 状态：系统根据当前日期和报价的“有效日期”对比，若当前日期<有效日期，则判断为“有效”，若当前日期>有效日期，则判断为“失效”。

- 更新人：系统自动记录最后操作的用户名。

- 更新时间：系统自动记录最后一次操作的系统时间。

#### 1.3.7 客户收费报价新增

- 客户收费报价管理页面可创建、修改、查看和删除客户收费报价。

（1）按钮说明

- 提交：提交时对必填信息进行校检。若必填项未输入，或输入长度格式不符合要求，则该输入项红色高亮提示，《提交》按钮置灰不可点击。

- 取消：取消当前新增客户收费报价，返回客户收费报价列表页面。

- 复制：复制当前序号的报价内容。

- 删除：删除当前序号的报价。

- 新增行：新增页面默认10条报价行，如果报价行不够，点击该按钮添加一行。

（2）字段说明

字段定义见 [数据字典 · 客户运输报价新增字段](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-007-005)。

**返空费计算规则：**
- `返空费 （%）`：系统根据运单状态为“已取消”的对运单计算返空费。返空费=运输费*返空费比例。百分比数值，数值取值范围0-100，保留小数点后2位

（3）业务规则说明

| 场景名称 | 客户收费报价管理-客户收费报价新增 |
| --- | --- |
| 范围/概述 | 填写客户信息、路线信息、车辆信息、报价信息，完成报价新增。 |
| 主要参与者 | 航晟客服、主管 |
| 前置条件 | 进入客户收费报价管理，点击“新增报价”按钮，进入此页面 |
| 业务结果 | 校验通过后新增客户收费报价并返回报价列表；校验失败时不保存并提示原因。 |
| 主业务流程 | 进入“新建报价”页面，填写：客户信息、路线信息、车辆信息、报价信息。<br>1.客户信息：<br>- 客户：所有客户名称，由系统合作方档案管理类型为“客户”带出。<br>- 税率（%）：填写税率，保留小数点2位。<br>- 币种：选择结算的币种代码，和结算系统的币制代码一致。<br>- 未保存前，可重新修改客户信息。<br>2.路线信息：<br>- 提货点：省市二级联动选择，最后填写的是详细地点。<br>- 卸货点：省市二级联动选择，最后填写的是详细地点。<br>- 是否往返：选择往返或者是单程车。<br>- 未保存前，可重新修改路线信息。<br>3.车辆信息：<br>- 车型：添加、编辑一个报价时只能选择一种车型。<br>- 监管类型：添加、编辑一个报价时只能选择一种监管型。<br>- 特种车：添加、编辑一个报价时只能选择一种特种车。<br>- 运输时效：该路线车辆任务完成的预计用时。<br>- 未保存前，可重新修改车辆信息。<br>4.报价信息：<br>- 提货费：车辆完成一次任务后的航晟应收的金额，单位（元/车）。单程、往返类型都只按照价格算一次。提货费和单价（元/KG）的收费方式，一个报价只能存在一种计算方式。<br>- 单价：车辆完成一次任务后的航晟应收的金额，以单价方式计算，提货费=单价（元/KG）*提货重量（KG）。取值保留小数点后2位。另外录入了起步价，计算的提货费>起步价，则按计算的提货费应收；如果计算的提货费<起步价，则取起步价应收。<br>- 返空费（%）：运单状态更新为“已取消”。系统根据报价管理中的“返空费比例”乘以运输费。此处填写返空费比例，保留小数点后2位。<br>- 起始日期：生效日期默认为提交报价当天。录入的为有效期，格式“YYYY-MM-DD”。<br>- 有效期：录入的为有效期，格式“YYYY-MM-DD”。<br>- 未保存前，可重新修改报价信息。<br>点击“确认”进行提交保存。<br>- 提交成功：显示“保存成功”提示，跳转到“客户收费报价管理列表”界面。<br>- 无法提交：若必填项未输入，则该输入项红色高亮提示； |
| 业务分支 | 客户收费报价列表页面“上传报价”按钮，支持通过excel表格批量上传，按照上传模板填好必填的信息。上传时会校检必填信息和去重已存在的报价。支持xls、xlsx格式 |

- 报价方式校验：（单价、单位）和运输费只能2选一，其中一项必填。
- 报价状态判断：有效期结合起始日期判断报价状态“生效”“失效”“待生效”。

#### 1.3.9 客户收费报价查询与状态

（1）按钮说明

- 查询：在不选择任何查询字段下，点击“查询”按钮，默认所有查询条件。选择对应的查询条件，则显示符合结果的数据。查询出的数据，按照客户首个字符拼音顺序排列。

- 重置：重置查询条件。

- 新增报价：跳转至“新增报价”页面。

- 上传报价：弹出“导入excel报价”弹窗。

- 修改：跳转至“修改报价”页面。

- 删除：删除当前的报价，点击时有确认删除提示。

- 批量删除：删除已经勾选的报价。

1. 查询项定义

字段定义见 [数据字典 · 客户运输报价筛选项](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-007-007)。

（3）列表字段说明

字段定义见 [数据字典 · 客户运输报价列表字段](PRD.高捷物流系统一期.第035篇.数据字典.7A3D9E1F50.md#doc-7A3D9E1F50-fields-007-008)。

1. 列表说明

- 排序规则：查询结果先按客户名称首个字符的拼音字母顺序排列；同一客户下，“有效”报价优先于“失效”报价。

- 客户：显示全称。

- 状态：系统根据当前日期和报价的“有效日期”对比，若当前日期<有效日期，则判断为“有效”，若当前日期>有效日期，则判断为“失效”。

- 更新人：系统自动记录最后操作的用户名。

- 更新时间：系统自动记录最后一次操作的系统时间。

#### 1.3.10 报价批量上传规则

| 场景名称 | 客户收费报价管理-客户收费报价上传、供应商报价管理-供应商报价上传 |
| --- | --- |
| 范围/概述 | 批量上传客户收费报价和供应商报价 |
| 主要参与者 | 航晟客服、主管 |
| 前置条件 | 分别进入客户收费报价列表和供应商报价列表，点击《上传报价》按钮，弹出上传 Excel 的弹窗。 |
| 业务结果 | 文件全部通过校验时批量生成报价并返回对应列表；任一行校验失败时整份文件不导入，并提示错误行及原因。 |
| 主业务流程 | 进入报价上传弹窗，按新增报价规则上传Excel文件，支持`.xls`、`.xlsx`格式。<br>- 标红项为必填项。上传时校验供应商车行名称是否与系统数据一致，以及必填项和格式是否正确。任一行校验失败时整份文件上传失败，并按“第<行号>行必填项为空”或“第<行号>行供应商车行未找到匹配项”的格式提示错误。<br>- 上传报价与已生效的相同报价重复时，提交失败并提示“已存在报价，请不要重复添加”。<br>点击“确认”提交。<br>- 提交成功：提示“上传成功”，并根据上传入口返回“供应商报价管理列表”或“客户应收报价管理列表”。 |
